# 事实文档执行

撰写 ADR、按事实文档改代码、或发现文档未覆盖的需求时使用本页。完成标准：改动后的 ADR 只含已确认要做的内容；代码只落实这些内容；多出来的需求已记下并在收尾询问。

## ADR

只写已确认要做的决策、原因、适用边界和待验证假设。用要做的事陈述约束。

不写验收内容：验收方法写入 `docs/validation/验收流程.md`，验收记录落点见根 `AGENTS.md` 项目导航。

## 改代码

先读相关 `CONTEXT.md`、ADR 与视觉规范，只落实其中已写明的内容。

可用 `npm run docs:impact` 按改动路径列出候选事实文档；它只作提示，实际同步范围仍按影响判断。
