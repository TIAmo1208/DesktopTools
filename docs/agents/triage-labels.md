# 需求分流标签

| 标准角色 | 工单标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工执行 |
| `wontfix` | `wontfix` | 终止处理 |

技能使用本表中标准角色对应的工单标签。
