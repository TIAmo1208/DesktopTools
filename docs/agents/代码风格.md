# 代码风格

写代码与写注释时读本页。AGENTS.md 只保留两条高频规则：注释必写、事件接口与处理函数命名。

## 注释与日志

- 用户可见日志中的说明、状态和字段标签使用中文。
- 命令行参数、协议字段、类型与枚举名称、设备标识、文件路径、平台原生错误及其他需要精确检索的技术值保留原文。
- 在关键执行节点添加必要日志，并根据内容和严重程度选择 `DEBUG`、`INFO`、`WARN`、`ERROR` 或 `FATAL` 等级。
- 每个类前添加简短的职责说明。
- 每个接口声明后添加简短的用途说明。
- 每个接口实现前添加简短的用途说明。
- 每个变量声明后添加简短的用途说明；变量声明为表达式或闭包时，注释放在声明前。
- 重要逻辑块前添加简短说明，交代处理目的和边界。

## 代码组织

- 简单条件及其执行逻辑能清晰单行表达时写在同一行；不同功能模块之间空行分隔。
- 文件头仅保留必要声明；静态接口靠近首次使用位置，控制数量。
- 新增接口先评估调用方、复用价值和复杂度；调用方超过 3 个、复用价值高且逻辑较长时抽取，其余优先留在现有函数内。
