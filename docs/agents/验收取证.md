# 验收取证

执行验证时使用本页。层定义、判据、证据标签与禁止事项见 `docs/validation/验收流程.md`；需要看画面时的抓取分级与纪律见 `docs/agents/取证工具.md`；TMP、互斥体、产物与端口见 [环境前提](环境前提.md)。本页只回答「先跑哪条」。

## 先跑哪条命令

1. 纯逻辑、契约、几何 → `node --test <测试文件>`，收尾跑 `npm test`。
2. React 组件、样式、交互 → 加跑 `npm run dev` + `npm run test:browser`。
3. Rust 侧平台代码 → `npm run test:rust`。
4. 真实宿主里能数值化的事实（计算样式、计数、落盘偏好）→ 开发宿主带调试端口启动后 `node scripts/取证探针.mjs`。
5. 需要真实宿主日志、返回码或人眼确认 → `.\scripts\后台启动程序.ps1 -Theme <主题>`，用户操作后读日志与退出码。

`npm run test:rust` 已注入 `TMP`；直接调用 `cargo test` 时先按根 `AGENTS.md` 设置，否则 `cl.exe D8050` 会阻断整条链。

## 优先在哪层取证

按 L0 → L1 → L2 → L3-探针 → L3 顺序，能落低层就不上高层。凡是能表达成返回值、尺寸、计数或计算样式的现象，必须在低层或 L3-探针断言。

## 环境性失败

判据与清单见 `验收流程.md` §6：除清单内、且报错为权限或前置条件类的用例外 0 失败。不得因环境性失败重跑同一命令，也不得转而打开程序截图。

## 允许看画面的情况

只看 `验收流程.md` §4 的六项人眼清单；抓取顺序（数值探针 → CDP 截图 → PrintWindow → 实机截图需用户同意）见 `docs/agents/取证工具.md`。

## 结论标注

每条结论标注它属于哪一类证据：软件模拟、浏览器断言、运行时探针、真机日志、人眼截图。五类之间不得互相冒充。
