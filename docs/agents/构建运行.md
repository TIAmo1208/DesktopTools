# 构建与运行

命令与构建产出按本页执行。TMP、互斥体、产物路径与 0xC0000142 见 [环境前提](环境前提.md)，本页不重复。

## 门禁命令

- 类型检查 `npm run typecheck`；受影响测试用 `node --test <测试文件>`；项目全量测试 `npm test`（含前端、组件与 `cargo test --all-targets`）。
- 格式化 `npm run format`（Prettier 与 `cargo +nightly-2026-09-08 fmt`）；提交前执行 `git diff --check`。
- 修改 Rust 或 Cargo 配置前，先结束本项目的开发监听；集中完成改动后，依次执行检查、受影响测试、阶段完整测试及最终构建，再启动程序。检查、测试和开发启动共用构建目录，Cargo 操作必须串行执行。
- 文件系统相关测试用临时目录构造 fixture；不断言仓库里 `plugin/` 等目录的实际内容，目录调整不应让测试变红。

## 构建与构建提速

- 日常 Rust 反馈优先使用 `cargo check` 和受影响测试；最终验收仍需实际构建（`npm run build` 或 `npm run tauri:build`）。评估构建提速时记录 `--timings` 与墙钟耗时，区分首次缓存准备、无改动构建和源码改动后的构建，不将 Cargo 编译单元耗时直接解释为纯链接耗时。
- `npm run tauri:installer` 依赖 `scripts/prepare-licenses.mjs` 生成的许可文件，普通开发与纯程序构建不依赖它。
- Windows 应用清单由 `src-tauri/build.rs` 对**全部目标**注入 `src-tauri/windows.manifest`（comctl32 v6 依赖），并关闭 `tauri-build` 只作用于 bin 目标的默认清单。依赖链静态导入 `TaskDialogIndirect`，lib 测试二进制没有这份清单时会在入口点之前以 `0xC0000139 (STATUS_ENTRYPOINT_NOT_FOUND)` 退出——`npm run test:rust` 报这个错误码时先核对清单注入，不要按缺失 DLL 或运行库排查。

## 插件目录同步与样式表缓存

- 开发运行的插件目录是 `build/target/debug/plugin`（见 ADR-0033、ADR-0016），仓库 `plugin/` 的改动不会自动同步过去。改主题（`plugin/<主题>` 下任何文件）后，先执行 `npm run sync:plugin` 同步到运行目录，再看效果；示例插件默认跳过，需要时加 `--include-examples`。
- `npm run tauri:dev` 启动时打印本轮实际加载的 `build/frontend` 与调试插件目录，先核对路径再判断 UI 是否生效。
- 宿主建窗口时把主题样式表地址拼进页面 URL，形式是 `theme.css?v=<cacheKey>`；`cacheKey` 由清单版本 + 样式表文件大小 + 修改时间派生，页面侧 `<link>` 与首帧拼进窗口地址的是同一串。改主题文件后 URL 自动变化，无需手动 bump 版本。WebView2 按 URL 缓存样式表：URL 未变时窗口仍渲染旧 CSS——样式未生效时先确认运行目录已同步新文件、页面 `link[data-theme-plugin]` 的 href 已经变化，再排查样式本身。

## 执行环境

TMP、互斥体、产物路径、1420/Edge、0xC0000142 与工具读取失败统一见 [环境前提](环境前提.md)。构建相关的三条：

- Rust 命令走 npm script（已注入 TMP）；直接 `cargo` 时先设 `TMP=build\tmp`。
- 最终构建用 `npm run tauri:build`（已带 TMP）。
- `cl.exe D8050` 先查 TMP；不要改 MSVC 参数或排查安全软件。

## 长任务、后台句柄与进程查询

- 后台任务句柄不跨回合：长任务在同一回合内前台分块执行，或把结果增量写入 JSONL/日志再汇总。下一回合拿不到上一回合的后台句柄，未落盘的结果按未完成处理。
- 进程与端口用 `tasklist`、`netstat -ano`；`wmic process` 与 CIM 查询在本机会挂起到超时，不要用它们查命令行。
- 浏览器断言与 Rust/前端构建串行执行：并发会互相等锁，并让 CDP/Edge 启动超时，产生“环境性失败”的假象。
- 断言与开发服务器收尾后确认 `127.0.0.1:1420` 无监听；无可见 Edge 窗口时清理无头残留（`scripts/跑断言页.mjs` 已内置该守卫）。
