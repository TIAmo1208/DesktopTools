# 取证工具与截图纪律

需要「看画面」时读本页。分层定义与各层证据标签见 `docs/validation/验收流程.md`，本页只管**怎么抓、抓什么、留下什么**。

## 取证顺序

从便宜且确定的一级往贵的一级退。上一级拿不到结论才进下一级，不要跳级。

| 级 | 手段 | 能回答什么 | 入口 |
| --- | --- | --- | --- |
| 1 数值探针 | 只读 CDP `Runtime.evaluate` 读计算样式、DOM 计数、`dataset`、`link` 数量；读 `settings.json` 等落盘状态 | 位置、尺寸、颜色、计数、状态归属 | `node scripts/取证探针.mjs` |
| 2 CDP 窗口截图 | `Page.captureScreenshot`（`clip`、`format: "jpeg"`、`quality: 60`、`fromSurface: true`、带超时） | 只能看、不能数值化的呈现（裁到元素，不抓整屏） | `scripts/取证探针.mjs --截图` |
| 3 PrintWindow | `PrintWindow(hwnd, dc, PW_RENDERFULLCONTENT)` | 非 WebView2 的原生窗口表面（透明桌面宿主取不到内容，属预期失败） | `scripts/窗口截图.ps1` |
| 4 实机屏幕截图 | 屏幕区域拷贝 | 前三级都取不到的合成结果 | **先停下来问用户，同意后才执行** |

第 4 级会抢占用户的桌面操作，且失败后只能反复重试，所以把它挡在同意门槛后面：脚本要求显式带 `-实机屏幕截图 -已获用户同意`，缺一律以 `[环境]` 退出。上一级失败时也不得自动升级到第 4 级。

## 取证纪律

- **先列清单再一次跑完**：进宿主前把要核对的点全部写进检查清单，一轮跑完再统一读结果。不要「截一张—看一眼—再截一张」。
- **文案从 DOM 读**：文本、占位、提示一律用探针读节点内容。图像只用来判断纯视觉呈现，不靠识图读字。
- **通过的项不留图**：截图只在回归失败时保留，作为定位证据；通过项只留数值结论。
- **结果只在本机**：截图、日志、探针输出都写进 `build/validation/`，该目录不入库。本机结论只代表本机环境。
- 超时单次有界，超时即失败并给原因，不循环重试、不靠重启碰运气（与 `验收流程.md` §5 一致）。
- **主题样式表缓存会伪造失败/成功结论**：WebView2 按 URL 缓存样式表；文件已同步但 URL 未变时，窗口仍按旧 CSSOM 渲染（计算样式读到的「效果」可能还是旧规则），而 `fetch(href, { cache: "no-store" })` 却能取到新文本——这个差异最像「样式写错了」。核对顺序：先确认样式表内容是新的（读 `document.styleSheets` 的规则数/是否包含新选择器，或用无缓存 fetch 对比文本），再读计算样式判断效果；两者不一致优先怀疑缓存与插件目录同步（开发运行目录见 `构建运行.md`），样式未生效时禁止反复改 CSS 试错。

## 检查清单写法

`取证探针.mjs` 读一份 ES 模块，默认导出检查项与截图项。检查项是只读表达式，返回可序列化值：

```js
// .scratch/<问题>/清单.mjs
export default {
    检查: [
        { 名称: "主题行文案", 表达式: `document.querySelector("#interface-theme-plugin")?.value ?? null` },
        { 名称: "未归类名称颜色", 表达式: `getComputedStyle(document.querySelector(".desktop-item__label")).color` },
        { 名称: "主题样式表数量", 表达式: `document.querySelectorAll('link[data-theme-plugin]').length` },
    ],
    截图: [{ 名称: "外观页主题行", 选择器: ".appearance-settings" }],
};
```

运行：

```powershell
node scripts/取证探针.mjs --清单 .scratch/<问题>/清单.mjs --目标 desktop-host --截图 build/validation/<问题>/截图
```

参数：`--端口`（默认 9223）、`--目标 <URL 子串>`（多窗口时选目标页）、`--截图 <目录>`、`--超时 <毫秒>`（默认 10000）。退出码 0 全部完成，1 有检查项失败，2 环境问题（端口未监听、目标页不存在、超时）。

探针依赖开发宿主带远程调试端口启动：

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = "--remote-debugging-port=9223"
```

端口只对本机生效，探针只读，不改页面状态。

## 原生窗口截图

```powershell
.\scripts\窗口截图.ps1 -进程名 desktop-tools
```

输出落在 `build/validation/窗口截图/`，文件名带进程名与时间戳，同时打印窗口标题与尺寸。取不到内容时按上面的顺序退级，不会静默成功。
