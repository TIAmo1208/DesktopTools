# 收集箱使用工作区共享条目

## 定位与状态

收集箱作为临时中转站，保留工作区共享集合和公共格子外壳；收入、类型及复制取出的已确认决策见 [ADR-0021](0021-收集项以Markdown文件为事实.md)。选择、打开、拖放与清理的 UX 主流程已确认，并支持右键切换混排／分离、右上角菜单复选筛选及跳过不匹配项的部分投放。UI 细节与视觉稿已确认，前端已实现三类呈现、混排／分离、复选筛选、选择和逐项清理确认；后端已接入独立条目扫描、删除恢复和按类型打开。原生复制拖出已接线，Windows 拖动与外部目标兼容性尚未经真实环境验证。

## 当前实现基线

收集箱设置保存全局 `collectImagePreviewWidth`，单位 DIP，整数范围 48–156，缺失时默认 78；列表图片高度为宽度的 2/3，默认图像槽为 78×52。沿用偏好事件更新所有收集箱，不改变原图与导出内容。

独立图片与文本共用 500ms 悬停时机、定位和关闭规则；图片浮层最大为 520×420 DIP（含内边距），完整等比显示。非 GIF 图片按实际显示尺寸乘 DPI 读取静态缩略图，长边最多 768 物理像素，共用图像 STA 与有界缓存；列表请求仍最多 384 像素且保持静态。GIF 悬停直接通过已有原图接口播放动画，保留格式、安全校验及 32 MiB 文件限制，不受 768 像素限制，不实现动画帧缩放或自定义解码。原图播放可能按原始分辨率解码，CSS 显示上限不保证降低解码内存。离开、折叠、拖动、失焦或销毁时关闭浮层并释放前端图像引用，迟到结果丢弃，不预读原图。非 GIF 的像素上限用于控制传输与前端像素内存，高 DPI 下允许牺牲部分清晰度。

收集项打开由 Tauri 与独立宿主共用执行入口；失败时发布收集项变化事件，按当前磁盘事实刷新所有收集箱，保留失效映射并标记不可用。错误说明包含目标路径、中文原因与 Shell 返回码，避免只有数字且列表停留在旧状态；未关联程序等打开失败不等同于文件缺失，不直接将所有失败标记为不可用。

独立图片列表通过 `read_collect_image` 的 `pixels` 参数请求显示尺寸乘 DPI 的缩略图，上限 384 物理像素；只在展开且进入可见区域时读取，离屏释放前端图像，尺寸变化按事件更新。复用现有 Windows Shell 图像 STA、请求合并和有界缓存，不新增线程或轮询。列表显示静态缩略图以降低解码、传输和渲染负担；编辑窗不传尺寸，继续读取原图并保留 GIF 动画。系统图片处理器决定内部解码方式，不能保证每种格式都按采样解码或限制其峰值内存；无缩略图时显示不可用，不回退加载整张原图。

已有选择不阻止文本悬停预览。改变选择时关闭旧预览，重新悬停仍可预览；拖动、菜单、删除确认和折叠期间继续禁止预览。图片读取与复制拖动准备同时接入 Tauri 和独立桌面宿主通道，共用业务执行入口。

收集箱通过格子基类的 `collapsedSize` 指定 56px 折叠高度，宽度沿用展开宽度。非空时标题位置显示最新条目的标题与文本，不另加“收集箱”标题；空时仅显示“收集箱”。该例外为摘要提供正常字号的空间，其他格子的默认折叠高度仍为 28px。

收集箱是官方插件的桌面格子，使用与其他功能格子相同的公共外壳，参与贴边吸附以及与屏幕、其他格子的几何交互。工作区维护一份条目集合，多个格子呈现同一收集箱目录；格子保存尺寸、折叠和滚动。

展开态与折叠态共用标题右侧的排序、新建和折叠图标工具区。排序复用公共格子排序菜单，提供名称、时间两种单选项；列表直接呈现条目标题和摘要，不提供常驻编辑图标，置顶、删除使用条目右键菜单。可见工具区不提供恢复按钮，恢复最近删除保留在格子菜单，以保持列表紧凑。

应用内删除成功后，所有收集箱立即从会话列表移除该条目。删除事件携带文件名，接收方在重新读取文件前移除对应缓存；迟到的读取结果不得恢复已移除的缓存。只有外部删除或改名造成缓存路径失效时保留不可用项，应用内删除不产生不可用占位。

应用内重命名成功后，所有收集箱清除旧文件名的会话缓存，再按磁盘扫描结果呈现新名称，避免被误判为外部路径失效。共用 `collect-items-changed` 的 `deletedName` 字段表示需要移除的旧身份，不代表文件被删除或进入删除包；暂停刷新时也先清除旧身份，恢复刷新后读取新名称，迟到读取不得恢复旧身份。该规则仅用于应用已确认成功的重命名，不追踪外部重命名。

首次读取区分加载、失败重试与空集合，成功前禁用新建、恢复和内容投放；刷新保留现有列表及可见选择。`ComponentTile.acceptsDrop` 同时控制内容白名单和 `component-unready` 命中类型，原生现有目标解析仅接收 `component`，防止未就绪格子穿透投放。就绪变化通过已有命中图观察器发布，不新增轮询。

删除采用原生 HTML `dialog` 确认共享范围和类型数量，默认聚焦取消，提交期间通过 ref 防止重入；成功项取消选择，失败项保留。列表中的方向键只移动焦点，空格切换选择，`Ctrl+A` 仅在列表内生效；折叠关闭预览与条目菜单，停止未完成的拖动准备，隐藏选择不接收删除快捷键。原生模态命中及 OLE 生命周期尚未经真实环境验证。

设置页功能开关打开且还没有收集箱格子时创建一个；格子菜单的“新建收集项”复用工具栏的 `toolbar.create`，创建条目并打开编辑窗，工具未就绪时禁用，以保持两个入口的行为一致。列表先展示置顶收集项，其余按当前排序：名称用当前文件名（重命名后按新文件名排序，不按正文展示标题排序），时间用文件创建时刻且新的在上。条目标题取正文第一个标题，没有则用去掉 `.md` 的文件名。折叠态工具区提供新建、名称/时间排序与折叠/展开切换。有内容时把最新一条收集放在标题位置，展示一行标题和一行摘要并隐藏格子标题；无内容时显示“收集箱”并隐藏收集项摘要。展开后直接显示标题和最多三行纯文本摘要，保留原文换行，单击选择条目，双击、Enter 或右键打开文本编辑窗，条目右键菜单提供“打开”、置顶和删除。条目悬停 500ms 后显示无标题的 Markdown 只读预览，使用与编辑内容相同的渲染语义；鼠标离开条目立即关闭，切换条目、打开菜单、拖动、收起、失焦或销毁立即关闭。桌面格子用 `markdown-to-jsx` 语法树提取纯文本：标题去除，强调和链接保留文字，代码、表格单元格保留内容，图片使用 `[图片：说明]` 或 `[图片]` 占位；预览关闭原始 HTML 并使用图片占位。摘要与预览不改写源 Markdown。

展开与折叠摘要共用 `collectExcerpt`。摘要保留段内换行，以单换行分隔段落和代码块，压缩无意义空行，列表项及表格行分别换行，行内强调和链接不额外换行，避免 Vditor 保存的段落在纯文本提取时粘连。摘要仍最多提取 240 个字符；语法树不保留源文件空行数量，摘要只恢复紧凑块级分隔，不逐字复现连续空行。该规则仅用于摘要，不改变 Markdown 原文或完整导出正文，展开列表最多显示三行；折叠摘要只显示首行，后续内容省略，由公共标题组件限制行数和高度，避免文字溢出固定 56px 的格子。

监听配置目录下 `collect` 的文件变化并更新对应列表；外部删除或改名导致原路径不存在时，原条目显示不可用及对应错误状态，不因路径失效直接移除条目。该规则仅在当前运行会话保留用户可见的问题线索；不可用状态不保存到硬盘。每次启动重新扫描文件，以扫描结果建立列表，不追踪跨重启的外部重命名身份，也不恢复上次会话的不可用条目，以避免引入额外身份持久化。
