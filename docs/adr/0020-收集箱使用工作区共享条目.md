# 收集箱使用工作区共享条目

收集箱通过格子基类的 `collapsedSize` 指定 56px 折叠高度，宽度沿用展开宽度。非空时标题位置显示最新条目的标题与文本，不另加“收集箱”标题；空时仅显示“收集箱”。该例外为摘要提供正常字号的空间，其他格子的默认折叠高度仍为 28px。

收集箱是官方组件桌面格子，使用与其他功能格子相同的公共外壳，参与贴边吸附以及与屏幕、其他格子的几何交互。工作区维护一份条目集合，多个格子呈现同一收集箱目录；格子保存尺寸、折叠和滚动。

展开态与折叠态共用标题右侧的排序、新建和折叠图标工具区。排序复用公共格子排序菜单，提供名称、时间两种单选项；列表仅呈现条目标题和按需展开的摘要及编辑图标，置顶、删除使用条目右键菜单。可见工具区不提供恢复按钮，恢复最近删除保留在格子菜单，以保持列表紧凑。

应用内删除成功后，所有收集箱立即从会话列表移除该条目。删除事件携带文件名，接收方在重新读取文件前移除对应缓存；迟到的读取结果不得恢复已移除的缓存。只有外部删除或改名造成缓存路径失效时保留不可用项，应用内删除不产生不可用占位。

设置页功能开关打开且还没有收集箱格子时创建一个；格子菜单的“新建收集项”复用工具栏的 `toolbar.create`，创建条目并打开编辑窗，工具未就绪时禁用，以保持两个入口的行为一致。列表先展示置顶收集项，其余按当前排序：名称用当前文件名（重命名后按新文件名排序，不按正文展示标题排序），时间用文件创建时刻且新的在上。条目标题取正文第一个标题，没有则用去掉 `.md` 的文件名。折叠态工具区提供新建、名称/时间排序与折叠/展开切换。有内容时把最新一条收集放在标题位置，展示一行标题和一行摘要并隐藏格子标题；无内容时显示“收集箱”并隐藏收集项摘要。展开后直接显示标题和最多三行纯文本摘要，保留原文换行，单击整个条目打开收集项编辑窗，条目右键菜单提供“打开”、置顶和删除。条目悬停 500ms 后显示无标题的 Markdown 只读预览，使用与编辑内容相同的渲染语义；鼠标离开条目立即关闭，切换条目、打开菜单、拖动、收起、失焦或销毁立即关闭。桌面格子用 `markdown-to-jsx` 语法树提取纯文本：标题去除，强调和链接保留文字，代码、表格单元格保留内容，图片使用 `[图片：说明]` 或 `[图片]` 占位；预览关闭原始 HTML 并使用图片占位。摘要与预览不改写源 Markdown。

展开与折叠摘要共用 `collectExcerpt`。摘要保留段内换行，以空行分隔段落和代码块，列表项及表格行分别换行，行内强调和链接不额外换行，避免 Vditor 保存的段落在纯文本提取时粘连。摘要仍最多提取 240 个字符；语法树不保留源文件空行数量，摘要只恢复块级分隔，不逐字复现连续空行。源 Markdown 不变，展开列表最多显示三行；折叠摘要只显示首行，后续内容省略，由公共标题组件限制行数和高度，避免文字溢出固定 56px 的格子。

监听配置目录下 `collect` 的文件变化并更新对应列表；外部删除或改名导致原路径不存在时，原条目显示不可用及对应错误状态，不因路径失效直接移除条目。该规则仅在当前运行会话保留用户可见的问题线索；不可用状态不保存到硬盘。每次启动重新扫描文件，以扫描结果建立列表，不追踪跨重启的外部重命名身份，也不恢复上次会话的不可用条目，以避免引入额外身份持久化。
