# 隔离自有布局与 Explorer 图标布局

Desktop Tools 自有布局是桌面接管期间的布局权威，每个 Windows 虚拟桌面呈现同一完整桌面项目集合，共享围栏成员与项目归属，并独立保存围栏空间布局、未归类区域位置、组件和滚动状态；Explorer 原始布局用于首次导入和退出恢复。持久化布局包含显示器身份、虚拟桌面身份、围栏完整状态、组件状态和桌面项目引用，并采用原子写入、自动快照、手动备份、还原、当前 Schema 校验与上一可读版本恢复。每个已完成布局事务在空闲 `2 秒` 后合并生成自动快照，每个虚拟桌面保留最近 `20` 份；完整还原前生成的工作区快照计入发起还原时当前虚拟桌面的该配额。手动备份使用带 Schema 版本和完整性校验的 UTF-8 JSON，覆盖完整工作区并由当前 Windows 用户权限保护，适用于同一 Windows 用户配置文件；Windows Shell 命名空间继续提供项目事实。仅接受当前共享结构的 Schema，其他格式直接拒绝读取，不迁移、兼容读取、冲突合并或创建迁移备份。完整还原以事务方式替换工作区；当前 Windows 虚拟桌面全部保留，已有身份承接对应备份布局，备份中缺失的活动桌面创建为新 Windows 虚拟桌面，当前系统新增桌面获得默认布局。围栏允许重叠并持久化层级顺序，按下围栏标题、内容区或成员时将整个围栏置顶；点击置顶持久化并进入两秒合并快照，显式层级命令进入布局撤销历史。拖动悬停只显示临时目标预览，成功投放将目标围栏置顶并持久化层级，取消拖动恢复开始前层级。围栏锁定固定位置和尺寸，成员选择、打开、菜单、滚动、排序和归属操作继续可用；空围栏保留最后展开尺寸、布局模式、滚动位置、折叠状态和层级，折叠时显示标题，手动或悬停展开后恢复空内容区并继续作为项目拖放目标。折叠围栏标题持续接收项目投放，悬停 `400 ms` 展开内容区，展开前完成投放时按自动排序规则落位或追加到手动顺序末尾；成功投放后，标题悬停策略在指针与拖动项目离开 `600 ms` 后收起，手动展开和固定展开保持当前状态。解散围栏直接提交一个布局事务，成员以围栏内容区左上位置为组锚点，按当前视觉顺序进入原显示器未归类网格，逐项避让已有项目并保持连续排列；围栏锁定状态随围栏结束，撤销操作完整恢复围栏及成员状态。围栏移动和缩放采用自由定位，在距离工作区边缘或其他围栏边缘 `8 DIP` 内磁性吸附，按住 `Alt` 临时关闭吸附。围栏始终归属一台显示器，拖放结束时以围栏中心点所在显示器作为目标，中心仍在原显示器时将围栏约束回原工作区边界；跨混合 DPI 显示器迁移时保持逻辑尺寸和内部布局，按目标显示器 DPI 重新渲染，并将完整围栏约束在目标工作区。多个未归类项目作为一组跨显示器拖动时，全部项目归属投放点所在显示器，保持组内 DIP 相对偏移，以拖动锚点吸附目标网格；组与已有项目碰撞时优先执行位移最小的整体平移，剩余溢出项目按组内视觉顺序进入最近可用网格，相同位移距离依次按从上到下、从左到右和网格坐标裁决。目标网格容量不足时恢复拖动开始前的源布局、滚动位置和层级，保留完整选择集合并把焦点恢复到拖动锚点，同时显示“目标区域空间不足，项目已恢复原位”；按住 `Alt` 投放时允许项目在目标工作区内自由重叠定位。每个未归类区域独立维护自由定位项目层级；指针命中最上层项目，单击或拖动将项目置顶，键盘导航覆盖全部项目。项目层级随虚拟桌面布局持久化并进入自动快照，显式置顶命令进入布局撤销历史。选择集合来自多台显示器时，每个源显示器子组保持内部 DIP 几何，各子组按显示器视觉顺序组成连续块，并以实际拖动项目所在子组为落位锚点。未归类项目使用 Windows 图标水平与垂直间距指标构成不可见网格，指标按当前显示器 DPI 转换为 DIP；系统指标变化后重新计算网格项目布局，自由定位项目保持 DIP 坐标和相对重叠关系，并以最小位移约束到有效工作区。跨显示器移动时，自由定位项目保持 DIP 相对位置并按目标显示器 DPI 重新渲染。用户拖动默认吸附到网格，按住 `Alt` 临时自由定位，自动新增项目进入最近可用网格。自动排序提供名称、类型和修改时间规则，比较值来自 Shell 属性，名称使用 Windows 自然字符串顺序，主字段相同时依次使用系统显示名称和稳定项目引用裁决；属性暂缺项目位于末尾并保持已有稳定顺序，属性就绪后重新参与完整排序。Shell 属性变化通知在 `250 ms` 窗口内合并，窗口结束后执行一次完整重排，并以最小滚动量保持焦点项目可见。Shell 属性变化、重命名确认和属性就绪引起的自动重排作为派生布局结果直接更新布局并进入合并快照；用户发起的排序模式、排序字段和排序方向变更形成布局事务。项目进入自动排序围栏后立即按当前字段和方向重排整个围栏，切回手动排序时将当前自动排序结果固化为新的手动顺序。暂时无法解析的成员继续保留在围栏中并显示失效状态，可参与逻辑归属、排序和布局事务，重新解析后恢复当前顺序与布局。显示器断开期间，其内容临时投射到当前主显示器，持久归属与临时投射分别维护；显示器重连后恢复原位置，用户在投射期间主动移动的项目归属当前主显示器。
