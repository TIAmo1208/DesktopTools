# 使用独立 Rust 守护进程保护桌面接管

正式桌面宿主使用独立 Rust guardian 进程。guardian 在桌面接管前保存 Explorer 图标状态、Explorer 身份、接管阶段和宿主恢复信息，并通过注册表变化事件持续观察用户对 Windows 桌面图标可见性的修改，将最近一次用户设置作为恢复值。主进程退出、正常停止和设置变化使用同一无限等待集合；设置变化后重新注册通知，空闲期不使用超时轮询。启动失败、正常退出、`Ctrl+C`、主进程崩溃、Explorer 重启和兼容适配器运行时失效使用同一恢复契约；适配器失效时 guardian 恢复 Explorer 状态，主程序停止桌面接管、保留布局数据并在测试面板记录错误。业务状态、布局和 Shell 操作结果由主程序持有。
