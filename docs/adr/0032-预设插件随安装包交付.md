# 预设插件随安装包交付

## 状态与原因

原来的安装后复制、同版本跳过与按清单 ID 可选卸载决策不再适用，已被[插件默认目录与随包资源](0016-正式项目架构.md#插件默认目录与随包资源)取代。插件现在直接由安装包输出到安装目录下的 `plugin`，不再通过主程序复制到用户数据目录。

## 当前边界

- 安装包显式携带 `主题-青笺`、`AstrBot 状态`、插件文档与索引；仓库 `plugin/示例/` 中的开发示例不分发。
- 不再提供预设插件安装/卸载启动参数或独立清理勾选。真正卸载清除安装目录的 `plugin` 子树，包括用户放入的插件；更新模式不递归删除，升级保留用户新增插件，但会按打包清单覆盖同名文件。
- 显式配置到安装目录外的插件目录不由安装器复制或清理。插件自定义设置保存在配置目录，沿用配置保留规则。
