# 文件夹门户采用路径绑定与原生文件操作

文件夹门户提供指定目录的简易资源管理器能力，显示文件与子目录。门户按路径绑定真实目录，围栏继续管理逻辑归属；这一边界使用户能从桌面操作源文件，同时避免将移除格子或调整围栏归属解释为删除、移动源文件。

## 已确认决策

- 桌面右键的 Desktop Tools 菜单提供“创建文件夹门户”，调用系统目录选择器。选定后创建独立格子并保存绑定，取消不创建，不改变已有围栏成员。
- 设置页的“文件夹映射”二级菜单提供“新建文件夹映射”，复用系统目录选择器和工作区创建命令；已有映射以标题与绑定路径表格呈现，单击整行选中，右键提供重新映射路径和移除映射。
- 重新映射路径确认后只提交新的绑定目录并发布工作区快照；设置页等待下一次工作区快照更新表格，不额外主动读取目录或请求刷新。门户内容会话随新的绑定根目录重建，当前浏览路径和选择回到新根目录。移除映射复用工作区移除命令，只删除实例，不删除绑定目录。
- 设置页映射表使用条件分隔线：没有映射时不显示分隔线和空表格；存在映射时显示分隔线和表格。表格右键使用 `menu`，位置跟随鼠标并在窗口边缘避让。
- 支持系统选择器可选择的文件系统目录，包括磁盘根目录、移动硬盘和网络共享目录；不提供独立网络凭据管理。允许多个门户绑定同一路径并独立浏览。
- 目录改名或移动后不自动追踪，原路径失效时保留门户，通过“更换目录”重新指定。更换后回到新根目录、清空选择，保留外观和布局；“移除门户”只移除格子及绑定，不删除源目录或文件。
- 导航限定在绑定目录及其子目录，提供“上一级”和“返回根目录”，根目录禁用“上一级”。标题保持绑定目录名称，不提供独立标题重命名。内容顶部以折叠式面包屑显示相对路径；空间不足时折叠中间层级，祖先节点可点击，当前节点不可点击，省略号只表示折叠。完整路径可查看，不提供任意路径输入。
- 单击选中，连续点击形成的每一对点击打开项目；文件由系统默认程序打开，文件夹在门户内进入。实现不依赖浏览器一次性的 `dblclick` 计数，避免多次导航后浏览器点击计数跨目录继续递增导致后续双击失效。普通 `.lnk` 交给系统打开；目录链接解析目标在绑定目录内才在门户进入，否则打开资源管理器。
- 不保存上次浏览的子目录，程序重启显示绑定目录。子目录失效时返回绑定目录并提示原因；绑定目录不可访问时保留门户，显示异常、“重试”和“更换目录”。移动设备或网络恢复后可重试。
- 默认使用“小图标＋名称”的紧凑列表，可切换平铺，沿用围栏视觉规则；每个门户保存显示方式和排序设置。支持名称、类型、大小和修改时间的升降序，默认文件夹优先、名称升序，两种显示共用排序，不支持手动重排。
- 隐藏文件及受保护系统文件遵循资源管理器显示设置，不增加独立开关。
- 文件与文件夹使用系统原生上下文菜单。支持 `Ctrl/Shift` 多选、框选、`Ctrl+A/C/X/V`、`Delete`、`F2`；选择限定在门户当前目录，切换目录清空选择，粘贴目标为当前目录。
- 门户与围栏之间、门户之间的拖放采用 Windows Shell 的真实复制／移动语义及修饰键规则；无修饰键沿用 Shell 协商的默认移动效果，`Ctrl` 请求复制，`Shift` 请求移动。门户目标为当前目录，围栏目标为桌面目录。同目录拖放交给系统判断，不改变显示排序。普通围栏之间仍只改变逻辑归属。
- 自动监听当前目录，保留右键“刷新”和 `F5`，刷新尽量保留仍存在项目的选择与滚动位置。
- 门户遵循[统一工作区](0015-统一工作区且不区分虚拟桌面.md)和[统一格子操作](0018-共享格子外观并隔离布局撤销.md)。完整归属一台显示器，允许整体跨屏移动；断屏临时投射到主屏，重连恢复原归属及布局。

## 已确认交互分工

标题、导航空白和内容空白使用统一自绘格子菜单；按目录操作、显示排序、格子外观与布局、绑定管理分组，组间使用分割线。菜单提供当前目录的刷新、新建和粘贴，文件及文件夹项目使用 Windows 原生上下文菜单，不叠加格子菜单。菜单按真实可用能力启用或禁用，无首尾、连续或空组分割线。

新建沿用[Shell STA 与新建分流](0012-在专用STA运行时执行Shell操作.md)。每个门户同时只保留一个待命名项，临时位于当前可见内容顶部，名称主体默认选中、扩展名单独显示；Enter 明确提交、Esc 取消，失焦不创建，输入法组合期间不提交。成功后按排序归位；待命名项不参与打开、复制和拖放。导航或换绑先取消未提交项，已经提交的创建目标保持不变。

名称冲突、创建失败、刷新失败和其他操作提示通过统一消息管道通知，不在门户内容中增加独立提示文本块，也不抢占命名焦点。失败保留输入，不覆盖已有文件；部分操作失败通知说明实际结果、项目与原因。目录不可访问属于持续状态，门户仍保留原位状态、重试与更换目录入口。刷新失败时保留旧内容并标记过期，禁用依赖失效目录的写操作。切走后完成的操作反馈注明原目标目录，不强制跳回。

这一分工复用格子操作与消息呈现，区分当前目录的持续状态和一次操作的反馈，避免将移除门户误解为删除源文件。

## 实现边界

Shell 的目录身份校验、枚举、菜单、粘贴和拖放必须针对真实来源及目标目录，不能直接沿用固定桌面命名空间的业务限制。路径绑定不等同于用路径替代全部 Shell 项目身份。

当前门户通过工作区 `folderPortals` 集合保存独立身份、绑定路径、显示器归属、几何和外观字段。创建不检查路径是否已有门户，每次选定目录都追加独立实例。创建、几何更新和移除使用工作区事务及统一快照交付，前端不再维护独立路径轮询。移除仅删除实例记录，不删除绑定目录。目录浏览和选择仍属于实例内部会话状态。

当前外壳组合 `DesktopTileBase`、`DesktopTileHeader` 和 `DesktopTileViewport`，内容不再重复绘制标题和表面；菜单直接调用所属实例，禁止按绑定路径广播操作。外观独立提交，布局撤销保留当前折叠、标题显隐与按钮偏好，门户不提供独立标题重命名。

门户文件项目的原生菜单从当前目录的 `IShellFolder` 构建，复用现有 Shell STA、菜单 owner 和 `IContextMenu` 消息转发。普通 Delete 和 F2 使用同一 STA 的 `IFileOperation` 回收及重命名，并记录实际结果与撤销依据；删除不直接调用文件系统删除函数，不跟随链接删除目标。命令在操作前校验完整选择，拒绝父目录、路径分隔符和替代数据流名称。取消与部分失败保留仍存在的选择，命名失败保留输入并发送消息。

当前目录已使用 `ReadDirectoryChangesW` 监听，剪贴板、菜单、删除、重命名和门户 OLE 拖动源已接入。门户目标通过宿主命中图保留当前目录路径，并在专用 Shell STA 中以 `IFileOperation` 执行真实传输。门户路径安全校验可保留 `\\?\` extended-length 形式；进入 `SHCreateItemFromParsingName` 等 Shell 解析边界时必须转换为普通 DOS/UNC 解析路径。门户内 `Ctrl+Z/Y` 尚未接入统一撤销时间线，绑定目录自身删除时的即时失效通知尚未补齐；系统拖入门户与同名覆盖后的归属尚未经真实环境验证。

桌面菜单注册采用当前状态对应的固定动作全集替换产品专属 `shell` 子树，避免动作顺序变化残留旧序号。清理范围限定为 `HKCU\\Software\\Classes\\DesktopBackground\\shell\\DesktopTools\\shell`，不修改系统或其他程序菜单；注册表更新后通知 Explorer 重新读取菜单。

完整 UX 与 UI 均已确认，视觉约束见[文件夹门户](../design/文件夹门户.md)。原生菜单和真实文件操作属于首版，不能缩减为只读枚举。
