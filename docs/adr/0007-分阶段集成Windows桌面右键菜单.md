# 分阶段集成 Windows 桌面右键菜单

Milestone 1 分开实现桌面背景菜单与项目 Shell 菜单。Desktop Tools 接收桌面空白区域的右键输入，通过 Shell 操作代理显示原生桌面背景菜单，并追加新建围栏、编辑布局、刷新桌面项目和打开设置等产品操作；项目菜单通过完整 Shell 菜单接口显示选中项目的真实菜单，并追加加入围栏、移出围栏和编辑布局等产品操作。右键已选项目时保留当前选择集合并以全部选中项目构建多选菜单；右键其他项目时将目标设为唯一选择并构建单项菜单。产品命令使用全部选中项目的共同能力集合，命令覆盖整个选择集合时启用并提交为一个布局事务。菜单键或 `Shift+F10` 打开的项目菜单锚定焦点项目，围栏菜单锚定标题，桌面背景菜单使用当前显示器内最后指针位置，并以工作区左上区域作为回退坐标。项目菜单使用专用原生 owner HWND，转发 owner-drawn 菜单、动态子菜单和菜单字符消息。Milestone 1 锁定 x64 主程序与 x64 Shell 扩展；x86 Shell 扩展进入后续兼容范围，Windows 11 现代菜单进入后续发行阶段。
