# 浮岛卡内收起与卡片外滚动条槽

## 背景

浮岛展开后所有卡一次全高呈现：收集箱一多就把整屏占满，用户想先看别的卡只能先收起整个浮岛。桌面格子早就有逐卡「折叠 / 展开」按钮与折叠态摘要，浮岛卡缺少同一层级的收起入口。

同时展开态滚动条是覆盖在卡片右内边距上的，视觉上像贴在卡片边缘；用户要求它和卡片分开、放到卡片外的独立槽里，并要求「卡片 + 槽 + 槽内间距」整片区域都不触发移出退回。

展开动画还有一个已知问题：收集箱首次展开时先按加载态实测一次宽度，条目读出来后再提交一次更宽的窗口，观感是「先展开、再调宽」。

## 决策

- 展开态每张岛卡右上角提供 `28 × 28` 收起/展开按钮（图标 `16`，沿用桌面格子的 `fence-toggle-collapse.svg` / `fence-toggle-expand.svg`，悬停或聚焦时出现，带 `aria-expanded`）。收起只改该卡内容高度，不改卡片顺序、不写工作区、不改变浮岛三态。
- 收起态逐卡保存在偏好 `islandCardCollapsed`；卡片二级页的「记忆收起状态」开关（`islandCardCollapseMemory`，缺省开启）关闭后不读也不写该卡的收起态，回落到默认值：收集箱默认收起（`islandCollectCollapsedDefault`），其余卡默认展开。
- 收集箱收起时只列最近 `islandCollectCollapsedCount` 条（`3` / `5` / `10`，默认 `3`），保持 `300 DIP` 内容宽与三列混排，条目仍可拖出；加载态与空态也占同一内容宽，首次实测即得到最终宽度，展开动画结束后不再二次调宽。
- 同态重测（内容增减、卡内收起）提交自然目标窗口并让窗口随内容收缩；只有切态动画期间保留入态并集窗口。「展开终态保留入态并集」的旧语义只约束动画本身。
- 展开滚动条移到卡片外的槽里：槽宽 `16 DIP`（`4 DIP` 间距加 `12 DIP` 轨道），展开窗口在内容宽之外加宽同样的宽度，卡片本体宽度不变；贴右边时槽在卡片左侧，卡片仍贴边。整条槽（含未出条时的同一条槽）归浮岛命中且不触发移出退回，按住滑块不退出展开。
- 收集箱拖出结束后读一次原生光标位置（`island_cursor_inside`），按真实光标是否在岛内决定是否回落常态；OLE 拖动期间页面收不到 `pointerout`，不能只等悬停事件。

## 原因与职责边界

收起是卡内的呈现密度，不是第二套浮岛状态：三态仍由窗口层与页面状态机维护，收起只影响卡片内容与随后提交的窗口高度。把它放进偏好而不是运行期临时状态，是为了和桌面格子的折叠语义一致，也让「记忆」开关有明确作用域。

滚动条槽是窗口几何的一部分：轨道必须在卡片外，窗口就要为它让出宽度；命中判定与渲染共用同一份 `islandScrollGeometry`，避免「看得见但点不到」或「看不见却能退回」的分歧。

## 后果

- 偏好新增四个字段（收起表、记忆表、收集箱默认收起、收起条数），设置页卡片二级页新增对应行；旧配置缺字段时按默认值补齐。
- 展开窗口宽度等于内容宽加 `16 DIP`；固定视口带宽仍是 `420 DIP`，覆盖最大卡宽 `360` + 槽 `16` + 刘海 `24`。
- 新增 transport 命令 `island_cursor_inside`，与窗口拖动共用同一物理客户区命中规则。
- 收起态高度变化会触发一次窗口重测提交，动画仍受界面动画与减少动效偏好约束。

## 待验证

- 真机确认收起/展开按钮的命中区、图标状态与悬停出现时机，以及收集箱收起后的条数与拖出行为。
- 收集箱首次展开（条目尚未读到）时窗口宽度是否一次到位，不再出现二次调宽。
- 拖出到 Explorer、桌面与其他应用后，岛是否按光标真实位置回落；拖回岛内释放时是否保持展开。
- 滚动条槽在四边、两形态下的位置、间距与退回表现。
