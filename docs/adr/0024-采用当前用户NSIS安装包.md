# 采用双安装模式 NSIS 安装包

## 决策与原因

Windows x64 测试安装包采用 Tauri 自带的 NSIS 打包路径和标准安装界面，安装时由用户选择“仅为我”或“所有用户”。“仅为我”安装到当前用户目录，不请求 UAC；“所有用户”自动请求 UAC，并在 x64/arm64 架构使用 64 位 Program Files。复用现有图标，不引入 MSI、自动更新、签名或 GitHub 发布流程。

安装包包含同次构建的 `desktop-tools.exe` 与 `desktop-tools-guardian.exe`，两者安装在同一目录。构建必须启用 `custom-protocol` 并内嵌前端。保留纯程序构建入口，另设安装包构建入口。

缺少 WebView2 Evergreen Runtime 时使用 Tauri 的联网引导安装方式；检测同时读取 HKLM 与 HKCU，避免两种安装模式重复安装已有运行时。无网络且缺少运行时的机器不能完成依赖安装。

## 安装与卸载边界

NSIS 的 `MultiUser.nsh` 提供安装模式选择页并设置 Shell 上下文。“仅为我”默认安装到 `$LOCALAPPDATA\Desktop Tools`，产品卸载登记写入 HKCU；“所有用户”默认安装到 `$PROGRAMFILES64\Desktop Tools`，产品卸载登记写入 HKLM。安装位置、快捷方式及产品卸载登记均按选择后的上下文处理，卸载器通过 `MULTIUSER_UNINIT` 恢复相同上下文。旧 WiX 安装只在 HKLM 枚举；同模式 NSIS 旧版本通过 `SHCTX` 查找，因此安装器只覆盖或卸载用户本次所选范围内的 NSIS 版本。

覆盖与卸载前复用 `--desktop-menu exit` 请求正常退出，并在有限时间内检查当前用户的主程序与 guardian 均已停止。未退出、退出命令失败或存在无法定位安装程序的当前用户运行实例时中止，不强杀进程。`FindProcessCurrentUser` 不检查其他登录用户；所有用户安装或卸载仍只保护发起操作的当前登录用户，管理员需先确认其他会话没有运行 Desktop Tools。检查只在安装与卸载阶段短暂执行，不增加常驻监听。

检测到已安装版本时，重装页按版本关系分支：同版本与升级提供互斥的“添加/重新安装组件”（默认勾选）和“卸载 Desktop Tools”两个勾选项，勾选卸载时先运行旧卸载器再安装，否则直接覆盖安装——只覆盖同名文件并重写卸载登记与卸载器，旧版本独有的文件会保留；降级只提供卸载确认，未勾选时“下一步”不可用，勾选后先卸载再安装。默认覆盖是为了让同版本重装与升级不再依赖卸载器，避免卸载失败中断安装，同时保留用户数据与桌面菜单登记；代价是旧版本遗留文件不会被清理。

插件资源由 Tauri 资源映射直接输出到 `$INSTDIR\plugin`，不提供预设复制命令或独立清理勾选；真正卸载递归删除该子树（包括用户新增插件），`$UpdateMode=1` 时不递归删除，外部显式插件目录不触碰（见 [ADR-0016](0016-正式项目架构.md#插件默认目录与随包资源)）。

安装完成后通过 `--register-desktop-menu` 登记当前程序位置；卸载在删除程序前通过 `--unregister-desktop-menu` 移除产品菜单。桌面菜单实现固定写入 HKCU，因此即使选择“所有用户”，菜单也只对执行安装的当前用户可见；这与写入 HKLM 的产品卸载登记不同。保留用户配置、布局、收集箱、自定义数据目录与日志；不增加用户数据清理逻辑。

## 受控模板升级

`src-tauri/installer/installer.nsi` 取自 `tauri-cli-v2.11.4` 的 NSIS 模板。升级 Tauri CLI 后必须重新对比上游模板并回放、核对以下定制：

- 双安装模式的 `MultiUser.nsh` 初始化、选择页、UAC、默认目录、`SHCTX` 登记和卸载上下文；
- 重装页的同版本、升级、降级选项，以及旧 WiX 的 HKLM 枚举；
- `hooks.nsh` 的当前用户运行中检测、正常退出请求、桌面菜单注册与移除；
- 插件资源输出到 `$INSTDIR\plugin`，真正卸载递归删除、`$UpdateMode=1` 保留插件的分支；
- WebView2 的 HKLM/HKCU 检测与联网引导安装策略。

核心应用采用 `GPL-3.0-or-later`，随包提供许可证及第三方许可文件。本次产物为未签名测试安装包，不改变已签名官方发行版的定义；生产签名与公开发布另行落实。

安装生命周期、两种账户范围的覆盖安装与卸载、WebView2 依赖环境、用户数据保留及桌面菜单恢复尚未经真实环境验证；构建成功不等同于功能可用。
