# 固定 Windows 应用身份

产品显示名固定为 `Desktop Tools`，仓库规范名固定为 `desktop-tools`。Windows 应用使用 Tauri identifier `io.github.tiamo1208.desktop-tools`、Windows Package Name `DesktopTools`、Publisher Display Name `Desktop Tools Project` 和 MSI Manufacturer `Desktop Tools Project`。这些稳定标识承载安装更新连续性和 WebView 数据目录；MSIX Publisher DN 由 Milestone 4 的 Microsoft Store 身份或生产签名证书 Subject 提供，并以签名渠道给出的精确值锁定。
