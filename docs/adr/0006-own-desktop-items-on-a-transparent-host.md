# 在透明桌面宿主中接管桌面项目

Milestone 1 由 Desktop Tools 自绘并接管完整桌面项目集合的呈现与交互；Explorer 提供桌面命名空间、Shell 操作和恢复兜底。公开 Windows 契约直接提供 Shell 文件操作、真实菜单、系统剪贴板和 OLE 拖放语义；React 以 Windows 系统交互为选择、键盘和焦点验收基线，并负责选择集合、选择锚点、焦点容器、桌面焦点目标、框选、命中、布局、排序、滚动和逻辑拖动。最近获得项目焦点的项目成为选择锚点，范围选择覆盖焦点容器内的完整逻辑顺序；`Tab` 在未归类区域、围栏标题和组件之间移动高层焦点，方向键在容器内部移动项目焦点。单击围栏标题、围栏空白内容区或桌面空白区域时，React 清空项目选择并把焦点交给对应语义目标。菜单键与 `Shift+F10` 由 React 根据桌面项目、围栏或桌面背景焦点选择语义菜单，再由对应产品边界提供命令。重叠围栏按持久层级判定输入和拖放，层级最高的可见语义交互区域接收操作；上层围栏语义区域外的坐标继续命中下层围栏，上层语义区域内部的视觉透明像素继续归上层处理。拖动悬停使用临时目标预览并保持持久层级，成功投放后目标围栏置顶，取消拖动恢复开始前层级。全部桌面宿主通过真实像素、最小输入和 guardian 准备检查后隐藏 Explorer 图标视图并提交接管；准备失败时关闭宿主并保持 Explorer 原始状态。ADR 0010 的 Explorer 持续渲染方案由本决策取代。
