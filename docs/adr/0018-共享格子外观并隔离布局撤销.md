# 共享格子外观并隔离布局撤销

## 尺寸约束

所有格子的持久展开边界采用 `80 × 48 DIP` 公共底线，前后端解码、创建、修改及保存的展开高度使用同一数据规则。围栏内容下限不再作为后端数据有效性条件；这样公共几何不依赖某类内容，也无需 Rust 复算字体或 DOM 布局。内容层通过可选 `minimum` 提供外框下限，公共层校验覆盖值并保证它不低于数据底线，鼠标、键盘、吸附和跨屏消息使用同一有效值。

围栏内容视口下限为 `164 × 110 DIP`，包含内容内部留白；内容层叠加外壳每侧 `1 DIP` 边框和 `1 DIP` 留白，仅固定标题再加 `28 DIP`，得到 `168 × 142 DIP` 或 `168 × 114 DIP` 外框下限。标题切换更新有效呈现和交互边界，不自动写回布局；恢复或更小的合法保存尺寸同样按内容下限呈现。音乐继续沿用自身测量与占位计算，不将动态内容尺寸写入后端契约。

临时投射优先适应实际视口，允许有限正尺寸小于持久底线；前后端分别校验投射与持久矩形。投射不污染保存的展开边界和撤销历史，用户提交时才形成满足数据底线的权威布局。公共默认创建尺寸、显式覆盖能力及 `collapsedSize` 保持独立，不新增迁移或后台纠正写入。较小视口、混合 DPI 和标题切换的原生呈现效果尚未经真实环境验证。

## 外壳与内容职责

已确认采用 `features/tiles/DesktopTileBase` 作为唯一公共格子入口，内部组合几何与展开 Hook、菜单、输入捕获和标题拖动；业务宿主提供稳定身份、权威边界、外观、最小尺寸、显示器环境、焦点及类型化提交回调，不分别注册几何监听。公共几何算法位于 `tiles/tileGeometry`，不依赖围栏内容目录。选择这一边界是为了让围栏、门户和官方内容遵守相同取消与提交生命周期，不统一不同业务的后端身份或命令。

活动几何的 Escape 在捕获阶段优先取消，覆盖原生输入准备、指针捕获、跨屏释放等待、失焦及卸载；无活动几何时保留输入框和内容快捷键。领域提交开始后不承诺撤回已提交动作。公共入口接收 `locked` 并限制位置与尺寸，不限制内容操作；当前持久化契约和 UI 未提供锁定字段及入口，产品锁定功能仍待单独确认。

公共标题骨架位于 `tiles/header`，负责文本、摘要呈现、编辑、显隐、按钮命中及拖动边界，保留 `commands` 工具区插槽。最新收集项与摘要计算留在收集箱，公共层不识别 `componentId` 或访问条目。围栏、门户、收集箱、音乐、时间和 Debug 分别归入 `tile-content`；工作区装配及跨屏 OLE 协调留在 `workspace`，插件注册、能力及失败隔离留在 `components`。

移动在开始时捕获一次完整结构化静态帧，本屏与跨屏复用；缩放继续实时排版。沿用现有跨屏会话与转发协议，结束取消待发送帧并释放预览，迟到消息不得恢复已结束会话。内容样式随组件归属，不覆盖公共外框操作。该决策不改变既有视觉、Shell 文件操作、Schema 或插件能力契约；多屏、取消时序及性能尚未经真实环境验证。

悬停或跨屏拖入触发的临时展开在公共外壳中提升显示层级，高于当前焦点格子，低于菜单与拖动预览，避免先前点击的格子遮挡临时展开内容。临时展开结束后恢复原显示层级，不改变键盘焦点、持久布局顺序或撤销历史。

公共菜单通过 React context 保留所属格子身份，包含通过 Portal 呈现的格子菜单、收集项菜单及二级菜单。格子表面或所属菜单被悬停时，已开启自动展开的折叠格子保持临时展开；离开整个范围或菜单销毁后释放对应悬停状态，不将“菜单仍打开”等同于持续悬停，不修改折叠偏好。菜单外点击、焦点转移、窗口失焦及打开另一菜单关闭当前菜单组，父子菜单间转移保留菜单。独立宿主复用现有前台状态事件处理外部前台和锁屏，不增加轮询；订阅仅存活于菜单打开期间，迟到注册立即释放。透明宿主跨窗口和跨屏实际输入尚未经真实环境验证。

公共外壳通过 `collapsedSize` 接收调用方指定的折叠宽高；省略宽度时沿用展开宽度，省略高度时使用 28px。收集箱指定 56px 折叠高度（28px 的两倍），给最新标题与文本保留阅读空间；空收集箱使用相同高度。该尺寸同时用于可见外框、拖动、吸附和跨屏预览，展开后恢复已保存的展开尺寸，不把折叠尺寸写回布局。

已确认的项目约束：没有特殊说明时，所有桌面格子使用同一套移动、尺寸调整、折叠、展开策略、锁定和外观操作。内容类型不构成例外依据；门户锁定只限制位置与尺寸，内容操作继续可用，折叠后展开继续显示当前目录。公共外壳接入本身不代表全部行为已经验证。

已确认设计：桌面格子采用公共外壳与差异化内容组合，标题栏作为可选组件，工具区由内容定制。文件围栏使用完整标题工具，时钟、Debug、音乐只提供折叠/展开按钮。收集箱使用同一公共外壳与贴边吸附；折叠时有内容则把最新一条收集放在标题位置，显示一行标题和一行摘要并隐藏格子标题；无内容时显示“收集箱”并隐藏收集项摘要。折叠态工具区保留新建、按名称或时间排序以及折叠/展开切换。外壳复用不改变文件与组件的业务身份和能力边界。

同一格子的外观设置统一保存，不因位置变化改变，也不进入撤销/重做。空间布局继续遵循既有规则，布局恢复不得覆盖当前共享外观。该边界避免把调整位置和恢复外观绑定为同一操作；外观需按稳定格子身份保存，不按虚拟桌面创建副本。

未设置时使用默认值，不实现历史版本兼容或迁移逻辑。现有围栏数据及组件私有状态继续保留。

当前实现通过 `DesktopTileBase`、`DesktopTileHeader`、`DesktopTileViewport`、`DesktopTileMenu` 和公共几何交互接入围栏、文件夹门户、收集箱、时钟、Debug、音乐。公共外壳统一执行折叠高度过渡，公共视口同步淡出并停止命中；组件折叠隐藏视口但保留挂载，时钟按实际展开状态停止或恢复活动时间订阅，音乐和其他内容沿各自既有生命周期运行。`followSystemReducedMotion` 为 `true` 时由 Windows 减少动态效果状态决定实际动画并保留 `interfaceAnimations`；为 `false` 时直接使用 `interfaceAnimations`。拖动和尺寸调整不经过折叠过渡。未组合标题栏的外壳不提供标题及折叠菜单。

当前 `set-tile-appearance` 只修改围栏或功能格子的一个字段，领域校验悬浮标题与按钮偏好的互斥条件。工作区持久载荷的 `layout.tileAppearances` 按 `fence:<id>` 或 `component:<instanceId>` 保存唯一外观；文件夹门户通过 `set-folder-portal-appearance` 保存相同公共字段。原子保存成功后才发布快照，Tauri 与 WebView2 共用入口。布局历史恢复使用当前外观及组件私有状态，外观命令不清空布局或 Shell 重做分支。

公共维护约束：跨屏格子移动释放时通过目标宿主读取可见格子边界后再吸附；原生输入建立及跨屏边界读取期间支持取消；排序按钮同步 `aria-expanded`；目标格子拒绝文件投放时不向下层围栏或背景穿透。
