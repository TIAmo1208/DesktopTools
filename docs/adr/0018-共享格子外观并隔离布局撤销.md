# 共享格子外观并隔离布局撤销

已确认设计：桌面格子采用公共外壳与差异化内容组合，标题栏作为可选组件，工具区由内容定制。文件围栏使用完整标题工具，时钟、Debug、音乐只提供折叠/展开按钮。外壳复用不改变文件与组件的业务身份和能力边界。

同一格子的外观设置跨虚拟桌面共享，不因跨桌面移动改变，也不进入撤销/重做。空间布局继续遵循既有规则，布局恢复不得覆盖当前共享外观。该边界避免把调整位置和恢复外观绑定为同一操作；外观需按稳定格子身份保存，而不是作为每个虚拟桌面布局的独立副本。

未设置时使用默认值，不实现历史版本兼容或迁移逻辑。现有围栏数据及组件私有状态继续保留。

当前实现通过 `DesktopTileBase`、`DesktopTileHeader`、`DesktopTileViewport`、`DesktopTileMenu` 和公共几何交互接入文件围栏、时钟、Debug、音乐。组件折叠只隐藏视口，不卸载内容或停止订阅。未组合标题栏的外壳不提供标题及折叠相关菜单。

`set-tile-appearance` 只修改一个字段，领域校验悬浮标题与按钮偏好的互斥条件。工作区持久载荷中的 `tileAppearances` 按 `fence:<id>` 或 `component:<instanceId>` 保存唯一共享外观；逐桌面快照使用投影。原子保存成功后才发布快照，Tauri 与 WebView2 共用入口。布局历史恢复及跨桌面投影使用当前共享外观，外观命令不清空布局或 Shell 重做分支。

代码已通过前端构建和 Rust 编译；按当前任务要求未运行测试或真实桌面验收。当前实现还保留以下待验证边界：跨屏格子移动释放时通过目标宿主读取可见格子边界后再吸附；原生输入建立及跨屏边界读取期间支持取消；排序按钮同步 `aria-expanded`；目标格子拒绝文件投放时不向下层围栏或背景穿透。
