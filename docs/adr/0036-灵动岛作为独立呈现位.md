# 灵动岛作为独立呈现位

## 背景

需要一处不依赖透明桌面宿主的桌面常驻胶囊：屏幕边缘常驻一个不抢焦点的独立窗口，承载插件与官方能力的卡片，随时可点。桌面格子由透明桌面宿主承载，进入工作区布局、撤销与配额体系，不适合承载这种常驻辅助位；岛因此是一条独立呈现路径。

偏好契约、清单 `island` 字段与合成岛实例、纯 DIP 几何函数与原生岛窗口层已落地；岛页面只挂 `about:blank` 占位 WebView，视觉与交互未交付。

## 决策

### 独立窗口与独立来源

- 岛是独立原生窗口与独立 WebView 来源，不是桌面宿主屏的组成部分：窗口样式为 `WS_POPUP`，扩展样式为 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，不进任务栏与 Alt+Tab，不抢焦点（`WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`）。
- 岛页面走独立协议 `desktop-tools-island`，复用既有来源白名单与命令通道；只有岛协议自身的来源可以调用既有命令边界。
- 窗口按偏好 `islandEnabled` 懒建，关闭或退出时幂等销毁；未收到首个 `set_island_state` 提交前保持隐藏。置顶断言挂在共享前台事件（`desktop-refresh-policy-changed`）上，不启动轮询；前台出现全屏、最大化覆盖工作区或锁屏时隐藏，锁屏独立于 `islandHideOnFullscreen` 开关。恢复显示使用 `SW_SHOWNOACTIVATE`，不收回已断言的置顶。

### 不进工作区快照

岛不持有布局、不参与撤销、不在工作区快照内：

- 位置与顺序只存在于偏好：`islandEdge`（`top`/`bottom`/`left`/`right`，空串表示顶部居中默认位，不固化为显式值）、`islandOffset`（沿贴边方向的 DIP 偏移）、`islandCardOrder`（岛卡展开态排列顺序）。
- 岛卡实例是运行时按清单与 `islandCardOrder` 合成的实例，实例标识 `island.<pluginId>`；不创建工作区实例、不参与 `maxTiles` 配额、不进入布局撤销历史。
- 拖动落点沿统一偏好保存路径持久化，不写任何布局事实。

### 三态模型

- 岛同一时刻只处于一种状态：常态（`collapsed`）、hover、展开（`expanded`）；不存在多态叠加。
- 状态由岛页面经 `set_island_state` 提交，一次提交携带该状态的屏幕 DIP 窗口联合盒 `windowBox` 与窗口内局部卡片区域 `cards`；后端不为岛维护状态机。
- 指针移出即回落常态；常态必须恰好一个胶囊卡片区域，卡片数量上限 128。
- 展开态不允许直接拖动，必须先回落常态；`begin_island_drag` 拒绝非常态提交。

### 形状级穿透

- 命中区域由 `SetWindowRgn` 从卡片区域合成：每张卡片是带圆角的 `CreateRoundRectRgn`，多卡片经 `CombineRgn`（`RGN_OR`）合并；区域外像素不属于窗口，输入天然穿透到桌面。
- 卡片区域由页面以 DIP 提交，后端按当前主屏缩放一次性转成物理像素；窗口盒超出主屏工作区、卡片越界或圆角非法时拒绝提交。
- 一次状态切换只提交一次区域与一次物理窗口盒，不逐帧调整 HWND。
- 切态提交任一原生步骤失败时按 fail-closed 处理：岛清空几何并隐藏，不保留新旧混合状态；此后必须先由页面重新提交常态，岛才能拖动。

### 贴边与展开方向

- 几何全部是纯 DIP 函数，不调用 Win32：最近边吸附（按胶囊中心，等距按上、下、左、右优先）、沿边偏移夹紧、贴边放置、空偏好顶部居中、展开方向（指向工作区内部）与态联合盒。
- 首次状态提交按偏好落位；之后的窗口盒由页面提交，后端夹紧在主屏工作区内。
- 主屏是本期唯一目标屏，工作区取主屏 `rcWork` 的 DIP 表达。

### 原生拖动

- 常态下页面调用 `begin_island_drag`：宿主先 `ReleaseCapture()`，再向岛窗口发送 `WM_NCLBUTTONDOWN`（`HTCAPTION`），交给 Windows 原生移动循环；不重写移动与命中逻辑。
- 原生移动循环结束（`WM_EXITSIZEMOVE`）后按胶囊中心吸附到最近边，夹紧偏移后回位；落点经 `SettingsState::update` 在偏好提交锁内只改 `islandEdge` 与 `islandOffset` 两个字段（不整份覆盖其他偏好），`islandEnabled` 为假时不写。落点带开始序号，旧序号任务被丢弃，不覆盖更新的落点。
- 拖动全程不激活窗口。

### 材质回退

- 岛窗口背景使用 DWM 系统材质：`DWMWA_SYSTEMBACKDROP_TYPE` 取 `DWMSBT_TRANSIENTWINDOW`，帧延伸铺满客户区；材质可用时不再绘制类画刷纯色底。
- 材质不可用时回退到类画刷纯色背景，只记 WARN，不使建窗失败。

### 岛卡与卡片顺序

- 插件岛卡按清单 `island` 字段声明，与桌面格子共用同一 `plugin:slot` 入口分派和外壳契约；官方与本地插件走同一字段。字段规则见 [ADR-0029](0029-插件来源与范围.md)。
- 岛卡顺序只记录在偏好 `islandCardOrder`，调整来源只有拖动一种，不设其他入口。
- 该偏好在反序列化时规范化：只保留带 `official.` 或 `plugin.` 前缀的非空标识，去重、最多 32 条；被丢弃条目只记总数日志。

## 后果

- 岛与桌面格子是两条独立呈现路径：同一插件可以同时有桌面格子和岛卡；格子配额、布局撤销与工作区快照规则都不约束岛，岛也不反哺工作区。
- 复用既有命令边界与前台事件，岛只新增 `set_island_state`、`begin_island_drag` 两条命令，不新增事件或集合。
- 材质、穿透与置顶都依赖系统行为，真机表现按待验证清单确认。
- 主屏专用使多显示器用户只在主屏看到岛，这是本期接受的边界。

## 待验证

- 透明 WebView2 与 DWM 材质、`SetWindowRgn` 在真机上的共存表现：区域边缘、材质透出、输入穿透与置顶抑制。
- 三态切换、hover 回落与拖动吸附的端到端行为依赖岛页面提交状态，页面落地后随验收验证；几何与窗口层单测不替代真机验证。

## 范围之外

- 岛页面与卡片视觉：三态 UI 与卡片内容呈现；当前只挂 `about:blank` 占位页。
- 设置页岛分组：岛开关、贴边、偏移、全屏隐藏与岛卡顺序的设置界面。
- 歌词来源与歌词卡片内容。
- 多显示器支持：本期只使用主显示器，扩展到其他显示器须另行决策。
- 卡片排序交互的 UX/UI 细节：本 ADR 只确定排序来源唯一为拖动，界面呈现不在此决定。
