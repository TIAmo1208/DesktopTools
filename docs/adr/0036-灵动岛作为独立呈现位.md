# 灵动岛作为独立呈现位

## 背景

需要一处不依赖透明桌面宿主的桌面常驻胶囊：屏幕边缘常驻一个不抢焦点的独立窗口，承载插件与官方能力的卡片，随时可点。桌面格子由透明桌面宿主承载，进入工作区布局、撤销与配额体系，不适合承载这种常驻辅助位；岛因此是一条独立呈现路径。

偏好契约、清单 `island` 字段与合成岛实例、纯 DIP 几何函数与原生岛窗口层已落地。岛协议已加载 `island=1` 的真实前端入口并注入同源原生桥；岛卡快照、状态桥与独立三态页面已接通；页面实测尺寸后串行提交几何，常态与 hover 空白可触发原生拖动，展开态拖动卡片本体只保存偏好顺序。设置入口由设置页的一级「岛」页与卡片二级页实现；原生视觉与交互仍需真机验收。

## 决策

### 独立窗口与独立来源

- 岛是独立原生窗口与独立 WebView 来源，不是桌面宿主屏的组成部分：窗口样式为 `WS_POPUP`，扩展样式为 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，不进任务栏与 Alt+Tab，不抢焦点（`WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`）。WebView2 后代窗口递归合并 `WS_EX_NOACTIVATE`，保留其余扩展样式；创建后、子窗口创建/销毁通知后与导航完成后重新应用，不拦截页面点击或键盘消息。建 WebView 时关闭 Wry 默认的主动聚焦。WebView2 点击仍可能绕过 `WM_MOUSEACTIVATE` 激活宿主：左键按下期间的 `WA_ACTIVE`/`WA_CLICKACTIVE` 记录原窗口，延后至消息栈退出最多恢复一次；无效目标、原生拖动或前台已被用户切走时放弃。该路径是前台恢复补偿，不是系统级禁止显式激活的保证。
- 岛页面走独立协议 `desktop-tools-island`，复用既有来源白名单与命令通道；只有岛协议自身的来源可以调用既有命令边界。
- 窗口按偏好 `islandEnabled` 懒建，关闭或退出时幂等销毁；未收到首个 `set_island_state` 提交前保持隐藏。置顶断言挂在共享前台事件（`desktop-refresh-policy-changed`）上，不启动轮询；锁屏时恒隐藏；开启 `islandHideOnFullscreen` 时仅独占全屏隐藏，普通应用最大化、覆盖工作区或覆盖整屏不触发岛隐藏。恢复显示使用 `SW_SHOWNOACTIVATE`，不收回已断言的置顶。

### 不进工作区快照

岛不持有布局、不参与撤销、不在工作区快照内：

- 位置与顺序只存在于偏好：`islandEdge`（`top`/`bottom`/`left`/`right`，空串表示顶部居中默认位，不固化为显式值）、`islandOffset`（沿贴边方向的 DIP 偏移）、`islandCardOrder`（岛卡展开态排列顺序）。
- 岛卡实例是运行时按清单与 `islandCardOrder` 合成的实例，实例标识 `island.<pluginId>`；不创建工作区实例、不参与 `maxTiles` 配额、不进入布局撤销历史。
- 拖动落点沿统一偏好保存路径持久化，不写任何布局事实。

### 三态模型

- 岛同一时刻只处于一种状态：常态（`collapsed`）、hover、展开（`expanded`）；不存在多态叠加。
- 状态由岛页面经 `set_island_state` 提交，每份静默态或动画帧均携带完整 `{ state, windowBox, cards }`：屏幕 DIP 窗口联合盒与局部卡片区域同步变化，不新增动画命令或事件；后端不维护三态状态机。
- 常态与 hover 的指针进出使用 `250ms` 消抖，hover 非交互区单击展开；按钮、输入与插件交互区域保留自身行为。常态必须恰好一个胶囊卡片区域，卡片数量上限 128。
- 常态与 hover 均允许调用 `begin_island_drag` 进入原生窗口拖动；展开态禁止拖动窗口，必须先收起，只允许拖动卡片本体调整顺序。
- 常态胶囊朝向由贴边推导：贴上下为横向胶囊，贴左右为竖向胶囊；hover 与展开始终横向，卡片纵向堆叠，贴边锚点保持不变，整块向工作区内部生长。竖向胶囊与横向胶囊共用同一内边距，因此宽度等于媒体图直径加两侧内边距。
- 三态尺寸、内边距、圆角与媒体图取值以[灵动岛](../design/灵动岛.md)为准，本 ADR 不重复数值。

### 透明矩形窗口与命中边界

- 岛原生窗口始终为透明矩形：空类画刷，`DwmEnableBlurBehindWindow` 使用空区域并开启合成，`DwmExtendFrameIntoClientArea` 四边取 `-1`。不设置系统材质，也不绘制纯色回退画刷。
- 可见卡片圆角与抗锯齿由页面 CSS 绘制，不调用 `SetWindowRgn` 裁切，也不使用 `WM_NCHITTEST` 做形状穿透。矩形窗口范围内的圆角外透明像素与卡间隙仍属于岛命中区，点击不会落到后方桌面或应用；透明是像素表现，不代表输入穿透。
- 卡片几何仍由页面以 DIP 提交，用于校验和拖动锚点，不生成原生区域；后端按主屏缩放设置矩形窗口盒，窗口盒超出主屏工作区、卡片越界或圆角非法时拒绝提交。
- 静默状态去重后一次提交；动画期间允许按帧提交同步的卡片几何与物理窗口盒，单次三态切换时长不超过 `260ms`、帧率不超过 `60fps`。页面串行提交，不积压并发帧，结束后必须补一次精确最终态；轻微 overshoot 也必须满足同一坐标、卡片包含与圆角校验。动画受既有 `followSystemReducedMotion` / `interfaceAnimations` 控制，不新增偏好。
- 动画帧与静默态共用完整校验和 fail-closed 收口；参数、工作区预检或原生步骤失败均清空几何、取消拖动资格并隐藏，不保留中间态。页面停止失败动画后重新提交合法常态可恢复，不以节流掩盖失败。

### 贴边与展开方向

- 几何全部是纯 DIP 函数，不调用 Win32：最近边吸附（按胶囊中心，等距按上、下、左、右优先）、沿边偏移夹紧、贴边放置、空偏好顶部居中、展开方向（指向工作区内部）与态联合盒。
- 首次状态提交按偏好落位；之后的窗口盒由页面提交，后端夹紧在主屏工作区内。
- 主屏是本期唯一目标屏，工作区取主屏 `rcWork` 的 DIP 表达。

### 原生拖动

- 常态或 hover 下页面调用 `begin_island_drag`：宿主先 `ReleaseCapture()`，再向岛窗口发送 `WM_NCLBUTTONDOWN`（`HTCAPTION`），交给 Windows 原生移动循环；不重写移动与命中逻辑。
- 原生移动循环结束（`WM_EXITSIZEMOVE`）后按胶囊中心吸附到最近边，夹紧偏移后回位；落点经 `SettingsState::update` 在偏好提交锁内只改 `islandEdge` 与 `islandOffset` 两个字段（不整份覆盖其他偏好），`islandEnabled` 为假时不写。落点带开始序号，旧序号任务被丢弃，不覆盖更新的落点。保存与偏好广播在后台线程执行；`begin_island_drag` 的命令线程在原生移动循环结束后最多等待本次保存完成 `2s`，正常返回后立即读取偏好可见新落点，不在 UI 线程等待或写盘。过期/关闭/取消仍正常返回；保存或广播失败、等待超时只记日志，不改变原生拖动结果，超时后台任务继续完成。
- 拖动全程不激活窗口。拖动中不按指针离开切态；`begin_island_drag` 返回 `{ pointerInside: bool }`：正常释放并完成吸附后，以 `GetCursorPos` 转成客户区坐标，与最终客户矩形比较（左上含、右下不含，不扣圆角）。该释放事实随本次保存完成屏障返回，取消、几何失效、过期落点或等待超时保守返回 `false`。页面据此决定 hover 或回落常态，不依赖 WebView2 补发 `pointerleave`，也不沿用拖动前的悬停记录。

### 岛卡与卡片顺序

- 插件岛卡按清单 `island` 字段声明，与桌面格子共用同一 `plugin:slot` 入口分派和外壳契约；官方与本地插件走同一字段。字段规则见 [ADR-0029](0029-插件来源与范围.md)。
- 岛卡顺序只记录在偏好 `islandCardOrder`，不设自动排序；写入路径有两条——展开态拖动卡片、设置页行尾「↑ / ↓」。两条路径写同一份列表，不产生第二份顺序。
- 该偏好在反序列化时规范化：只保留带 `official.` 或 `plugin.` 前缀的非空标识，去重、最多 32 条；被丢弃条目只记总数日志。

### 卡片分离与外观

- 一个功能一张完整卡片：每张卡自带表面、圆角与内边距，卡与卡之间留出间距，不连成一块。
- 现有主题把 `--fence-surface`、`--fence-border`、`--fence-text` 声明在 `.fence-workspace`；岛通过不可见令牌探针读取这三项，不把工作区定位、尺寸或格子样式带入岛根。偏好、样式表替换/加载与系统深浅色变化均触发重新读取，不增加轮询。
- 展开态外框不绘制表面与描边：外框只作为命中区域与拖动区域存在。卡间隙露出桌面像素，但输入仍属于岛窗口，不穿透到桌面。
- 卡片内容与内边距随状态逐级加大（常态 / hover / 展开），具体数值见视觉规范；媒体图与右侧信息列等高，保持正方形比例。
- 岛窗口保持透明矩形、不按卡片形状裁切，展开态不拖窗口：外框没有可见表面，不再显示左侧 `⋮⋮` 把手，拖动卡片本体非控件区域调整顺序，也可聚焦卡片后用上下键排序；按钮、输入、链接与插件交互内容不触发排序。

### 岛圆角

- 岛圆角是独立偏好 `islandRadius`（`0`–`16`，默认 `12`），不跟界面外观的 `cornerRadius`，也不跟 `--surface-radius`。
- 展开卡使用该值；hover 的圆角与常态的半高圆角属于形态固定值，不参与配置。
- 媒体图圆角始终跟随所在形态的外框圆角：常态为圆形，hover 与展开取外框圆角。
- 主题经 `theme.json` 的 `appearance.islandRadius` 写入同一偏好，切换或撤下主题按既有基线还原规则处理，见 [ADR-0034](0034-主题插件角色与基线还原.md)。

### 设置入口

- 岛是设置里的一级页，不并入「功能格子」；一级页只提供显示开关、全屏隐藏开关、岛圆角与卡片列表。
- 卡片行沿用功能格子的设置行形态，右侧控件组依次为：开关（该卡是否上岛）、顺序「↑ / ↓」、「›」（进入卡片二级页）。
- 卡片二级页页头为返回按钮与标题，右侧是移除图标命令与上岛开关；第二行是卡片身份与描述；其下是该卡自有设置，没有自有条目时显示「插件未提供设置条目」空态。二级页不再重复上岛开关。
- 卡片行提供基础右键菜单：打开卡片设置、上移、下移，分隔线后停用此卡片；菜单复用既有自绘菜单组件，不新写定位与键盘关闭逻辑。

## 后果

- 岛是继透明桌面工作区、普通应用界面、原生消息之后的第四个独立表面：不共享页面、不共享窗口盒，只在配色与字体上跟桌面主题。
- 岛与桌面格子是两条独立呈现路径：同一插件可以同时有桌面格子和岛卡；格子配额、布局撤销与工作区快照规则都不约束岛，岛也不反哺工作区。
- 复用既有命令边界与前台事件，岛提供 `get_island_snapshot`、`set_island_state`、`begin_island_drag`，不新增事件或持久集合。岛快照按需生成独立注册投影，不写工作区注册集合；组件运行时变化与偏好变化沿既有事件触发重读。
- 透明合成、透明像素的命中归属与置顶依赖系统行为，真机表现按待验证清单确认。
- 主屏专用使多显示器用户只在主屏看到岛，这是本期接受的边界。

## 待验证

- 透明矩形窗口在不同壁纸与深浅色下的壁纸透出、CSS 圆角边缘平滑、透明角落点击归岛，以及拖动、置顶与不抢焦点的联合表现。
- 三态切换、hover 回落与拖动吸附的端到端行为随页面验收验证；几何与窗口层单测不替代真机验证。
- 展开卡间隙保持透明像素但仍接收岛窗口输入；核对动画期间不残留纯色背景、黑边或不透明矩形。
- 歌词跟随与进度投影在真实播放器、外部取词源上的刷新节奏、首句延迟与无词回落需真机核对；单测不替代真实网络与播放器验证。

## 与音乐协议的关系

岛的音乐卡常态显示一行歌词、展开显示进度与当前句，依赖播放时间轴。前端消费共享音乐源，只为可见的时间投影设置计时，不另订阅音乐事件或请求歌词。展开频谱仅订阅既有采集事实，不启停全局采集；仅有岛且没有其他采集消费者时保持固定高度基线。后端支持带消费者引用计数的采集单例后，岛才可按需参与采集生命周期。音乐协议因此增加时间轴事实与投影锚点，约束见 [ADR-0016](0016-正式项目架构.md) 的音乐监听一节：时间轴单独成子快照，不进入完整快照的收敛比较，也不新增常驻轮询。

## 范围之外

- 多显示器支持：本期只使用主显示器，扩展到其他显示器须另行决策。
- 队列翻页与轮换、任务栏嵌入、Win10 磨砂、给岛插件额外能力：均不做。
- 歌词取词的接口形态、失败重试与缓存策略留在实现内决定；本 ADR 只确定时间轴事实由音乐协议提供、歌词不依赖播放器自有接口。
- 卡片内容本身的视觉（音乐卡、插件卡内部排版）由卡片作者与视觉规范决定，本 ADR 不代为规定。
