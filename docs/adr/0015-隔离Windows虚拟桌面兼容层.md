# 隔离 Windows 虚拟桌面兼容层

Milestone 1 使用独立、可替换的虚拟桌面适配器提供虚拟桌面枚举、当前桌面身份、创建、删除和切换通知，并将版本相关的私有 COM 能力限制在该适配器内部。Windows 公开 `IVirtualDesktopManager` 只承担顶层窗口桌面归属查询、当前桌面判断和窗口迁移。新虚拟桌面首次出现时呈现完整桌面项目集合，全部项目进入主显示器未归类区域，围栏为空，组件采用产品默认集合；虚拟桌面删除后，对应布局转为保留 `30` 天的布局归档，手动备份继续按自身生命周期保留。恢复布局归档时创建新的 Windows 虚拟桌面，并将归档布局绑定到新身份。完整备份还原保留当前 Windows 虚拟桌面，匹配已有身份，为备份中缺失的活动布局创建新桌面，并为当前系统新增桌面建立默认布局。拖动期间收到虚拟桌面切换通知时，主程序取消当前拖动并恢复源布局，随后激活目标虚拟桌面的独立布局、选择集合和焦点状态。运行期间适配器失效时，guardian 恢复 Explorer 状态，主程序停止桌面接管、保留全部布局数据并记录错误。当前 Windows 10 22H2 平台验证适配器的身份稳定性、生命周期通知、布局切换和恢复；其他 Windows 版本不再阻塞当前实现。
