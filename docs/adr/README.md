# ADR 索引

本目录记录已确认的架构决策。改代码前先按主题查这张表，只读相关几份，不整目录翻。

## 维护规则

- 新增 ADR：编号取当前最大值加一、四位数，文件名用 `编号-标题.md`，并在下方「生效决策」登记。
- 决策被取代：在新 ADR 写明取代关系，在旧 ADR 顶部加一行指向新 ADR，把旧条目移到「已被取代」。
- 本索引只列生效决策；被取代的文件留在磁盘上作溯源，不承载约束。
