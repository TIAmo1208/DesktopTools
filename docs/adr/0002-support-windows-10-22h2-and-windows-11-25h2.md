# 支持 Windows 10 22H2 与 Windows 11 25H2

Desktop Tools 将 Windows 10 22H2（OS build 19045）设为最低版本，并把 Windows 10 22H2 与 Windows 11 25H2（OS build 26200）同时纳入正式验收矩阵；渲染运行时采用 WebView2 Evergreen Runtime。两个版本提供相同的 Milestone 1 功能能力、操作结果、产品交互语义和恢复行为；原生菜单、系统确认界面与系统视觉沿用对应 Windows 版本的呈现。任一版本的强制项失败都会阻止对应能力发布。Windows 10 22H2 已结束常规支持，这项兼容投入用于覆盖仍在使用该版本的桌面效率用户，同时通过 Windows 11 25H2 验证当前 Shell 行为和后续演进路径。
