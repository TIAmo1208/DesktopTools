# 插件目录随设置迁移

## 状态与原因

插件目录指针、整目录复制迁移与失败后重试的决策不再适用，已被[插件默认目录与随包资源](0016-正式项目架构.md#插件默认目录与随包资源)取代。默认插件根与程序安装资源合一，避免安装后再次复制；不提供旧版目录兼容或自动迁移。

## 当前边界

启动直接解析 `pluginDirectory`：空值使用可执行文件所在目录下的 `plugin`，显式值沿用原有路径安全校验。无法取得可执行文件目录时明确报错，不回退到用户数据目录。生效目录在运行期间冻结，偏好变更下次启动生效，不复制原目录文件，也不读写 `plugin-location.json`。

配置目录迁移属于独立功能，继续保留。开发运行不加特例，通常使用 `build/target/debug/plugin`；仓库插件目录需显式配置后才能用于开发。
