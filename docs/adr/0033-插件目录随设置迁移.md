# 插件目录随设置迁移

## 背景

插件代码目录独立于主配置目录（默认位于 `%APPDATA%\TIAmo\plugins`），用户可在设置页自定义选择新的插件根目录。为保证应用数据管理一致性，当用户更改插件目录偏好后，插件目录应当具备类似配置目录的平滑迁移能力，避免代码文件散落或实例意外失效。

## 决策

### 1. 指针机制与生效目录定位

- 在启动定位目录（Tauri 的 `app_data_dir()`，即 `%APPDATA%\<bundle identifier>`，本应用为 `%APPDATA%\io.github.tiamo1208.desktop-tools`）下维护 `plugin-location.json` 指针文件，与 `config-location.json` 位于同一目录并保持同一套架构逻辑。启动定位目录固定不变，不随配置目录或插件目录本身的迁移而移动。
- 指针文件中仅记录当前生效插件目录的标准绝对路径（不采用 `\\?\` 等 verbatim 路径），且该指针文件不随插件目录或配置目录本身的迁移而移动。
- **解析优先级**：
  1. 优先读取并校验 `plugin-location.json` 指针；
  2. 若指针文件缺失或损坏，则读取生效配置目录下的 `settings.json` 获取 `pluginDirectory` 偏好；若偏好未配置或为空串，回退至默认插件目录 `%APPDATA%\TIAmo\plugins`；
  3. 首次检测到指针缺失（例如老版本升级或初次运行）时，按上述兜底规则确定初始目录，并自动建立写入 `plugin-location.json` 基线指针。

### 2. 迁移时机与整目录复制语义

- **运行时冻结**：当前运行期内实际挂载的插件目录在启动时冻结，运行期间界面上的偏好修改仅持久化保存至 `settings.json`，不会立即在本次运行中热切换目录。
- **启动时迁移**：在下一次应用启动时，比对配置中的偏好路径与指针文件所记录的路径：
  - 若路径一致，直接采用；
  - 若路径不一致，启动准备阶段（`prepare_plugin_directory`）执行整目录迁移。
- **迁移复制规则**：
  - **目标目录必须为空**：若新目标目录已存在且非空，拒绝迁移并记录 ERROR；
  - **拒绝嵌套包含**：源目录与目标目录不能互相包含；
  - **安全校验**：严禁符号链接、目录联接（junction）及重解析点；
  - **原子确认**：整目录文件完整复制成功后，最后一步才更新写回 `plugin-location.json` 指针文件。

### 3. 失败降级与重试机制

- 若目标被占用、校验不通过或复制过程中断失败：
  - 记录 ERROR 级别日志；
  - **不更新指针文件**，本次运行降级回退至旧插件目录继续工作，确保应用能够正常拉起与访问已有插件；
  - `settings.json` 中保留用户的新目标偏好，待下次启动再次尝试迁移。

## 结果与影响

- 插件目录迁移与配置目录迁移机制完全对齐，均采用启动定位指针 + 启动期迁移 + 运行期冻结模式。
- 保证了在外部资源管理器或安装器中，即使宿主尚未启动，也能通过只读解析 `plugin-location.json` 准确找到当前生效的插件根目录。
