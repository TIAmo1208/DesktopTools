# 浮岛消息通知锚点与显示开关

## 背景

不同来源的消息曾各占一枚胶囊锚点；天气变化和收集箱新收录又各占一枚，通知多时挤掉仍在活动的音乐。关闭原有「胶囊消息通知」也不能单独控制音乐或插件卡在紧凑两态的显示。

## 决策

- 原生 Toast 的只读投影、浮岛侧天气变化与收集箱新增通知，以及系统通知监听读取的只读条目，共用一条消息通道与一枚「消息通知锚点」。锚点身份不变，锚点内的图形随最新条目变化：系统通知条目用来源应用 Logo（`20 × 20` 安全区、`3px` 圆角），普通信息与天气、收录等本地条目用 Lucide `bell`，成功用对勾，警告用 Lucide `triangle-exclamation-point`，错误用 Lucide `circle-x`，加载在有确定 `0–1` 进度时画进度环、没有进度时用 `resources/loading.svg`（每秒一圈、关闭动效时静止）；颜色沿用正文色、通过绿、警告黄与错误红。来源只属于条目，不参与锚点身份。音乐保留独立活动锚点，插件卡保留常驻锚点。hover 顶部仍用功能图标表示身份，列表逐条显示应用 Logo 或类型图标，胶囊图形不复制到 hover 列表。
- 同一条原生通知按原生身份更新，本地条目有独立身份；按到达时间从新到旧排列。胶囊在正文期显示最新正文与计数，超过 99 条显示「99+」；正文期结束后只保留锚点图标，胶囊正文让位给下一枚有内容的锚点，没有其它内容时只剩锚点圆。hover 只显示最近 5 条，每行是「来源 · 内容 · 时间」，正文单行省略，时间沿用当天时分、跨天补月日。每行可单独关闭；全部关闭或到期后撤下锚点。
- 「正文展示时间」与「锚点显示时间」是两条独立的时长，各自从条目到达时刻起算、互不串接，默认 `5` 秒与 `30` 秒，不提供设置项。条目寿命取两者较长者的截止时刻：正文长于锚点时正文结束锚点一起消失，正文短于锚点时正文收起后锚点继续留到自己的期限。失败、待确认与带确定且未走满进度的加载只豁免锚点期，正文照常收起。hover 和展开的阅读期间不移走当前条目，也不暂停或续期两段计时；回到常态再按当前时间清理到期项，离开展开态还清除已读的普通原生通知。系统隐藏期间收到的通知恢复时一次并入同一锚点，不逐条补播，已过期的普通通知不补回。
- 天气只在成功摘要的主信息或天气代码变化后通知，不因首次读取、摘要缺失或未变化而通知。收集箱只在快照数量增加且有新身份时通知；重命名、置顶、删除和首次读取不算新增。两类通知只在浮岛侧投递，不新增原生 Toast；关闭时只移除本地条目。
- 原生 Toast 弹出及队列规则不变，关闭原生通知仍走原有离场命令。展开消息卡仍沿用原生投影及阅读暂存：默认折叠到最新一条，可展开最近 5 条；天气、收集箱的完整内容仍在各自卡片。消息卡以 `official.island-messages` 进入 `islandCardOrder`，与其它岛卡共用一套展开顺序与上移/下移、键盘排序；是否显示由 `islandMessageCardVisible` 控制，与铃铛锚点开关独立，通知传输、时效与逐条关闭语义不变。
- 「上浮岛显示」只决定某一功能锚点是否出现在胶囊与 hover，不改变浮岛卡开关、展开卡、音乐播放、通知投递或生命周期。偏好 `islandAnchorVisible` 按 `music`、`message`、`plugin` 分键保存，缺项使用各自默认值（均开启）。「浮岛 → 锚点显示」提供三项入口；「功能格子 → 音乐」也可修改同一个 `music` 键。
- hover 卡片宽度取所有可见锚点详情的自然宽度最大值，不窄于胶囊实测宽度，并沿用现有上限；卡片高度仍按选中详情实测。插件自绘不预挂载，选中后若增宽，本轮 hover 保留已经量到的最大宽度。测宽样本不参与命中或原生几何提交。

## 边界

原先点击收集箱 hover 提醒打开收集项编辑窗口的入口随提醒列表撤下；收集项仍可在展开的收集箱卡中打开。原生 Toast 仍按原规则弹出。真实 WebView2 中的几何、指针命中与不同 DPI 下的呈现待真机确认。

本决策接管 [ADR-0044](0044-浮岛内容层锚点与状态.md) 中按来源拆分消息、系统隐藏计数与 hover 宽度的条款，以及 [ADR-0045](0045-浮岛通知型锚点与图标语义.md) 中天气和收集箱的独立锚点、生命周期、图标与旧消息开关的条款。其余边界不变。
