# 浮岛展开态窗口保持工作区高度

## 背景

展开窗口原先随内容高度变化。单张卡反复折叠和展开时，即使列宽不变，也要重新调整原生窗口高度，造成布局重排和画面抖动。

## 决策

展开窗口从主屏工作区顶部开始，高度等于工作区高度；宽度仍为自然内容列加 `16 DIP` 滚动条槽，不扩大到屏幕宽度。卡片保留原顺序和间距。内容超过工作区时在页面中滚动，提交的卡片区域仍裁剪在视口内；宽度超过工作区时继续拒绝。

形变阶段保留两态并集，进入和退出各调整一次高度。展开期间折叠、排序、内容高低变化与滚动只更新页面布局和可见卡片，不重复提交相同窗口盒和视口；原生继续按最后实际下发的物理盒去重。胶囊与 hover 的几何、命中与拖动规则不变。

末张可见卡片下方的透明列沿用 `extra-band` 退回：指针连续停留 `120ms` 后回到胶囊，期间回到卡片则取消。卡间隙、圆角外像素和滚动条槽不参与该判定。父窗口保持矩形命中，不增加点击穿透、不拆分可视窗和输入窗。

本决策接管 [ADR-0036](0036-浮岛作为独立呈现位.md) 与 [ADR-0044](0044-浮岛内容层锚点与状态.md) 中展开终态保留入态并集或随内容伸缩的几何描述。三态尺寸和滚动条见[浮岛](../design/浮岛.md#三态)。

## 已知边界

- 指针停留未满 `120ms` 时，透明列内的点击仍由浮岛接收，桌面可能收不到第一下点击。
- 透明列内的滚轮事件交给浮岛列表，不交给桌面。
- 从桌面图标起手拖拽时，如果按下点在透明列内，桌面不会开始拖拽。
- 指针经过透明列并连续停留 `120ms` 后自动收起，不需要点击空白。
- 拖入接收只按卡片显示区域判定：原生在进入、移动与释放时把光标位置换算到窗口内 DIP，与页面提交的 `cards` 矩形比对，透明列不进入接收路径、不广播接收事实、放下不收入；进入仍返回非 `NONE` 的有效效果以维持 OS 拖放会话，移动中在卡片与透明列之间来回会成对补发 active/inactive 事实。矩形命中与点击归属不变。
- 已知边界：页面在展开态把卡片之间的透明间隙也作为无圆角占位矩形并入 `cards`（用于窗口校验与鼠标归属），因此原生命中无法把「卡间隙」与真实卡片表面分开，卡间隙会按显示区域处理；卡列上下的透明列仍被排除。
