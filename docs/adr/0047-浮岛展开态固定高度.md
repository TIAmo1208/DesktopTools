# 浮岛展开态窗口覆盖整个工作区

## 背景

展开窗口原先随内容高度变化，单张卡反复折叠和展开时即使列宽不变，也要重新调整原生窗口高度，造成布局重排和画面抖动。后续曾把展开态固定为工作区高度、宽度仍取自然内容列；现在展开态需要按整屏承载，把窗口扩展到当前显示器工作区的完整矩形，卡片内容仍只占贴边内容列。

## 决策

展开窗口覆盖主屏工作区的完整矩形：宽度等于工作区宽度，高度等于工作区高度，均排除任务栏；窗口从工作区左上角开始。卡片内容仍按内容列宽度（`360` 卡宽加上 `16 DIP` 滚动条槽的 `420 DIP`）按 `islandEdge` 贴边或水平居中布局，`islandOffset` 继续生效；展开态页面视口铺满整个工作区，内容列以外是透明留白但接收页面指针事件。内容超过工作区时在页面中滚动，提交的卡片区域仍裁剪在视口内。窗口盒由工作区决定，不再随内容高度或列宽变化；页面提交的卡片区域仍以内容列盒为原点，原生在投放与几何判定前按工作区原点重基准（不缩放、不叠加贴边偏移），前端不需要感知父窗放大。胶囊与 hover 的几何、命中与拖动规则不变。

形变阶段保留两态并集，进入和退出各调整一次窗口盒。展开期间折叠、排序、内容高低变化与滚动只更新页面布局和可见卡片，不重复提交相同窗口盒和视口；原生继续按最后实际下发的物理盒去重。

父窗口保持窗口矩形命中，不做系统级点击穿透、不拆分可视窗和输入窗；透明区由页面接收指针并立即回胶囊。展开态页面视口铺满工作区；内容列占满工作区高度、上下无余量，左右为透明带。透明区域（卡片与内容列以外）沿用 `extra-band` 退回：指针停留在透明区域满 `120ms` 后回到胶囊，期间回到卡片/内容列则取消；透明区单击也直接回胶囊。拖动排序卡片的 `400ms` 手势期间不触发该退回（排序手势优先），第二指针移到空白也不启动/续期计时；释放、取消或退出排序后按落点恢复判定。卡间隙、圆角外像素与滚动条槽按页面既有命中归属处理，不新增原生命中分支。

本决策接管 [ADR-0036](0036-浮岛作为独立呈现位.md) 与 [ADR-0044](0044-浮岛内容层锚点与状态.md) 中展开终态保留入态并集或随内容伸缩的几何描述。三态尺寸和滚动条见[浮岛](../design/浮岛.md#三态)。

## 已知边界

- 展开态窗口覆盖整个工作区，透明区域内的点击仍由浮岛接收，桌面收不到第一下点击；透明区单击直接回胶囊，指针连续停留 `120ms` 也会自动收起。
- 透明区域内的滚轮事件交给浮岛列表，不交给桌面。
- 从桌面图标起手拖拽时，如果按下点在浮岛窗口内，桌面不会开始拖拽。
- 拖入接收只按卡片显示区域判定：原生在进入、移动与释放时把光标位置换算到窗口内 DIP，与页面提交的 `cards` 矩形比对，透明区不进入接收路径、不广播接收事实、放下不收入；进入仍返回非 `NONE` 的有效效果以维持 OS 拖放会话，移动中在卡片与透明区之间来回会成对补发 active/inactive 事实。
- 页面在展开态把卡片之间的透明间隙也作为无圆角占位矩形并入 `cards`（用于窗口校验与鼠标归属），因此原生命中无法把「卡间隙」与真实卡片表面分开，卡间隙会按显示区域处理；卡列上下的透明区仍被排除。
