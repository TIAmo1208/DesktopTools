# 收集箱入口统一创建

设置页的“添加收集箱”、Desktop Tools 桌面背景菜单的“添加收集箱”共用 Rust 侧同一个创建入口。该入口提交 `WorkspaceCommand::CreateComponent` 创建 `official.collect-box`，统一选择目标显示器、计算工作区可用位置、使用默认尺寸并发布工作区快照。

收集箱功能关闭时仍允许通过这些入口创建实例；功能开关只控制实例显示，不阻止布局创建。这样创建行为与现有“关闭只隐藏实例、保留布局”的语义一致，用户重新打开功能后可以看到已创建的格子。

桌面背景菜单动作通过固定 `--desktop-menu` 参数转发到主实例，再调用同一创建入口；设置页只调用 `create_collect_box`，不自行构造工作区命令、计算初始位置或展开尺寸，也不复制当前格子的尺寸。统一流程复用工作区现有的可用位置计算，默认展开尺寸沿用 `360 × 280` DIP 基线，避免不同入口产生重复堆叠或不同尺寸。

公共参数保留既有默认值和显式覆盖能力，默认值由所属公共流程解析，不在收集箱创建入口重复维护。创建时的展开边界与折叠呈现分别处理：收集箱继续通过公共外框的 `collapsedSize` 指定 `56px` 折叠高度，省略折叠宽度时沿用展开宽度；公共默认折叠高度仍为 `28px`。折叠尺寸不作为新实例的展开尺寸，也不覆盖已保存的展开边界。

收集箱格子的“移除”使用 `WorkspaceCommand::RemoveComponent`，只接受现有 `official.collect-box` 实例。沿用工作区原子保存、快照发布和布局撤销重做，不接触共享收集目录、条目或功能开关。移除当前焦点实例后，语义焦点回到桌面背景；保存失败则保留原快照。重启读取已保存的实例列表，不补回已移除的默认格子；移除最后一个收集箱后，仍通过设置页或桌面背景菜单的统一入口重新添加。

实例外观继续独立于布局历史保留，以便撤销恢复原格子的外观；即使移除时尚未设置外观，也保留默认外观记录以占用旧身份。创建流程同时排除现存实例身份和保留外观的身份，防止新格子继承已移除格子的偏好。移除能力限定于已有重新创建入口的收集箱；音乐控制此次仅复用公共菜单分组，不增加移除或创建能力。天气格子的创建入口沿用本决策的同一形状（由 Rust 侧入口完成组件创建并纳入同一布局事务，创建时写入功能开关）与同一套可创建、可移除声明，其来源绑定、初始状态、开关语义与移除边界见 [ADR-0026](0026-天气多来源与多城市并存.md)，不在本决策内重复定义。

工作区没有可用位置时的实际错误反馈、多显示器临时投射表现，以及收集箱移除后的真实桌面焦点与快捷键恢复尚未经真实环境验证。
