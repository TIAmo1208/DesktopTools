# 收集箱入口统一创建

设置页的“添加收集箱”、Desktop Tools 桌面背景菜单的“添加收集箱”和已有收集箱格子菜单的新建动作共用 Rust 侧同一个创建入口。该入口提交 `WorkspaceCommand::CreateComponent` 创建 `official.collect-box`，统一选择目标显示器、计算工作区可用位置、使用默认尺寸并发布工作区快照。

收集箱功能关闭时仍允许通过这些入口创建实例；功能开关只控制实例显示，不阻止布局创建。这样创建行为与现有“关闭只隐藏实例、保留布局”的语义一致，用户重新打开功能后可以看到已创建的格子。

桌面背景菜单动作通过固定 `--desktop-menu` 参数转发到主实例，再调用同一创建入口；设置页只负责调用 bridge，不自行构造工作区命令或 bounds。默认位置沿用工作区现有的可用位置计算，避免不同入口产生重复堆叠。组件默认尺寸沿用当前收集箱组件的 `360 × 280` DIP 基线。

待验证：工作区没有可用位置时的实际错误反馈和多显示器临时投射表现，沿用现有工作区命令错误契约验收。
