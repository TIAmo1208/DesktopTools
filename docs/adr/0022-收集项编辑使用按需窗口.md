# 收集项编辑使用按需窗口

编辑一份收集项时打开独立 `WebviewWindow`（对标设置窗）。同一文件同时只开一扇编辑窗，重复请求显示并聚焦已有窗口，避免并行编辑副本；不同文件可同时打开，不设全局单窗限制。应用内重命名后，已有编辑窗继续关联改名后的文件。窗口关联只保留在当前会话，窗口销毁后再次打开重新读取文件。窗口内使用打包进应用的 Vditor，`mode` 为 `wysiwyg`，工具栏不含 `edit-mode`、`both`、`preview`，并关闭 `cache.enable`。保存写回该收集项的 Markdown 文件后，桌面格子按文件变化重新静态渲染。

设置页提供退出编辑窗是否自动保存：开启则保存并关闭，关闭则询问保存、不保存或取消。

## 关闭时的附件回收

正文成功保存且确认关闭时，按磁盘最终正文清理该文档明确拥有、已无引用的受管图片；普通保存和编辑过程不清理，保留撤销能力。放弃草稿时，以最后成功保存的磁盘正文为准，只考虑本次编辑新登记的附件。保存失败、取消关闭、正文加载或读取失败不触发回收；清理失败仅记录中文日志中的路径和原因，不撤销成功保存，也不阻止已确认的关闭。

复制、移动和剪贴板写入实际新建图片后，在文档资源目录的 `.managed-images.json` 登记文件证据，复用既有 Windows 文件身份、属性及 SHA-256 检查。内部复制形成的嵌套资源逐个登记目标文件证据，不继承源目录的证据。重命名时证据随目录移动，操作前按当前归属重新定位路径。未登记的历史文件、外部修改或替换的文件、重解析点、外部仅链接文件、根目录独立图片和其他文档附件均不回收，不推断历史所有权。

复用 Markdown 解析器检查内联图片、引用式定义及链接，解析相对路径、绝对路径、文件 URL 和 URL 编码；常规 HTML 的 `src`、`href` 引用和实体参与保护。未闭合引用、复杂 HTML、多源或动态引用、任一文档不可读等不确定情况停止本次回收。检查范围包含收集箱根目录全部 Markdown，以保护跨文档引用；存在其他打开的编辑窗时无法确认其草稿引用，跳过本次清理。

编辑窗保存、改名、导图和关闭共用提交互斥状态；关闭回调读取最新 ref，清理完成前不放行重复关闭。后端校验调用窗口和文档绑定，在后台持有既有窗口注册锁完成关闭清理，避免新编辑窗或应用内改名插入检查过程。系统回收复用 Shell STA 和带文件证据的 Pre 回调，不新增线程、常驻扫描、轮询或历史扫描界面。外部程序仍可独立修改文档；逐项回收前重新读取引用并复核文件证据，观察不完整时保留。真实多窗口关闭与外部编辑并发仍需实机验收。

编辑器以收集项 Markdown 所在目录解析本地图片引用，支持资源目录相对路径与仅链接模式的绝对路径。图片显示地址仅用于渲染，保存、撤销和重命名仍使用原始 Markdown 引用；本地图片读取校验文件身份、图像格式，并限制为 32 MiB。HTTP(S) 图片使用原 URL 加载，不下载到资源目录。缺失资源保持加载失败，不改写正文。

正文图像保留原始 `src`，通过 `srcset` 呈现本地读取结果。双击放大通过 Vditor 的 `image.preview` 扩展入口，把已成功加载的 `currentSrc` 作为只读图像视图交给公开的 `Vditor.previewImage`，保留原有旋转与关闭功能；不修改正文 DOM、依赖包或重复调用原生图片读取。此适配避免原预览器仅复制 `src`，将本地相对路径误当作 WebView 页面资源。尚未加载、加载失败或无显示地址时不打开预览；GIF 复用原始图像数据，动画和原生窗口交互仍需实机验证。

收集箱与编辑窗中的 HTTP(S)、mailto 链接通过 Windows 默认程序打开，阻止 WebView 页面导航；其他协议拒绝并通过现有消息通知报告。该边界避免桌面宿主被外部网页替换，不改变编辑窗的正文编辑交互。

图片说明中的 Markdown 转义字符在 `alt` 属性内只渲染为文本，不生成编辑标记 HTML；重新解析和保存时转义图片说明，防止方括号等字符破坏图片语法。修正在编辑器实例初始化后、首次加载正文前安装，覆盖正文加载、编辑重排和保存；原始文件不执行自动修复或批量重写。Markdown 序列化允许等价的 URL 编码和格式规范化，图片目标与说明必须保持不变。

桌面暂停刷新无法约束已挂入桌面宿主的编辑器，因此编辑器放在按需窗口。

Windows 窗口创建与应用内重命名的关联维护在后台线程串行执行。Tauri 命令通过异步入口转交后台任务，原生桌面通道沿用其后台请求线程；主线程不得等待该关联锁，以避免 WebView2 创建窗口时互相等待。此线程边界不代替多窗口显示、聚焦与关闭的实机验收。
