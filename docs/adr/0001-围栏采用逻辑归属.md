# 围栏采用逻辑归属

围栏成员与归属由所有虚拟桌面共享，位置、尺寸、滚动和组件布局按虚拟桌面分别保存。共享围栏身份不随某个虚拟桌面的删除而删除；备份、还原和撤销必须维护共享内容的一致性。持久化使用独立的全局成员表和逐桌面空间结构，只接受当前格式，不迁移、兼容读取或合并旧数据，也不创建迁移备份。

围栏保存桌面项目引用、顺序与布局，原始文件继续保存在 Windows 用户桌面或公共桌面目录。所有虚拟桌面共享同一份围栏成员与项目归属，桌面项目恰好属于一个围栏或未归类区域；切换虚拟桌面不改变围栏内容。批量移动到围栏时，目标围栏的已有成员保持原位置，其他选中项目按稳定视觉顺序追加到末尾，整个命令形成一个布局事务。解散围栏直接形成可撤销布局事务，内部桌面项目以围栏内容区左上位置为组锚点，按成员当前视觉顺序进入同一显示器未归类网格，逐项避让已有项目并保持连续排列；围栏锁定状态随围栏结束，撤销操作完整恢复围栏及成员状态。该选择保留路径、快捷方式和外部应用行为，并将磁盘文件操作集中到明确的 Shell 操作流程中；物理目录归类和逐围栏混合模式会扩大数据迁移、恢复与误操作风险。
