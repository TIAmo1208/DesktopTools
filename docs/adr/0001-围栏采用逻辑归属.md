# 围栏采用逻辑归属

同一工作区内，每个桌面项目只在一个显示器表面呈现。围栏跨屏移动时，其标题、表面及全部成员整体移动；成员身份由围栏成员集合保存，不要求对应未归类位置记录。进入围栏时释放活动桌面槽位，原位置只保留在操作前的撤销历史中，避免隐藏槽位占用桌面容量或影响后续落位。普通移出按当前目标附近的可用网格落位，撤销使用历史布局。逐屏呈现按全局归属投影围栏和未归类项目，不能仅检查当前屏幕的围栏。跨屏拖动预览使用真实可见排列，取消恢复源表面，成功后以目标屏权威布局呈现。

围栏成员、归属、位置、尺寸、滚动和组件布局由同一工作区统一维护，不区分虚拟桌面。备份、还原和撤销保持同一工作区的一致性。仅接受当前格式，不迁移、兼容读取或合并旧数据，也不创建迁移备份。

围栏保存桌面项目引用、顺序与布局，原始文件继续保存在 Windows 用户桌面或公共桌面目录。工作区维护唯一的围栏成员与项目归属，桌面项目恰好属于一个围栏或未归类区域；切换虚拟桌面不改变围栏内容。批量移动到围栏时，目标围栏的已有成员保持原位置，其他选中项目按稳定视觉顺序追加到末尾，整个命令形成一个布局事务。解散围栏直接形成可撤销布局事务，内部桌面项目以围栏内容区左上位置为组锚点，按成员当前视觉顺序进入同一显示器未归类网格，逐项避让已有项目并保持连续排列；围栏锁定状态随围栏结束，撤销操作完整恢复围栏及成员状态。该选择保留路径、快捷方式和外部应用行为，并将磁盘文件操作集中到明确的 Shell 操作流程中；物理目录归类和逐围栏混合模式会扩大数据迁移、恢复与误操作风险。
