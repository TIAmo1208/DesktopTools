# 分离布局撤销与 Shell 操作撤销

Milestone 1 为每个虚拟桌面维护独立的会话布局撤销历史，虚拟桌面切换时保留，应用重启后由布局快照承担恢复。一次完成的拖动、缩放、排序模式变更、排序字段变更、排序方向变更、归属变更、显式层级命令、解散围栏或批量命令形成一个撤销单元，取消、失败和无状态变化的操作不生成记录；Shell 属性变化、重命名确认和属性就绪引起的自动重排作为派生布局结果进入合并快照。拖动取消恢复开始时的归属、顺序、位置、滚动位置和围栏层级，并保留原选择集合和拖动锚点焦点。组拖动作为一个布局事务保存全部成员的显示器归属、围栏归属、顺序、位置和自由定位项目层级，以及成功投放产生的目标围栏层级；撤销与重做恢复这些布局状态并保留用户当前滚动位置，选择集合继续引用同一批项目，焦点保留在仍可解析的拖动锚点。目标网格容量不足时执行同一恢复契约，并显示“目标区域空间不足，项目已恢复原位”。组拖动完成后发生外部项目变化时，仍在活动布局或暂时失效的引用参与恢复，Shell 已确认离开命名空间的项目保留历史引用，其他项目完成恢复，事务记录部分恢复结果，并显示“已恢复 X 项，Y 项状态已变化”；重做只作用于该次实际恢复且仍有效的项目集合。解散围栏的撤销单元保存围栏完整状态与成员原归属，显式层级命令进入撤销历史，点击围栏或自由定位项目引起的置顶进入持久布局与两秒合并快照。Desktop Tools 在当前应用会话中根据 `IFileOperationProgressSink` 返回的实际结果保存可逆 Shell 操作日志，通过新的 `IFileOperation` 执行重命名、移动、复制和移入回收站的补偿操作或重做，并为原始操作与每次补偿操作分别请求写入 Explorer 会话撤销记录；永久删除保持不可撤销。补偿操作使用原生 Shell 确认和错误界面，成功部分与用户选择形成新的日志状态。Shell 变化通知识别 Explorer 或其他程序引起的实际状态变化；明确匹配时标记对应记录已被外部撤销或重做，结果存在歧义时终止该记录及其后续重做链。已失效记录保留状态，`Ctrl+Z/Y` 跳过该记录并作用于最近的有效记录。用户在撤销后执行新的布局或 Shell 操作时，统一时间线当前位置之后的全部重做记录被清除，新操作成为最新分支。当前虚拟桌面的布局历史与共享 Shell 操作日志按完成时间组成统一撤销时间线；文本控件获得焦点时处理自身撤销，桌面内容工作区获得焦点时 `Ctrl+Z/Y` 作用于最近一项，重命名提交后形成 Shell 操作记录。
