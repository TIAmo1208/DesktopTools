# 统一工作区且不区分虚拟桌面

整个项目在任何情况下都不区分 Windows 虚拟桌面。内容、布局、门户绑定与浏览状态、选择、焦点和撤销历史由同一工作区维护，虚拟桌面的创建、删除或切换不触发业务状态分区、归档或恢复。

备份和还原只作用于统一工作区，不枚举、匹配、创建或删除 Windows 虚拟桌面，不依赖其私有 COM 身份作为持久化键。多显示器仍分别维护呈现与归属，断屏临时投射和重连恢复不变。

该决策避免工作区随 Windows 虚拟桌面切换而产生不同状态。不得仅因虚拟桌面切换主动取消业务拖动；系统实际取消拖放时仍执行既有取消契约。

## 实现状态

当前实现只持有一份工作区布局、交互状态与布局历史。启动、保存、备份还原、原生拖放及前端拖动均不读取 Windows 虚拟桌面身份；私有 COM 适配器、生命周期监听与创建、删除、归档恢复命令已移除。

持久文件使用版本 5，载荷为完整的 `layout` 与 `explorerLayoutImported`，围栏成员、外观和组件状态随同一布局保存。只接受当前格式，旧文件明确报错，缺失文件使用默认值。自动快照按统一工作区空闲合并并保留最近 20 份；还原前同步生成恢复点，保存失败不替换内存或清空历史。

自动回归覆盖统一布局与交互保持、空间和成员撤销顺序、组件私有状态保留、备份还原、保存失败回滚以及旧格式拒绝读取。在 Windows 10 双屏环境实测新建并切换临时虚拟桌面、关闭临时桌面返回原桌面，围栏和组件呈现一致，程序进程与持久文件保持不变；拖动过程中切换的交互细节仍待人工验收。
