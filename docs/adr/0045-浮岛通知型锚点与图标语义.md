# 浮岛通知型锚点与图标语义

## 背景

浮岛最初把音乐、收集箱与天气都当作常驻锚点。只要卡片在 `islandCardOrder` 里，即使没有播放、天气变化或新增收录，也会占据胶囊位置。顶部锚点仅用状态符号也不容易辨认功能身份。

原生消息、天气变化、收集箱新增现共用一枚消息通知锚点。独立天气和收集箱锚点、各自停留期限、收录完成强调、hover 提醒列表及其点击编辑入口均不再适用。现行通知规则、图标与「上浮岛显示」开关见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。本文保留音乐活动锚点、图标分工和卸载入口的决策。

## 决策

### 音乐活动锚点

- 只有音乐卡在 `islandCardOrder` 中启用，且媒体会话正在播放或暂停时，才产生活动锚点；停止、未知、无会话或未启用时不产生。音乐在普通事件层 `event`，随会话停留，不设置独立期限，更新时间轴与歌词不换锚点身份。插件卡仍用常驻层 `resident`。
- 音乐胶囊继续按播放状态与贴边方向使用固定内容盒，换句不重设窗口。紧凑两态是否显示锚点由 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 的开关决定，不改变媒体会话。

### 图标分工与详情

- 胶囊内的音乐媒体图以 `cover` 填满 `28` 圆；无图或加载失败时用 `--fence-border` 圆底和 `20 × 20` 安全区内的音符（`resources/island-music-note.svg`）。插件与普通事件继续用状态符号。消息通知锚点按最新条目选择图形：系统通知条目显示来源应用 Logo，其余按铃铛、对勾、`triangle-exclamation-point`、`circle-x`、进度环或 `loading.svg` 不定加载图；hover 顶部仍用功能图标表示身份，逐条图标（Logo 或类型图标）只属于 hover 列表，见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- hover 顶部用功能图标表示身份，拖放锚点仍用松手图标。音乐详情左侧保留媒体图或音符，艺人信息由宿主提供；插件详情可自绘，未提供则回落主信息行，约定见 [ADR-0029](0029-插件来源与范围.md)。天气和收集箱没有独立 hover 详情，全部进入消息通知列表。
- 展开卡的完整内容不变：音乐媒体图 `88`、天气详情与来源、收集箱列表、原生消息面板各自呈现。天气变化和收录通知关闭后不影响展开卡。

### 卸载入口归属

- 浮岛卡片二级页的「卸载卡片」只提供给插件卡（`plugin.*`）；官方卡（`official.*`）可以在卡片列表关闭上浮岛或选择「停用此卡片」。
- 「卸载卡片」只关闭该卡的上浮岛状态，不卸载插件、不弹确认。卸载插件仍走插件设置页的卸载命令。

## 原因与职责边界

媒体活动与卡片启用是两个事实。音乐锚点随会话出现，空闲时不占胶囊；hover 顶部用身份图标，详情保留媒体图或状态反馈。官方卡本身不能卸载，因此卡片设置只提供停用，不显示无效的卸载入口。

媒体与卡片是否启用由宿主提供，锚点出现条件由纯模型判断，页面负责图标与详情绘制。消息通知的来源、期限、阅读暂存、关闭和显示开关由 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 规定，不在这里另设期限或编辑入口。

## 约束

- 图标与背景复用已有主题令牌，不新增颜色令牌、渐变或阴影；保留音乐音符资源及其来源登记。
- 锚点仍按 [ADR-0044](0044-浮岛内容层锚点与状态.md) 的 `anchors` 契约提交，图标和显示策略不改变几何契约。

## 已知边界与待验证

- 展开天气卡的 `WeatherGlyph` 使用基础图形与 `code >= 300` 的附加路径，不是完整供应商天气图映射；未知代码回到基础图。
- 按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 的投递条件，换城市但主信息与天气代码相同不会产生通知；收录新条目若与旧条目碰巧同一创建毫秒，也不算新身份。
- 真机待确认音乐在四边、两种形态与窄胶囊下的媒体图裁切、无图回落，以及插件 hover 挂载与清理、官方与插件卡停用入口。合并通知和紧凑两态的显示开关以 ADR-0046 为准。
