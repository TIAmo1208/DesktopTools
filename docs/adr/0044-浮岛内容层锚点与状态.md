# 浮岛内容层采用锚点与状态分层

## 背景

浮岛原来的常态胶囊与 hover 按「一张卡的最新摘要」组织：音乐、收集箱、天气各自占用一段固定文案，消息到达时整条胶囊被最新一条消息占用，拖放进入时另起一张独立接收卡。这种结构无法同时表达多个来源的内容，也没有统一的状态词、符号与结束去向；新增浮岛显示内容时只能按卡片自定样式。

[浮岛](../design/浮岛.md)「内容设计语言」用一排锚点承载同时存在的内容。本决策定义内容单元、状态、层级、边界及模型、契约、渲染三处职责。音乐活动锚点、图标分工与卸载入口见 [ADR-0045](0045-浮岛通知型锚点与图标语义.md)；消息通知合并、隐藏恢复、hover 宽度与逐功能显示开关由 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 接管。

## 决策

### 胶囊与内容单元

- 胶囊由一排锚点组成：每枚锚点 `28 × 28` 圆（绘制区即蒙版，安全区 `20 × 20`），右侧一行主信息，最多再带一个附加项；锚点间距 `12`。
- 胶囊最多并排 `3` 枚锚点，第 `4` 枚起折成一枚「＋N」圆（数字封顶显示 `99+`），展开看全部；折叠不改变锚点顺序。
- 贴上下沿水平方向排列；贴左右时胶囊竖排，锚点圆与主信息按同一顺序向下排列。
- 主信息单行不换行：中文上限 `18` 字、英文上限 `36` 字符，超出省略。通用附加项由 `islandAnchorValue` 放行整数百分比、`99+` 与 `mm:ss`；消息通知另按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 的条目计数显示。
- 胶囊只读：根节点只在展开态进入 Tab 顺序，胶囊态为 `tabIndex=-1`，内部不放按钮或可聚焦子元素；胶囊内没有可单独打开的入口，非交互区单击展开，按住 `250ms` 进入原生拖动（沿用卡片规则）。
- 零锚点显示一个空态圆锚点（表盘），`hh:mm` 以 `13` 号字显示在圆右侧，仍可单击展开；只剩锚点时按锚点数量收缩宽度，不自动隐藏。
- hover 顶部列出所有可见锚点（用按钮表示，可换行），用功能图标区分身份；下方只显示选中项的内容。指针移到锚点即切换详情；左右方向键在列表内切换并在端点停住，`Enter` 只进入带内容的锚点。需要确认、删除、批准的操作只进展开。详情宽度取所有可见锚点内容的最大值且不窄于胶囊，细则见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 展开沿用「卡片」规则，只复用内容单元与状态符号，不复用胶囊与 hover 的尺寸与密度。

### hover 内容提供者

- hover 根据锚点身份展示详情。普通事件和默认详情最多两行；音乐详情沿用[浮岛的音乐 hover 构成](../design/浮岛.md#内容设计语言)，保留左侧媒体图、三行媒体信息与右侧播放控件。
- 消息通知列表由 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 规定，包含来自天气变化与收集箱新增的本地条目；两者不再有独立锚点或详情。
- 插件提供者由插件自绘：宿主只提供空容器，插件通过可选的 `renderIslandHover` 写入内容并返回清理函数；未提供时回落模型主信息行，入口抛错只把该 hover 区域落到「组件渲染失败」，岛与其他锚点不受影响。约定见 [ADR-0029](0029-插件来源与范围.md)。

### 锚点身份与出现

- 普通锚点身份由层级与来源决定（`layer:source`）：同来源同层级原地换内容，首次出现按插入序追加。音乐随播放或暂停的媒体会话出现（见 [ADR-0045](0045-浮岛通知型锚点与图标语义.md)），插件卡保持常驻锚点。
- 消息来源只属于条目，不拆分锚点。所有原生消息、天气变化与收集箱新增共用固定身份的一枚消息通知锚点（胶囊图形随最新条目类型变化），见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 内容切换按锚点接力：旧信息向旧锚点收回 `240ms`（收缩节奏 `200`–`280ms` 的定点），新锚点在右侧自下而上渐入 `300ms`（生长节奏 `280`–`320ms` 的定点），随后新内容从新锚点向右展开；状态变化取消未完成动画并直接落到终态。减少动效时没有插入、伸缩与滚动动画，也不保留离场层。
- 展开再收起保留锚点顺序与当前选中项。

### 状态集

- 内置十种基础状态：待开始 `pending`、进行中 `running`、暂停 `paused`、完成 `completed`、失败 `failed`、取消 `cancelled`、等待确认 `awaiting`、未连接 `disconnected`、未授权 `unauthorized`、无总量运行中 `indeterminate`。
- 每种状态必须同时给出视觉差异（环、不定弧或符号）、固定短词与结束去向（停留 `linger`、收成圆点 `dot`、直接消失 `vanish`）。通用完成态收成圆点，取消直接消失；消息通知的图标、摘要与保留期限按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 状态集不封闭：插件可按同一形状扩展状态，但必须补齐同样三项；内置状态不能被改写或省略。未知层级按最低显示优先级处理，不抢前台。
- 颜色只复用既有令牌：锚点与正文 `--fence-text`、轨道 `--fence-border`，语义色只用于运行 `--fence-active`、待确认 `--fence-warning`、失败 `--fence-error`，不新增颜色令牌。
- 播报节点常驻 `role=status`、`aria-live=polite`，整体播报「来源 · 短词 · 关键值」；连续进度只在 `25%`、`50%`、`75%`、完成与失败时播报；新增锚点不抢焦点、不打断当前播报，下一次播报带「新增 N 条」，当批新增先计入、实际播报后才消耗。

### 叠加与排序

- 内容按层级分层：拖放 `drop` > 确认 `confirm` > 消息 `message` > 普通事件 `event` > 常驻 `resident`（插件卡）。
- 处于前台的内容按上述层级选择。同层级的新锚点不抢占当前项；消息通知到达可收起胶囊内的音乐内容，不影响播放与进度。
- 消息通知在同一枚锚点更新主信息，换文沿用锚点内滚动；不再有跨消息来源的锚点接力。条目顺序和胶囊摘要见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。

### 边界规则

- 拖放：接收态在锚点行前插入一枚接收锚点，锚点换松手图标，主信息固定为「松开加入收集箱」「交给音乐播放」或「无法接收」；没有匹配目标时松手回退且不执行。投放期间不按悬停消抖或透明边距退回。
- 系统隐藏恢复：隐藏期间收到的通知恢复时一次并入同一 bell，不单设计数锚点、不逐条补播；到期和去重规则按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 通知超时按条目计算，阅读期间暂留、回常态后再清理；失败和待确认不超时。保留和已读规则按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 展开消息卡仍按 [ADR-0039](0039-浮岛消息呈现.md) 读取原生投影并暂存阅读内容，不延长原生队列期限。
- 数据过期：内容层不单独标识过期，是否显示过期由插件状态决定。

### 音乐胶囊的固定内容盒

- 音乐胶囊有媒体会话时仍按播放状态与贴边方向选固定内容盒，不按当前句文本收缩：横向播放中 `240`、暂停 `168`；竖向播放中 `176`、暂停 `96`（竖向最小 `52`）。固定件 `52` = 内边距 `8 × 2` + 锚点圆 `28` + 间距 `8`，内容盒 = 档位 − `52`（横向 `188` / `116`，竖向 `124` / `44`）。
- 歌词长短、晚到或消失都不重新测量、不提交 `set_island_state`；滚动只用合成层的 `transform` 更新位移，减少动效时改为单行截断。
- 「浮岛宽度跟随内容」只指锚点集合或主信息变化引起的自然收放，不包括固定盒内的歌词换句。hover 详情的最大宽度按 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)；hover 窗口仍取胶囊态与 hover 内容区的并集。

### 契约与职责边界

- 纯模型 `src/features/island/islandContent.ts` 负责锚点身份与顺序、状态、层级、hover 选中、折叠与空态及拖放文案；`islandMessages.ts` 负责通知条目身份、合并、期限与锚点投影（见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)）。模型不依赖 React、不读 DOM、不持有定时器，时间由调用方传入。
- 契约 `src/contracts/island.ts` 的 `IslandStateRequest.anchors` 可选，只由常态提交胶囊锚点行的实测圆形区域；悬停列表与展开卡片不提交几何。锚点上限 `4`（三枚并排加一枚「＋N」），校验宽高相等、半径等于半边长（`0.5 DIP` 容差）且落在窗口盒内；非常态携带锚点即拒绝（空数组的归一化差异见下）。
- 常态仍必须恰好一个胶囊卡片区域：原生拖动中心与窗口夹紧按卡片区域计算，锚点行另由 `anchors` 承载，不改变拖动与落点语义。Rust `IslandStateRequest::validate` 与 TS 同文案门禁，旧载荷经 `serde(default)` 兼容。
- 原生不为内容层维护状态机：三态仍由页面实测并调用 `set_island_state` 提交；原生只校验并接受锚点几何，不改拖动中心与夹紧。
- 投放事实由 Rust 纯决策产生：只发 `{active, kind:"collect"|"reject"}` 两类 typed fact，页面唯一适配点把 `collect` 映射为收集箱接收态、`reject` 映射为「无法接收」、`active=false` 映射为回落。收入效果与源是否允许复制由 Rust 决定，页面只呈现。
- 渲染层不伪造原生行为：内容事实、状态声明与拖放目标可作为属性注入，用于断言页与后续接入；生产入口只渲染 `<IslandPage />`，不传这些属性。

### 契约归一化差异

- 非常态携带 `anchors: []` 时，TS 按「字段存在即拒绝」拒绝空数组，Rust 反序列化补默认后只拒绝非空数组。生产不发送该载荷（渲染层只在常态注入 `anchors`），这是两端的归一化差异而不是缺陷。

## 原因与职责边界

一排锚点让不同功能在胶囊并存，前台内容切换不必清空其他功能；每个锚点保留稳定身份与层级。消息类只共享一个身份，避免不同来源耗尽胶囊锚点位。

职责划分按「谁持有事实」决定：状态与内容事实来自各业务模块与原生队列，内容层只做纯投影；锚点几何由页面实测后提交，原生只校验与保存；拖动中心、窗口夹紧与投放效果仍归原生。这样内容层可以独立单测，也能在断言页注入十态而不需要为每种状态构造生产场景。

音乐胶囊保留固定内容盒，是因为播放中的歌词按句更新：若宽度随每句文本收缩，窗口会在播放过程中持续抖动并反复触发原生提交，违背「避免逐句重设窗口」的既有约束。固定内容盒让换句只在盒内滚动，与「宽度跟随内容」不矛盾——后者约束锚点集合变化，不是歌词逐句。

## 后果

- 契约新增可选 `anchors`（常态锚点行几何），TS 与 Rust 双端门禁；胶囊与 hover 的渲染从按卡摘要改为一排锚点与提供者内容。
- 新增纯模型 `islandContent.ts` 承载锚点身份、十态、叠加与边界语义，渲染层只消费其结果。
- 音乐保留活动锚点，插件卡保留常驻锚点；原生消息、天气变化与收集箱新增共享一枚通知锚点，见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- hover 根据选中锚点提供不同详情，插件可自绘；通知列表、宽度与独立显示开关由 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 规定。
- 投放事实带类型，「无法接收」在生产可达；音乐投放没有产品能力与原生事实（见「已知边界」）。
- 本文与 [浮岛](../design/浮岛.md) 保留通用内容层规则；[ADR-0046](0046-浮岛消息通知锚点与显示开关.md) 接管消息合并、隐藏恢复、通知期限、hover 宽度与紧凑两态的逐功能显示。

## 已知边界与待验证

### 已知边界

- 生产内置卡与消息覆盖 `pending`、`running`、`paused`、`disconnected`、`indeterminate`、`failed`、`completed`；`awaiting`、`cancelled`、`unauthorized` 没有生产者，插件扩展状态没有内容事实契约入口。
- 音乐投放没有产品能力与原生事实：`kind` 只有 `collect` 与 `reject`，页面仅在注入 `dropFact` 时能渲染「交给音乐播放」的同一分支，不记为原生可达。音乐投放需要独立的收入语义（入队、去重、队列满反馈、与音乐会话绑定），属于独立产品决策。
- 完全隐藏期间到达后离场、且没有被页面收到或出现在恢复快照中的消息，不会被重建。恢复统一并入 bell，见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 活动锚点被折进「＋N」时，胶囊主信息以裸文本呈现，不走接力或换文滚动。
- hover 内容行不是音乐艺人的唯一来源，渲染层从宿主媒体事实补充这一行。

### 待验证

- 真机确认胶囊锚点行在四边与两形态下的命中、拖动、单击展开，hover 锚点列表的指针与键盘切换、`Enter` 进入，以及控件焦点描边。
- 真机确认真实文件拖到未启用收集箱的浮岛时出现「无法接收」，移出或松手后回落原内容；拖到已启用收集箱时出现「松开加入收集箱」并完成收入。
- 真机待确认音乐在锚点行的宽度、截断与滚动，特别是固定内容盒在换句、歌词晚到与消失时不提交窗口。
- 真机待确认锁屏、截图与全屏隐藏后的通知恢复；边界见 [ADR-0046](0046-浮岛消息通知锚点与显示开关.md)。
- 十态与插件扩展的生产接入契约（内容事实、状态声明），以及折叠进「＋N」的活动锚点是否补接力或补断言。
