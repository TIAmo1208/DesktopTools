# 收集项以 Markdown 文件为事实

收集项的事实是配置目录下 `collect` 中的一份 Markdown 文件。默认文件名为创建时刻 `年-月-日-时-分-秒.md`（Windows 文件名不能使用冒号，时分秒用连字符分隔），创建后可改名；同一秒重名时后续文件加 `-2`、`-3`。该条引用的图片等文件放在与 Markdown 同主名的旁侧资源目录。置顶表 `pinned.txt` 保存已置顶收集项相对 `collect` 的路径；重命名收集项时同步该表。更改配置目录时把整个 `collect`（含资源目录与 `backup`）一并迁到新目录。

工具区「新建」生成一份默认名空文件并打开收集项编辑窗。从其他位置把文本或图片拖到收集箱格子时，先展开并显示内部条目：释放在某条收集项上则写入该文件，释放在格子其他位置则新建收集项。

应用内重命名同步移动同主名资源目录，并转换 Markdown 链接目标中的本条资源路径；正文、代码片段和外部 URL 中的相同文字保持原样。转换由 Rust 的 Markdown 解析器按源码范围执行，磁盘内容与编辑器草稿共用规则。草稿转换只返回编辑器，不因重命名保存未提交内容；转换期间禁用输入，成功后清空含旧路径的编辑撤销历史并保留原有未保存状态，防止后续保存或撤销写回旧资源路径。磁盘正文使用同卷临时文件原子替换，避免转换写入失败时截断原文。

收集项编辑窗内 `Ctrl+V`：文本按原样写入；普通 URL、Markdown 链接和 HTML 链接均支持粘贴为 Markdown 链接，并把光标放在名称位置；图片按当前收入方式处理。图片收入方式由设置页功能项提供，工作区共用，为复制到该条资源目录、移动到该条资源目录、或保留原文件只写入链接，默认复制。允许跨卷移动；严格执行所选收入方式，复制或移动失败不回退到其他方式，通过现有消息通知显示对应错误，避免实际文件操作偏离用户选择。编辑窗内已渲染图片的右键菜单提供复制到资源目录、移动到资源目录。写入资源目录的图片在 Markdown 中使用相对路径。

条目右键提供置顶和删除；格子菜单恢复最近一次删除。删除时将 Markdown 文件和同主名资源目录移动到 `backup` 下的删除包，保留原文件名，并在删除包内写入 `info.json`，记录原文件名、删除前是否置顶和删除时间；`backup` 最多保留 10 个删除包，超出时删除最久的删除包及其信息。恢复最近删除项时按 `info.json` 移回原文件名、资源目录并恢复删除前的置顶状态，使恢复结果保留原条目身份及资源关联。恢复时遇到同名文件或资源目录冲突直接失败，不覆盖现有内容。
