# 收集箱作为临时中转站并按内容类型取出

## 已确认决策

收集箱用于临时收入、直观查看、复制取出和主动清理，不以长期文档管理为目标。文本继续以 Markdown 保存，但不再要求所有内容都表现为 Markdown 文档：独立图片直接展示，普通文件以路径映射收入，避免为了中转重复存储文件。多个格子继续共享集合。

### 收入与类型

- 想法通过新建文本项记录；文本、链接拖到空白处新建文本项，拖到已有文本项则追加到末尾。
- 单张或多张图片拖到空白处，一张图片生成一项并直接展示图像；拖到已有文本项则插入正文，不拆成独立图片项。独立图片固定复制到 `collect` 根目录，保留源文件；无路径图像在根目录保存为 PNG。文档插图沿用文档同名资源目录及原有复制、移动、仅链接设置，两条路径分开处理。
- 普通文件以源路径映射为独立项，收入不复制源文件，不包含文件夹。删除映射只移除收集箱记录，不删除源文件；源文件移动、改名或删除后显示不可用，不自动追踪源路径。

### 复制取出与清理

- 支持单选、多选拖出，只提供复制语义，始终保留原条目；整理后的删除由用户主动执行。路径可用或拖放结束均不是外部目标已保存成功的证明。
- 文本拖到文件夹时复制原始 `.md` 与配套资源目录，维持图片相对引用；多选时保持多个独立文件，不合并成一份文档。
- 文本拖到输入框或文本编辑器时默认提供可读纯文本，去除标题、强调等 Markdown 标记，保留段落、列表结构、代码内容和链接地址；多选按列表顺序用空行拼接，不使用有长度截断的列表摘要作为完整拖出正文。
- 独立图片拖出提供实际图片文件；文件映射项拖出前检查源路径可用，再提供源文件复制。检查与目标实际读取之间仍可能发生源文件变化，失败不能报告复制成功或移除条目。
- 外部目标选择接受的数据表示，不按聊天软件或编辑器名称猜测格式。图片与文本混选拖到聊天软件不承诺通用支持，常用目标的接收行为须实机验证。

### 选择、呈现与清理交互

- 单击选择，Ctrl 增减选择、Shift 范围选择；双击、Enter 或右键“打开”打开单项。文本使用已有编辑窗，图片与文件映射交给系统默认程序。每个格子的选择独立，拖动已选项保留多选，拖动结束不触发打开。
- 单列呈现三类条目；格子右键菜单提供“混排”“分离”切换，分离以分隔线划分不同类型，不创建类型标签页。右上角菜单提供复选筛选条件，采用 Mantine `Menu.CheckboxItem` 的交互形式。分组与筛选只改变呈现，不改变共享内容事实。默认混排；分离按文本、图片、文件映射顺序分组，各组内置顶优先，再按当前排序，保持类型分区且复用既有排序能力。
- 筛选条件为文本、图片、文件映射，默认全部勾选，切换时保持菜单打开。允许全部取消，显示“无匹配收集项”并提供“重置筛选”，与共享集合为空区分。筛选隐藏的条目取消选择，`Ctrl+A` 仅选择可见项，避免操作不可见内容。
- 排列与筛选按格子独立保存并跨重启保留，允许多个格子呈现不同视图而不拆分共享集合；选择集合只在会话内存在，不持久化。
- 保留展开态固定空白投放带，拖入时才显示新建反馈；只突出实际命中的追加或新建目标。折叠保持 56 高基线，文本展示最新标题与摘要，图片和映射展示名称与类型。
- 单选、多选清理均先确认共享范围及分类数量，默认聚焦取消；文件映射只移除记录，不删除源文件。只移除成功项，失败项保留选择并报告。三类条目共用最多 10 个删除包，按条目逐项恢复原身份与置顶状态；独立图片连同所属本地文件恢复，文件映射只恢复记录、不操作源文件，恢复冲突拒绝覆盖，不提供整批一键恢复。
- 文本导出保留原文，资源引用保证范围限定为目标无同名冲突的条目自有相对资源；外部链接保持原样，不收集或改写。外部程序独立重命名正文或资源目录时不承诺引用有效。
- 收集箱之间（含同一格子）按条目类型复制或追加，原项保留：文本到文本项追加，图片到文本项插入，空白处创建独立项；不把内部文本误收成 `.md` 文件映射。
- 文本收集项存在编辑窗时拒绝外部或收集箱之间的正文追加，提示先关闭编辑窗；不依赖未保存状态同步，不覆盖编辑草稿。该拒绝属于单项操作失败，不缓存为目标类型拒绝，其他匹配条目继续处理。

### 部分投放与拒绝复用

收集箱单次操作跳过不匹配项，继续处理匹配项，不因一个拒绝项放弃整组；同次操作中某类型被目标拒绝后，后续同类型项直接跳过，避免重复判断。完成反馈区分已处理、跳过与失败，不宣称整批成功，拖出始终保留原条目。

类型拒绝按文本、图片、普通文件、目录或不支持类型区分，只在一次操作的同一实际目标（格子实例及命中文本项、非文本项或空白）内复用；目标变化后重新判断。图片项与文件映射项不接收追加，普通文件落在文本项不改投空白，按不匹配跳过。单项路径失效、权限、读取或写入失败不能推定整类不受支持。

独立图片与普通文件混合收入时，严格执行图片复制和文件仅映射；只有命中文本文档时图片插入沿用原收入设置，记录本地逐项结果，不向来源报告整批移动，也不让来源删除未移动项；源端实际反馈须实机验证。外部目标未提供逐项结果时，不虚构拒绝类型或成功项，不通过拆成多次隐式拖放模拟确认。

### 实施与验证边界

上述 UX、混排／分离、复选筛选、选择、部分投放规则及 UI 视觉稿均已确认；前端已实现三类呈现、格子独立视图状态、选择与清理确认，后端已接入独立条目目录、删除恢复及系统默认打开。内部文本与自有资源复制、独立图片／映射复制、部分投放及编辑状态拒绝已有业务层自动化覆盖；编辑窗实际生命周期、指针取消、Windows 复制拖出与外部目标仍待实机验收。

当前实现采用根目录 Markdown 与图片文件、文件映射 `collect/items/<item-id>/info.json` 的当前版本结构，不提供旧格式迁移层。根目录图片以实际文件名作为身份，沿用带后缀的冲突命名并独占创建，保留扩展名以支持系统默认打开。扫描只列根目录图片，不将文档资源重复列为独立项；删除恢复沿用最多十份删除包，冲突拒绝覆盖。映射记录保留 `sourcePath`，源文件失效时保留记录并显示不可用。

## 当前 Markdown 实现与保留约束

本节描述文本项的 Markdown 正文编辑、原子保存、资源关联及删除恢复约束；独立图片与文件映射使用上节的独立条目结构，不套用文本文件身份。

文本收集项的事实是配置目录下 `collect` 中的一份 Markdown 文件。默认文件名为创建时刻 `年-月-日-时-分-秒.md`（Windows 文件名不能使用冒号，时分秒用连字符分隔），创建后可改名；同一秒重名时后续文件加 `-2`、`-3`。该条引用的图片等文件放在与 Markdown 同主名的旁侧资源目录。置顶表 `pinned.txt` 保存已置顶收集项相对 `collect` 的路径；重命名收集项时同步该表。更改配置目录时把整个 `collect`（含资源目录与 `backup`）一并迁到新目录。

工具区「新建」生成一份默认名空文件并打开收集项编辑窗。拖入时临时展开并显示条目：文本和图片落在文本项时追加，落在图片或映射项时跳过；空白处按内容类型新建。普通文件落在文本项时跳过，不改投空白。真实 OLE 场景待验收边界见[格子内容拖放验收](../validation/格子内容拖放验收.md)。

拖入追加读取磁盘最新正文，拖入与编辑保存共用同卷临时文件原子替换，写入失败不截断已有正文。无路径图像先有界验证再新建条目；图片文件按顺序收入并提交每项引用，失败报告已收入数量与已落盘资源位置，不宣称批量原子完成。`BI_RGB` 32 位 DIB 的保留高字节不当作透明度，按 RGB 写入 PNG。

拖入由统一原生宿主按目标策略分流，收集业务负责文件与资源写入，不依赖独立桌面中不存在的 Tauri 窗口拖放监听。同一数据对象只收入一种表示，优先级为本地文件、图像数据、明确 HTTP(S) 链接、普通文本。文件集合逐项处理图片和普通文件，目录跳过，失效路径报告单项失败；格式读取失败不静默改选另一种表示。图像数据支持 PNG 和未压缩的 24/32 位 DIB，正文上限 1 MiB、原始图像上限 32 MiB、解码像素上限 64 MiB、文件集合上限 512 项。边界用于限制外部数据的内存与执行开销，不是所有第三方格式均可收入的承诺。

文档插图遵循既有复制、移动、仅链接偏好，复制或移动目标为文档同名资源目录；独立图片固定复制到根目录，不受该偏好影响。无路径图像按命中目标写入文档资源目录或根目录。HTTP(S) URL 保存 Markdown 链接，不下载远程图片；只提供 HTML 的来源不接收，有纯文本表示时按文本收入，不执行任意 HTML。收集失败保留原条目内容并通过现有消息管道报告，已完成资源操作与未完成操作应保持可追踪，不能虚报整批成功。

应用内重命名同步移动同主名资源目录，并转换 Markdown 链接目标中的本条资源路径；正文、代码片段和外部 URL 中的相同文字保持原样。转换由 Rust 的 Markdown 解析器按源码范围执行，磁盘内容与编辑器草稿共用规则。草稿转换只返回编辑器，不因重命名保存未提交内容；转换期间禁用输入，成功后清空含旧路径的编辑撤销历史并保留原有未保存状态，防止后续保存或撤销写回旧资源路径。磁盘正文使用同卷临时文件原子替换，避免转换写入失败时截断原文。

收集项编辑窗内 `Ctrl+V`：文本按原样写入；普通 URL、Markdown 链接和 HTML 链接均支持粘贴为 Markdown 链接，并把光标放在名称位置；图片文件按当前收入方式处理。“图片文件收入方式”位于设置页的收集箱二级页面，不属于本地时间；工作区共用，为复制到该条资源目录、移动到该条资源目录、或保留原文件只写入链接，默认复制。允许跨卷移动；严格执行所选收入方式，复制或移动失败不回退到其他方式，通过现有消息通知显示对应错误，避免实际文件操作偏离用户选择。编辑窗内已渲染图片的右键菜单提供复制到资源目录、移动到资源目录。写入资源目录的图片在 Markdown 中使用相对路径。

条目右键提供置顶和删除；格子菜单恢复最近一次删除。删除时将 Markdown 文件和同主名资源目录移动到 `backup` 下的删除包，保留原文件名，并在删除包内写入 `info.json`，记录原文件名、删除前是否置顶和删除时间；`backup` 最多保留 10 个删除包，超出时删除最久的删除包及其信息。恢复最近删除项时按 `info.json` 移回原文件名、资源目录并恢复删除前的置顶状态，使恢复结果保留原条目身份及资源关联。恢复时遇到同名文件或资源目录冲突直接失败，不覆盖现有内容。
