# 频谱条带显示验收

## 结论与范围

音乐控件的实时频谱已从「覆盖封面」改为不遮挡封面的独立条带：宽布局位于右栏信息下方，宽为右栏宽度、高 `18px`；紧凑与最小布局贴在内容底边，封面高度为内容高度减 `18px`；关闭开关时条带整行不占位，最小内容回到 `168 × 94px`。本次验收在真实桌面宿主中完成了尺寸、位置、静音基线与 CPU 取值，四态截图均来自宿主页面（CDP `9222`），非页面预演。

- 验收结论：尺寸与位置、关闭态无残留、浅色/自定义强调色柱色、静音与暂停基线、CPU 开关对比均通过；「无会话」状态因宿主机上存在正在播放的用户媒体会话（`cloudmusic.exe`）而未独立构造，列入未覆盖范围。
- 环境：Windows 10 `10.0.19045`，AMD Ryzen 5 5600G（12 个逻辑处理器），双 `2560 × 1440` 显示器；宿主页缩放 `100%`（`devicePixelRatio = 1`）。Debug 构建（`build/target/debug/desktop-tools.exe`）+ `npm run dev` 页面，真实媒体会话为 `cloudmusic.exe` 播放带封面曲目。
- 取证方式：宿主以 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 启动，在 `9222` 端口下取 `?desktop-host=1&monitor=0` 页面，用 CDP `Runtime.evaluate` 读取布局与画布像素，用 `Page.captureScreenshot` 的 `clip` 按格子矩形截图。

## 布局量测

量测值为 CDP `Runtime.evaluate` 返回的 `getBoundingClientRect()` 结果（CSS px，保留两位小数，`devicePixelRatio = 1`）。取数表达式原文：

```js
(() => {
    const px = (value) => Math.round(value * 100) / 100;
    const rect = (element) => {
        const box = element.getBoundingClientRect();
        return { x: px(box.x), y: px(box.y), width: px(box.width), height: px(box.height), right: px(box.right), bottom: px(box.bottom) };
    };
    const find = (selector) => document.querySelector(selector);
    const control = find(".music-control");
    if (!control) return { ready: false };
    const tile = control.closest(".desktop-tile");
    const content = control.closest(".official-component__content");
    const artwork = find(".music-control__artwork");
    const body = find(".music-control__body");
    const metadata = find(".music-control__metadata");
    const spectrum = find(".music-control__spectrum");
    const actions = find(".music-control__actions");
    const canvas = spectrum?.querySelector("canvas") ?? null;
    const style = getComputedStyle(control);
    const box = (element) => (element ? rect(element) : null);
    const gap = (a, b) => (a && b ? px(a - b) : null);
    const controlRect = rect(control);
    return {
        ready: true,
        theme: document.documentElement.dataset.desktopTheme,
        layout: control.dataset.layout,
        artworkState: control.dataset.artwork,
        spectrumState: control.dataset.spectrum,
        fontSize: style.fontSize,
        padding: { top: style.paddingTop, right: style.paddingRight, bottom: style.paddingBottom, left: style.paddingLeft },
        min: { width: style.minWidth, height: style.minHeight },
        tile: box(tile),
        content: box(content),
        control: controlRect,
        artwork: box(artwork),
        body: box(body),
        metadata: box(metadata),
        spectrum: box(spectrum),
        actions: box(actions),
        canvas: canvas ? { ...rect(canvas), bitmapWidth: canvas.width, bitmapHeight: canvas.height } : null,
        gaps: {
            metadataToSpectrum: spectrum && metadata ? gap(rect(spectrum).y, rect(metadata).bottom) : null,
            spectrumToActions: spectrum && actions ? gap(rect(actions).y, rect(spectrum).bottom) : null,
            artworkToSpectrum: spectrum ? gap(rect(spectrum).y, rect(artwork).bottom) : null,
            spectrumToControlBottom: spectrum ? gap(controlRect.bottom, rect(spectrum).bottom) : null,
            bodyToSpectrum: spectrum ? gap(rect(spectrum).y, rect(body).bottom) : null,
            bodyToControlBottom: gap(controlRect.bottom, rect(body).bottom),
            actionsToControlBottom: gap(controlRect.bottom, rect(actions).bottom),
            artworkToControlBottom: gap(controlRect.bottom, rect(artwork).bottom),
            metadataHeight: rect(metadata).height,
        },
        colors: {
            canvas: canvas ? getComputedStyle(canvas).color : null,
            body: getComputedStyle(body).color,
            fenceText: getComputedStyle(find(".fence-workspace")).getPropertyValue("--fence-text").trim(),
            desktopAccent: getComputedStyle(document.documentElement).getPropertyValue("--desktop-accent").trim(),
        },
    };
})();
```

## 静音与暂停基线

画布像素取数表达式（对条带 canvas 逐像素统计非透明行、列、连通列组、alpha 与颜色直方图；行/列/alpha 字段在全部样本中使用，颜色直方图为最终证据版本）：

```js
(() => {
    const canvas = document.querySelector(".music-control__spectrum canvas");
    if (!canvas) return { present: false };
    const width = canvas.width;
    const height = canvas.height;
    const data = canvas.getContext("2d").getImageData(0, 0, width, height).data;
    const rowCounts = new Array(height).fill(0);
    const columnCounts = new Array(width).fill(0);
    const alphas = new Set();
    const colors = new Set();
    const histogram = new Map();
    let painted = 0;
    let topRow = height;
    for (let y = 0; y < height; y++) {
        for (let x = 0; x < width; x++) {
            const index = (y * width + x) * 4;
            const alpha = data[index + 3];
            if (!alpha) continue;
            painted++;
            rowCounts[y]++;
            columnCounts[x]++;
            alphas.add(alpha);
            const key = `${data[index]},${data[index + 1]},${data[index + 2]}`;
            colors.add(key);
            histogram.set(key, (histogram.get(key) ?? 0) + 1);
            if (y < topRow) topRow = y;
        }
    }
    // 连续有像素的列组数，用来核对实绘段数。
    let segments = 0;
    for (let x = 0; x < width; x++) if (columnCounts[x] && !columnCounts[x - 1]) segments++;
    const paintedRows = rowCounts.flatMap((count, row) => (count ? [row] : []));
    const css = canvas.getBoundingClientRect();
    return {
        present: true,
        css: { width: Math.round(css.width * 100) / 100, height: Math.round(css.height * 100) / 100 },
        bitmap: { width, height },
        devicePixelRatio: window.devicePixelRatio,
        paintedPixels: painted,
        paintedRowCount: paintedRows.length,
        paintedRows,
        topPaintedRow: painted === 0 ? null : topRow,
        bottomPaintedRow: painted === 0 ? null : Math.max(...paintedRows),
        paintedColumns: columnCounts.filter(Boolean).length,
        segments,
        alphas: [...alphas].sort((a, b) => a - b),
        colorHistogram: [...histogram.entries()].sort((a, b) => b[1] - a[1]).slice(0, 6),
        maxRowWidth: Math.max(...rowCounts),
    };
})();
```

| 状态 | 会话事实（`get_current_music_session`） | canvas | 绘制像素 | 非透明行 | 非透明列 | 连通列组 | alpha |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 播放（宽布局） | `cloudmusic.exe`，`playing`，带封面 | 236 × 18 | 1340 | 13 | 160 | 16 | 最大 191（约 75%） |
| 暂停 | 同会话，`paused`（点击宿主「暂停」） | 236 × 18 | 192 | 1（第 17 行） | 192 | 1 | 全部 77（约 30%） |
| 静音播放 | `chrome.exe` 的 `Silence` 会话，`playing`，循环播放全 0 WAV | 236 × 18 | 192 | 1（第 17 行） | 192 | 1 | 全部 77（约 30%） |

暂停与静音时条带高度保持 `18px`，画布仍为 `236 × 18`；只画底部 1 行、同色 `30%` 的基线，且基线宽 `192 = 12px × 16 段`、左右各留 `22px`，与「单段步进不超过 12px、宽度富余时整组居中」一致。

「无会话」下 `playing = false`，与暂停态进入同一分支（`!playing || peak < 0.002`），但本轮宿主机上 `cloudmusic.exe` 的用户播放会话始终存在，未构造出真正的无会话状态，详见「未覆盖范围」。

## CPU 开销

沿用频谱事件投递验收的 10 秒窗口口径：读取 `desktop-tools` 进程 `TotalProcessorTime` 前后差除以窗口时长（占单核百分比），另附桌面应用进程树（`desktop-tools` 及其 WebView2 子进程）同窗口取值。测量时音乐为真实播放（`cloudmusic.exe`），格子 `420 × 200`、16 段、30fps，频谱开关各两次宿主采样（开、关分别在同一 Debug 构建的两次宿主启动中测量）。

```powershell
$p = Get-Process -Id <desktop-tools pid>
$a = $p.TotalProcessorTime.TotalMilliseconds
Start-Sleep -Seconds 10
$p.Refresh()
$d = [int]($p.TotalProcessorTime.TotalMilliseconds - $a)
"host_cpu_ms=$d per_core_pct=$($d / 100)"
```

| 频谱 | 宿主进程 10 秒 CPU | 占单核 | 进程树 10 秒 CPU | 进程树占单核 |
| --- | --- | --- | --- | --- |
| 开 | 203 ms / 156 ms | 2.03% / 1.56% | 3595 ms | 35.95% |
| 关 | 141 ms / 141 ms | 1.41% / 1.41% | 157 ms | 1.57% |

按工单口径（宿主进程）开关差值为 `0.15–0.62` 个百分点；进程树差值约 `3.4` 秒，主要来自 WebView2 中持续 `requestAnimationFrame` 的条带绘制与合成，关闭开关后组件卸载、动画循环停止，整棵进程树回落到静态桌面水平。

显示层缩小后的相对变化：

- 绘制面积：宽布局 canvas 从原本与封面同框的 `148 × 148`（21904 px²）降为 `236 × 18`（4248 px²，约 19.4%）；紧凑 `176 × 18`（3168 px²）相对封面铺满的 `176 × 138`（24288 px²）约 13.0%；最小 `168 × 18`（3024 px²）相对 `168 × 94`（15792 px²）约 19.2%。旧实现的同口径 CPU 与绘制像素未在本次重新编译测量，比例为按当前几何换算。
- 段数裁剪：实绘段数为设置段数与 `floor(条带宽 / 3)` 的较小值。16 段时三档宽度上限分别为 78、58、56 段，不触发裁剪；只有选择 64 段时紧凑与最小布局才分别裁到 58、56 段。宽布局 236px、16 段时单段步进被 12px 上限截断（基线宽 `192 = 12 × 16`），这是面积之外另一项固定开销上限。
- 绘制像素：播放时宽布局条带每帧约 1340 个非透明像素，紧凑 200 × 190 浅色播放帧约 495 个；相比原封面框尺寸，柱子绘制量随条带面积等比下降。

## 未覆盖范围

- 「无会话」状态未独立构造：宿主机上存在用户正在播放的 `cloudmusic.exe` 媒体会话，关闭该应用才能得到空会话，会中断用户播放，因此未执行。该状态与已实测的暂停态共用 `playing = false` 的同一绘制分支，但没有独立的 CDP 证据，不计入已通过项。
- 旧「覆盖封面」实现的同口径 CPU、绘制像素与截图像素未复测（源码与二进制已替换）；条带面积比例按当前布局几何计算，不是改动前后的实测对比。
- CPU 只测了 16 段、30fps、Debug 构建与 100% 缩放；64 段裁剪只做了段数公式与基线宽度验证，未单独测 64 段下的绘制与 CPU；Release 构建未复测。
- 未覆盖 `devicePixelRatio ≠ 1`、非 13px 字号、多显示器同时存在音乐控件、系统减少动态效果开启等组合；截图只裁切格子矩形，未与桌面壁纸背景合成对照。
- 采集失败路径的绘制表现未做真机复测：本轮验收后按复审意见修复了失败入口不清缓冲导致的残柱淡出（`MusicSpectrum.tsx` 在 `startAudioSpectrum` 失败和订阅错误回调中清零 `target`／`smooth`），该路径需让回环采集失败才能构造，因此只由代码复核确认失败当帧进入 1px 基线分支，没有 CDP 证据；条带尺寸、段数裁剪与静音基线不涉及该改动。
- 应用数据（设置与工作区布局）在验收后已恢复原值：桌面深色、16 段、30fps、频谱开，音乐格子回到原 `329 × 136` 与悬浮标题。
