# 天气设置验收

## 当前实现

“功能格子 → 天气”以列表显示已配置来源：来源名、服务地址、认证模式徽标、可用状态与启用开关，右键菜单提供显示详情、检测可用与删除，底部为“添加 API”；添加与编辑共用弹窗，添加模式提供供应商分段控件，编辑模式只回填非敏感字段。弹窗内提供该来源的凭据字段、私钥导入与显隐、临时城市搜索、按来源声明的能力验证、保存并启用。只有 Rust 权威会话的完整验证通过才允许保存。凭据进入 Windows Credential Manager，按来源各一条记录；城市与验证响应只保留会话内存。

开关切换到已配置来源时只做一次当前天气存活探测，探测失败保持原来源且不写偏好；删除来源只清除该来源记录，删除当前使用来源不切换到其他配置。来源可用状态保存在运行期内存，配置保存或删除后回到未确认。

桌面天气格子已接入当前摘要、24 小时预报、7 天预报、紧凑来源更新时间和过期标记，并按实时格子宽高组合显示，拖动缩放期间即时切换布局；详情入口位于公共标题栏右上角，并保留右键菜单入口，通过系统浏览器打开和风城市搜索返回的 `fxLink`。格子启动时从独立天气城市缓存恢复当前城市，城市选择成功后保存，GeoAPI 搜索结果不落盘。

设置命令只对 `main` 设置窗口开放，后台任务按窗口代次和草稿会话身份拒绝迟到结果。HTTP 使用系统 TLS 校验，禁止重定向，连接超时 8 秒、单请求总超时 20 秒，解压后响应最多 512 KiB；JWT 按官方要求提前 30 秒签发，有效期 15 分钟。上述参数适用于用户主动验证，自动调度按独立规则实施。

## 缓存与调度

后端按配置指纹与城市标识保存最近成功模块，同一位置刷新替换对应条目，不覆盖其他位置或积累历史版本。条目仅保存 `cityId` 作为天气数据的归属，不保存历史城市对象或搜索结果；返回时使用本次所选城市补齐呈现字段。读取和写入清理全部条目中的七天过期模块，无成功模块的条目移除。清除凭据后的离线读取使用该城市最近写入且仍保留的结果；不提供旧缓存格式迁移，缺少集合按空缓存处理。

预报请求入口按城市和模块保存运行期退避；网络、读取失败、HTTP 5xx 与限流使用退避，认证、权限及无恢复时间的额度失败停止对应模块，重新验证并保存配置后清除。成功只清除对应模块退避，受限模块仍返回缓存及失败状态，不阻止其他模块更新。共享活动调度器在无展开实例时条件等待，按模块到期或退避截止点唤醒。

已保存配置的预报和城市搜索请求绑定运行期配置代次与共享取消标记；保存或清除凭据成功后取消旧请求并清空旧预报退避，保存失败保留旧请求身份和退避。配置保存或清除成功后通过 `weather-configuration-changed` 通知，天气内容先订阅再读取，只在展开、可见且未暂停时重新读取。缓存有效性同时检查模块获取时间与 Provider 的内容和时间窗规则，时间戳尚未到期也不能复用不足 24 小时、跨日后不再含今天的七天或字段损坏的数据。

本阶段范围为设置页与桌面天气格子。

## 已验证

- `cargo check --manifest-path src-tauri/Cargo.toml` 通过。
- Rust 全量测试通过 171 项，8 项按已有测试声明跳过；其中天气专项 6 项覆盖官方 Host 校验、Ed25519 验签、连续小时、城市时区及夏令时、保存门槛、窗口代次及凭据状态读取失败后的取消。
- Host 使用虚构地址测试单级、多级、不同中间标签、大小写、连字符及长度边界；拒绝非法标签、协议、用户信息、端口、路径、查询、片段、根域名和伪造后缀。不读取用户实际凭据，不以本地格式测试代替真实账户接入。
- Windows Credential Manager 使用独立测试目标实际执行写入、查询、超长替换拒绝及清除，不读取或修改用户天气凭据。
- 凭据读取失败回归使用空测试目标触发 Windows 读取错误，确认旧会话身份不影响当前草稿、匹配身份仍设置取消标记并释放草稿，且不提前解除在途请求互斥；返回状态读取错误不阻止取消生效。
- `npm test` 前端测试通过 112 项，类型检查和前端生产构建通过，Rust 开发构建通过。
- `src/features/settings/weatherSettings.browser.html` 在 Edge 中运行生产组件及 Tauri 替代桥，并使用 React StrictMode，结果为 `PASS`。断言覆盖输入不请求、重复验证拦截、保存失败保留草稿、成功后清空私钥、取消后的迟到成功无效、导航确认、最新状态关闭保护及清理后关闭；验证中通过导航或窗口关闭触发确认后，“继续编辑”可立即关闭确认并保留草稿和原验证请求。
- Windows 原生设置窗口在 960 × 640、浅色、100% 缩放下检查：天气入口、未配置字段、滚动后的能力区和禁用命令可见；输入草稿后标题栏关闭和分类导航均弹出放弃确认，继续编辑保留页面，放弃后完成导航。
- 真实和风账户返回当前天气、24 小时与含今天的 7 天预报；桌面天气格子的渲染、天气获取与数据显示经人工确认通过。实际返回的 `attributions` 为指向供应商署名页的 URL，城市 `fxLink` 指向对应城市详情页。
- 桌面预报与设置共用天气结构、摄氏单位及小时/日预报时间窗校验，覆盖连续小时按实际时间戳验证和日预报按城市 IANA 时区核对含今天的七天。
- 来源栏按当前、小时、日模块各自的获取时间与有效期显示过期状态；到期边界、隐藏恢复、旧回调隔离及清理，以及桌面响应未通过校验时按对应模块失败且不覆盖旧缓存，已有自动回归覆盖。
- 能力验证项按草稿来源返回名称与项数，和风五项、Foreca 四项，`Snapshot.checks` 逐项携带标签与失败原因，前端按后端返回渲染，不再硬编码检查项数量；后端仍按该来源声明的完整项数判定验证通过。
- 启用来源已接入普通偏好 `weatherSource`，缺省和风；Rust 天气状态按已保存来源派生凭据记录名与城市缓存路径，保存偏好时重算，来源变化时取消在途请求并清空旧退避。Rust 全量测试 189 项通过、8 项按原声明跳过；`npm run typecheck` 通过，前端契约测试 92 项通过。
- 来源列表状态、可用状态三态、切换来源返回实际变化均已覆盖：列表只返回已配置来源，未配置来源不出现；和风回显账户 API Host，Foreca 使用固定服务地址；`observe` 结果决定可用与不可用，配置保存与删除回到未确认。
- 天气测试使用独立凭据记录名前缀，构造 `WeatherState` 的测试不再经过 `DesktopTools/Weather`，测试保存、查询与删除只作用于本测试专用记录。
- 设置页浏览器回归在生产组件与 Tauri 替代桥下运行，结果为 `PASS`。断言覆盖空态、添加弹窗的供应商切换、输入不触发请求、重复验证拦截、保存失败保留草稿、保存成功切换到来源列表、编辑模式回填非敏感字段且不回读私钥、有修改时的未保存确认、右键菜单三项命令、探测后可用状态更新与删除确认。
- 界面修正回归覆盖：设置页文本不可选中而输入值可选中、弹窗本体不显示焦点轮廓、图标按键使用系统图标字体、私钥草稿使用多行输入并保留换行、字段说明浮层显示在弹窗内部且可见、弹窗打开时列表区不显示弹窗反馈、关闭弹窗后不残留上次反馈。
- Foreca 请求失败按状态码区分参数不合法、凭据无效、权限不足、位置未找到与限流，并记录状态码；API key 校验拒绝含空白、不可见字符、`Bearer` 前缀或超出长度的值。Foreca 签发的 API key 是长度约 400 字符的签名令牌，输入与校验上限已相应放宽到 1024 字符；此前 256 字符的上限会截断该密钥并导致认证失败。
- 天气设置的图标改用 `resources/` 下的 Lucide SVG 资源，不再依赖系统图标字体；说明浮层、弹窗反馈与文本不可选中的修正均有自动回归覆盖。

## 可重复检查

运行 `npm run tauri:dev`，从托盘打开设置，进入“功能格子 → 天气”。先填写一个字段，分别检查标题栏关闭、返回和分类导航；选择继续编辑应保留草稿，放弃应清除草稿并完成原动作。

开发服务运行时打开 `/src/features/settings/weatherSettings.browser.html`，页面应显示 `PASS`。这是替代桥交互验证，不证明真实供应商接入成功。
