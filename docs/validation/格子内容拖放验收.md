# 格子内容拖放验收

## 实现边界

依据 [ADR-0017](../adr/0017-分离系统拖放与布局投放结果.md)、[ADR-0021](../adr/0021-收集项以Markdown文件为事实.md) 与[视觉规范](../design/视觉规范.md)，宿主统一接收 OLE 数据，格子业务白名单与执行效果分别校验。收集箱使用现有条目和资源管理，音乐使用现有默认关联打开入口；未增加依赖、用户可编辑白名单或旧配置迁移。

“图片文件收入方式”位于收集箱设置，普通文本、明确 HTTP(S) 链接、图片文件与受支持图像数据按固定优先级收入一次。文档插图沿用资源目录及复制、移动或仅链接设置；空白处独立图片固定复制到 `collect` 根目录并保留来源，普通文件只记录映射。被拒绝的格子不能将内容透传到桌面。

编辑窗双击放大回归已验证 PNG/GIF 显示地址复用、原节点几何、原始引用不变及加载失败时不打开。`collectEditorImages.browser.html` 已补充真实 Vditor 双击、旋转、关闭、Markdown 保持及读取次数断言，尚未执行；需人工检查本地图片和 GIF 放大、动画播放、旋转后关闭、加载中与失败时双击，以及保存和撤销后引用保持。类型检查与前端构建通过，构建仍有既有大于 500 kB 的分块提示。

附件清理的 7 项 Rust 回归通过，覆盖归属证据、跨文档引用、放弃草稿基线、改名、嵌套资源、损坏记录、保守保留及真实系统回收站操作。真实编辑窗的保存关闭、放弃、取消、多窗口及外部编辑并发仍待人工验收。GIF 悬停原图分流与关闭拒绝迟到结果已有回归，动画播放、超限文件提示及关闭后的内存释放表现仍待实机确认；GIF 原图解码不受 768 像素上限约束。

以下场景尚未得到真实桌面交互结果，不能以单元测试或启动日志代替：

1. 从浏览器拖入普通文本、链接、图片数据：展开收集箱，落在条目上追加，落在格子空白新建；同一内容只收入一次，来源不被删除。
2. 从资源管理器和本程序桌面拖入图片文件：文本目标分别验证复制、移动、仅链接；空白目标验证根目录独立图片始终复制且保留源文件。核对资源目录、Markdown 引用和源端效果，失败不虚报成功。
3. 图片混入普通文件、多个媒体文件、目录、仅 HTML、损坏或超限数据：按目标类型处理匹配项，跳过不匹配项并汇总失败；普通文件在收集箱空白处创建映射，目录不收入，不穿透目标。
4. 单个受支持媒体文件拖入音乐格子：由默认关联程序打开，媒体状态依赖既有会话，不承诺自动播放。
5. 跨显示器及混合 DPI、重叠格子、条目滚动或展开、释放前禁用或删除目标：只命中当前有效可见目标；离开、取消、释放均结束临时展开。
6. 回归桌面、围栏和文件夹门户既有文件复制、移动、内部布局、源端反馈与长传输响应性。
7. 收集项多选复制拖出到文件夹、文本编辑器及其他实际目标，核对源项保留、完整文本和配套资源，不以 OLE 结束宣称外部保存成功。
8. 文本编辑窗开启、关闭及重命名期间拒绝正文追加；原生宿主内确认删除模态焦点、背景命中阻挡及取消；混合 DPI、真实壁纸与主题可读性。
9. 原生宿主独立图片列表显示静态缩略图，滚动离屏及折叠停止加载，混合 DPI 下按显示尺寸请求；GIF 悬停播放原图，非 GIF 悬停使用有界缩略图。验证离开、折叠、拖动、失焦和销毁后关闭浮层，迟到读取不得恢复图像；编辑窗仍可显示原图及 GIF 动画。选择条目后移入文档可悬停预览，拖动和模态期间不触发预览。
