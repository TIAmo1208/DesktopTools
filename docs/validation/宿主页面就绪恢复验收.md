# 宿主页面就绪恢复验收

## 变更范围

恢复线程新增提交前页面就绪监视：未就绪宿主在导航完成后超过宽限期（15 秒）、导航长期未完成（120 秒）或前端上报资源加载失败时才轻量重载，连续重载按 5/10/20/40 秒退避；已提交宿主的心跳重载使用同一退避。页面导航进度由原生 `PageLoadEvent` 记录，`about:blank` 占位页不计入就绪等待基准。

## 验收方法

- 单元测试：`cargo test --manifest-path src-tauri/Cargo.toml --all-targets`，覆盖宽限期、导航兜底上限、失败报告、退避与封顶判定。
- 运行时观察：Debug 构建 `npm run tauri:dev`，读取 `%LOCALAPPDATA%\TIAmo\DesktopTools\<日期>.log` 的启动时间线，核对重载日志与接管提交时间。
- 通过 CDP（`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`）读取宿主页面 `document.readyState`、资源条目数与桌面格子数量，确认页面实际渲染。

## 证据

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 双屏启动接管 | 20 秒宽限期打断仍在加载的页面，20 秒一次重载风暴，接管提交耗时 89 秒 | 无重载日志，导航开始 12:24:13、完成 12:25:05、同一秒提交接管 |
| 正常页面加载 | 首个页面请求在重载干扰下 12–29 秒未完成 | 页面手动重载 4 秒完成 249 个资源、11 个格子、126 个桌面项目 |
| 判定逻辑 | 仅按时间宽限 | 导航完成后的宽限、导航兜底、失败报告三种触发，均受退避节流 |

修改后本轮启动日志无 WARN/ERROR 级重载或失败记录，`Debug 测试` 格子显示阶段 `committed`、就绪 `2 / 2`。

## 未覆盖

- 页面持续加载失败（开发服务器长时间不可用）只验证了判定逻辑与退避单元，未做整机关闭服务器的长时运行验证。
- 开发模式首屏加载耗时约 50–65 秒属 Vite 冷启动与 WebView2 初始化开销，未在本次变更加以优化；本次只去除打断与重载风暴。
