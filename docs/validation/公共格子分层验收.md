## 状态与实现范围

状态：公共格子分层与收集箱统一创建已由用户手动验收通过；公共尺寸底线与围栏内容高度调整已完成自动测试，实际界面待用户验收。职责边界见 [ADR-0018](../adr/0018-共享格子外观并隔离布局撤销.md)，实际目录见[前端目录结构](../../src/README.md)。

本结论以用户总体反馈为依据，不虚构逐项测试数据，不推断混合 DPI、工作区无可用位置、全部异步取消时序及长时间资源表现均已验证。产品持久锁定和收集箱移除等不在前述测试清单内的变更不包含在本次验收结论中。自动检查记录保留各自证据范围，不替代用户实机反馈，也不自动覆盖并行改动。Windows 10 build 19045 启动日志确认两个宿主、每个宿主注册六个 OLE 投放窗口并完成桌面接管，仅证明启动事实。既有手动验证覆盖资源管理器双向拖动、桌面跨围栏投放、文件门户投放、跨屏项目释放和控件跨屏释放，不代表新增内容接收已通过实机验收。

- `DesktopTileBase` 统一装配几何、展开、标题拖动和八向缩放；业务宿主只提供身份、权威边界、最小尺寸及类型化回调。活动几何在捕获阶段处理 Escape，覆盖准备、拖动和跨屏释放等待，提交开始后不撤回领域命令。
- 围栏、门户、收集箱、音乐、时间和 Debug 内容归入 `tile-content`；跨类型工作区留在 `workspace`，插件注册、能力与失败隔离留在 `components`。业务命令、文件操作和视觉基线保持既有边界。
- 移动捕获一次结构化静态帧；源端向同一目标持续移动时只发送几何，切换目标重发完整帧。目标复用静态节点；结束取消待发送帧、移除预览，并拒绝最近已结束会话的迟到消息。缩放继续使用真实组件排版。
- 公共 `locked` 参数已覆盖指针、键盘几何和缩放柄；当前产品没有对应持久化字段或设置入口，不能据此声明已实现产品锁定。

## Windows 实机验收与复测范围

用户已反馈手动测试未发现问题。以下保留为围栏、文件夹门户、收集箱、音乐、时间和 Debug 的后续回归检查范围，不表示每个细分场景都有独立通过记录：

1. 标题移动、八向缩放、边缘吸附、折叠尺寸、临时展开、标题按钮及内容输入，确认浅色与深色外观保持现有规则。
2. 原生输入准备、拖动和跨屏释放等待中的 Escape、失焦及卸载；取消恢复源表面且不提交，正常释放只提交一次。
3. 本屏与跨屏往返、混合 DPI、边缘吸附、布局撤销和重做；以真实 Windows 指针捕获和原生宿主为依据。
4. 含多条收集项的连续跨屏拖动，核对静态帧传输、目标节点复用和结束资源释放，并记录卡顿及资源表现。
5. 围栏排序、滚动和 OLE 投放；目标格子拒绝文件投放时不向下层围栏或背景穿透；文件门户格子 Escape 取消修复复测；门户导航与真实文件进出；收集项编辑、排序和摘要；音乐控制与最小尺寸；时钟活动订阅；Debug 命令。
6. 分别从设置页、桌面背景菜单创建格子；将原格子调整为非默认展开尺寸并折叠后再次创建，检查新实例沿用统一可用位置和默认展开尺寸，原格子的 `collapsedSize` 与保存的展开边界不受影响；工作区没有可用位置时的实际错误反馈沿用现有工作区命令错误契约，多显示器临时投射表现一并确认。
7. 将围栏缩到下限，检查固定标题时整体为 168 × 142 DIP、悬浮标题时为 168 × 114 DIP，内容视口均至少为 164 × 110 DIP；标题模式切换后再用鼠标和 Shift+方向键缩放，确认几何提交、折叠与恢复一致。已有更大围栏不因切换标题而自动缩小。

## 保留边界与待决策事项

设置页与桌面背景菜单共用格子创建入口 `create_collect_box`，复用 [ADR-0023](../adr/0023-收集箱入口统一创建.md) 的 Rust 创建流程；入口不传入位置或展开尺寸，也不复制已有格子尺寸。公共参数继续保留默认值与显式覆盖能力，收集箱只通过 `collapsedSize` 覆盖折叠高度为 56px，不覆盖权威展开边界。统一创建已纳入本轮用户验收；工作区无可用位置和多显示器临时投射等未提供专项结果的异常边界继续保留待验证，沿用现有工作区命令错误契约。收集箱移除后的真实桌面焦点与快捷键恢复不包含在创建流程验收中，仍需实机确认。
