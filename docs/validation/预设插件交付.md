# 预设插件交付验收

## 结论

`plugin/` 预设插件已随 0.4.0 安装包打包，安装与卸载按当前生效插件目录处理：清单注册、目录解析、同版本跳过、按清单 `id` 卸载、插件目录迁移与指针格式均有临时目录单测覆盖，示例插件与插件文档通过静态检查。除「真实安装/卸载执行」受安全边界限制未执行外，验收项全部通过。

本机 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Desktop Tools` 已存在正式安装登记（0.3.0，卸载程序指向 `%LOCALAPPDATA%\Desktop Tools`）。按任务安全边界只构建安装包并做脚本级核验，未运行安装器或卸载器，未修改已安装程序与真实 `%APPDATA%` 数据。

项目门禁全部通过：`git diff --check`、`npm run typecheck`、`npm test`、`cargo test --all-targets`（268 通过 / 0 失败 / 9 忽略）。`npm test` 首次运行曾因 Vite 依赖扫描读取工作区 `build/weather-review-browser/`（本机遗留、已 gitignore 的浏览器配置目录）被系统拒绝（EPERM）而中断一次，静默环境下重跑通过，详见「问题记录」。

### 示例静态检查

- 三份入口 `plugin/*/index.js` 均通过 `node --check`。
- 三个示例均使用 `export default` 导出外壳对象。
- 源码与 `innerHTML` 字符串中无内联 `style="..."` 属性；字号通过 `tile-content--size-*` 类名切换，文本使用 `textContent` / `.value` 赋值。

### 文档一致性

- 安装目标统一表述为「当前生效插件目录」：指针优先、偏好解析、空偏好回退 `%APPDATA%\TIAmo\plugins`。

## 问题记录

- `npm test` 首次运行在 `src/features/components/OfficialComponentHost.test.ts` 中断：该测试以仓库根为 Vite root 创建开发服务器，依赖扫描读取 `build/weather-review-browser/` 下的历史浏览器配置目录时返回 `EPERM: operation not permitted`（复制、重命名同样被拒绝），扫描报出 20 条错误后判定构建失败；静默环境下重跑该文件与整套 `npm test` 均通过（依赖扫描仍打印 5 条 EPERM，但不再中断）。`git status` 显示本次改动不含任何 `src/` 或 Vite 配置文件，该失败与本任务改动无关，属于本机遗留目录引起的间歇性环境问题。建议清理或移走 `build/weather-review-browser*` 后重跑。
- 排查上述问题时曾尝试把 `build/weather-review-browser` 与 `build/weather-review-browser-25144` 整体移出工作区以绕开扫描；移动被系统拒绝，但其中 31 个文件随部分移动进入临时目录，清理临时目录时被一并删除。这些文件属于本机遗留的浏览器配置目录（已 gitignore，不是源码或用户数据），其余文件未再改动，该操作不影响本任务的验收结论。
- 首次安装包构建失败于 `failed to remove file build/target/release/desktop-tools.exe`：工作区存在运行中的 release 实例（`build/target/release/desktop-tools.exe`，PID 7064 及其 guardian，非已安装版本），锁住了该文件。未结束该用户进程，改为独立目标目录 `build/target-installer` 重新构建成功。
