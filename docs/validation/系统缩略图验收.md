# 系统缩略图验收

## 验收对象与状态

验收范围为桌面项目、围栏内项目及其原生拖动图像，目标是不显示音乐应用角标、视频胶片边框或快捷方式箭头。文件夹门户不在本次接入范围。决策见 [ADR-0005](../adr/0005-里程碑1验收边界.md)，显示规则见[视觉规范](../design/视觉规范.md)。

独立 Windows API 样本验证和产品接入已完成。源码以系统图标列表提供首帧，独立图像 STA 为可见项目提取内容；原生拖动使用已完成缓存，未命中时保留图标。自动化通过范围与仍需实机验收的范围如下，不能将构建或启动日志当作像素验收。

## API 样本证据

在当前机器的 STA PowerShell 进程中，通过 `SHCreateItemFromParsingName` 获取 `IShellItemImageFactory`，以 48×48 像素请求尺寸读取用户桌面的四个原文件。每个文件先请求 `SIIGBF_THUMBNAILONLY | SIIGBF_INCACHEONLY`，再请求默认、`SIIGBF_ICONONLY`、`SIIGBF_THUMBNAILONLY`；未清空系统缓存或修改原文件。16 次调用均成功，第一轮的四个缓存请求均命中。

| 样本 | 默认返回内容 | 实际位图尺寸 | 默认请求总耗时 | 人工检查结论 |
| --- | --- | --- | --- | --- |
| `[deadman] 116147787.png` | 图片内容 | 46×48 | 3 ms | 返回图片而非类型图标 |
| `周杰伦 - 倒影.flac` | 音频封面 | 48×48 | 2 ms | 封面中没有音乐应用角标 |
| `doro表情包GIF动图_爱给网_aigei_com.gif` | GIF 静态帧 | 48×48 | 2 ms | 返回静态画面，不是动画播放 |
| `oceans.mp4` | 视频帧 | 48×20 | 3 ms | 画面中没有视频胶片边框 |

缓存首读耗时范围为 8–37 ms；表中默认请求发生在缓存读取之后。耗时包含 Shell 项目解析、图像获取及 PNG 保存，只是单次观察值，不能作为纯 API、冷提取或批量性能基准。图像内容依赖系统处理器及文件内容，不能按扩展名推断所有文件必定成功。

原接口探针使用 `Image.FromHbitmap` 保存人工对照图，可能丢失 Alpha，因此不以该导出图的黑底或边缘评价生产渲染。本轮未重新执行这四个文件的独立探针；新增生产路径的半透明 PNG 自动测试，不能外推全部处理器。不同 DPI 和持续 GDI 资源占用仍需独立验证。

## 集成验收清单

- 待验收：初始系统图标可见后再更新缩略图，慢提取不阻塞桌面接管、打开或菜单操作。
- 待验收：桌面和平铺 48px、列表 36px 外框稳定；横图、竖图和透明图保持比例，名称与命中区域不移动。
- 待验收：没有封面、损坏、读取失败或提取超时仍显示可用系统图标，不将缩略图缺失等同于项目失效。
- 待验收：图片、GIF、音频、视频和快捷方式均符合装饰排除要求，特别核查快捷方式箭头；第三方处理器行为不能由四个样本外推。
- 待验收：原生拖动内容与静态图像一致，位图尺寸和指针偏移正确，跨屏 DPI 切换不会拉伸或错位。
- 待验收：文件修改、重命名、删除、暂停恢复及迟到结果不会导致旧图覆盖新图；LRU 和系统缓存配合，不新增常驻轮询。
- 待验收：无缓存与重复读取、大量文件、界面响应和 GDI 句柄回收；分别记录场景，不清空用户全局缓存来代替隔离样本测试。

## 官方依据

- [IShellItemImageFactory::GetImage](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellitemimagefactory-getimage)：返回策略、尺寸、线程提醒及资源所有权。
- [IThumbnailCache](https://learn.microsoft.com/en-us/windows/win32/api/thumbcache/nn-thumbcache-ithumbnailcache)：系统共享缓存及缩略图处理器。
- [Thumbnail Handlers](https://learn.microsoft.com/en-us/windows/win32/shell/thumbnail-providers)：`Treatment` 与 `TypeOverlay` 装饰机制；本项目不以补齐 Explorer 装饰为目标。
