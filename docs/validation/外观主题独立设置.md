## 当前行为与实现边界

- 外观页上下排列「桌面网格主题」「界面与菜单主题」，各自设置深浅模式、使用 Windows 主题色开关和自定义主题色；开启系统色时禁用该组色块，关闭后恢复保留的自定义颜色。
- 桌面主题覆盖未归类项目、文件围栏和功能格子。设置等普通界面、自绘右键菜单及子菜单使用界面主题；Windows 原生桌面、文件和托盘菜单由系统呈现。圆角、字体及字号继续共用。
- `ApplicationPreferences.desktopAppearance` 保存桌面主题；`theme`、`accentColor`、`useWindowsAccentColor` 保存界面与菜单主题。缺少桌面主题时，前后端均使用固定默认值：`system`、`#2563eb`、`false`。Rust 使用普通 `DesktopAppearance` 字段及 `Default`，不设置旧主题复制或迁移逻辑；两组随完整偏好原子保存，保存失败保留权威状态。
- `PreferencesProvider.tsx` 复用偏好广播和 Windows 强调色订阅，在各窗口分别解析两组主题。根节点的 `data-theme` 与 `data-desktop-theme` 控制各自深浅模式，`--interface-accent` 与 `--desktop-accent` 隔离强调色。
- `FenceWorkspace.css` 承载桌面主题，`DesktopTileMenu.css` 在菜单自身定义界面主题，不继承围栏配色。视觉规则见[视觉规范](../design/视觉规范.md)，排序入口职责见[围栏排序](../design/围栏排序.md)。
