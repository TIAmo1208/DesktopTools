# 界面动画控制

## 当前行为

- `followSystemReducedMotion` 默认值为 `true`。开启时保留并禁用 `interfaceAnimations`，实际动画在 Windows 未要求减少动态效果时开启，在系统要求减少动态效果时关闭。
- 关闭 `followSystemReducedMotion` 后恢复“界面动画”操作，实际动画立即使用保留的 `interfaceAnimations` 值，不再受系统减少动态效果状态影响。
- 围栏、文件夹门户和功能格子通过公共外壳执行同一折叠动效；设置导航收展、设置分类切换和音乐模式切换读取同一有效动画状态。
- 动画关闭时取消正在运行的格子折叠过渡并进入当前目标状态；设置分类切换不保留浏览器默认 View Transition 动画。
