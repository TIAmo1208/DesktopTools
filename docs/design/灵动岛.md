# 灵动岛

本文记录灵动岛的形态、尺寸与令牌。岛的定位、窗口、拖动与偏好归属见 [ADR-0036](../adr/0036-灵动岛作为独立呈现位.md)；主题可覆盖的外观项见[主题变量契约](主题变量契约.md)。

## 定位与令牌归属

岛是继透明桌面工作区、普通应用界面、原生消息之后的第四个独立表面：独立原生窗口与独立页面来源，置顶显示、不抢焦点，不在桌面宿主页面内，也不进工作区快照、布局与撤销。窗口与信任边界见 [ADR-0036](../adr/0036-灵动岛作为独立呈现位.md)。

它跟随桌面主题、使用 `--fence-*` 令牌而不是界面主题，这是令牌归属，不代表它属于透明桌面工作区；该域的三条禁止事项（大圆角、悬浮面板构图、装饰性阴影）对岛豁免。豁免范围只到卡片形状为止：仍不加投影、光晕或任何超出卡片形状的装饰。

## 三态

- 常态胶囊：高 `44 DIP`，宽随一行内容伸缩；内边距 `8`；媒体图 `28` 圆形。贴上下用横向胶囊，贴左右用竖向胶囊（宽 `44 ＝ 28 + 8 × 2`，高随竖排歌词字数，最小 `52`）。只读，不出现控制。
- hover：常态进入与 hover 回落都使用 `180ms` 延迟；延时内反向越过边界会取消原目标，避免边缘抖动。高 `72`，内边距 `12`，媒体图 `48`、圆角 `16` 跟随外框；只显示当前卡，出现基础控制，不出现完整内容。
- 展开：内边距 `16`；媒体图 `88`，与右侧信息列等高并保持 `1:1`；卡片圆角取岛圆角。
- 圆角阶梯：常态半高 → hover `16` → 展开 = `islandRadius`（默认 `12`，`0`–`16`）。媒体图圆角始终跟所在形态的外框。
- 三态同一时刻只有一种；展开态移出岛体回落常态，常态与 hover 按双向延迟消抖。拖动期间不切态。

## 切态动画

- 动画服从现有 `animationsEnabled`，由 `interfaceAnimations`、`followSystemReducedMotion` 与系统减少动态效果共同解析，不另设偏好字段；有效动画关闭时立即提交最终形态，不加形变、模糊或淡入。
- 形状使用 `240ms` 的 ease-out-back 曲线，归一化进度为 `1 + 2.2 × (t − 1)³ + 1.2 × (t − 1)²`，终点前峰值约超出 `5.3%` 后回弹。尺寸额外限制在端点范围的 `±6%` 与工作区内；贴边轴保持边缘锚点，默认顶部居中保持同一中心，不逐帧重新取中心。
- 当前以不超过 `30fps` 同步提交完整窗口盒与卡片局部区域、圆角，串行等待上次提交，跳过重复几何；结束补一次精确最终态。连续切态取消旧帧链并从最近完成的几何衔接，失败停止帧链并最多自动补一次合法常态请求，持续失败不循环重试。
- 每次切态只渲染一套目标内容，先按最终态实测并冻结文字布局；外框形变时裁切内容，同步将模糊从 `5px` 收到 `0`、透明度从 `0` 到 `1`。不叠加新旧文字，不增加背景色光晕或卡外像素。

## 卡片

- 一个功能一张完整卡片：卡自带表面、圆角与内边距，卡间距 `8`，不连成一块。
- 展开态外框不绘制表面与描边，只作矩形命中区域；卡间隙透出壁纸，点击与拖动仍归岛。窗口始终为矩形，不使用 `SetWindowRgn` 或点击穿透；卡片圆角外的透明区域仍属于岛窗口，不把点击交给桌面。
- 内容左对齐，宽度取各卡最大值统一，高度各自；超宽内容在卡内省略，不撑宽岛。
- 按钮 `28 × 28`，图标 `16`。常态按下卡片本体可进入原生窗口拖动；hover 在非控件区域按下后记录起点，位移超过 `4 DIP` 才进入原生拖动，未越过阈值并在非控件区域抬起则单击展开。歌词、媒体图与空白均可使用这条交互；媒体图不触发原生图片拖动。按钮、输入、链接、插件交互区与明确标注的不可拖区域不参与拖窗或展开。
- 原生拖动结束取消挂起延时，重读已保存的权威位置偏好，并只按 `begin_island_drag` 返回的 `pointerInside` 判态：`true` 进入或保持 hover，`false` 立即回落常态；不依赖拖动后的 `:hover` 或边界事件猜测，释放不能再次触发单击展开。不沿用拖动开始时的形态或偏移；之后普通移入、移出仍按 `180ms` 消抖。
- 展开态没有左侧句柄：拖动卡片本体的非控件区域只调整卡片顺序，不移动窗口；卡片本体可聚焦，使用上下方向键调整顺序。拖动与键盘都写同一份 `islandCardOrder`。
- 常态宽随内容，展开卡宽度上限 `360 DIP`，实测后按内容动态调整。

## 颜色与材质

- 卡片表面 `--fence-surface`（深 `rgb(32 38 40 / 58%)`、浅 `rgb(185 185 185 / 58%)`），描边 `1px --fence-border`；正文 `--fence-text`，次要文字同色 `78%` 不透明度。
- 进度轨道正文色 `18%`，已播 `80%`；频谱柱正文色 `42%`，底部对齐。
- 窗口背景透明，不使用系统材质与类画刷；卡片表面与描边仍由 `--fence-*` 令牌绘制。圆角由页面 CSS 绘制并自然抗锯齿，圆角外为透明像素、透出壁纸；不添加投影或光晕。透明像素只改变视觉，不改变矩形窗口的输入归属。

## 字体

- 沿用 `Segoe UI Variable`；歌名 `13`、艺人 `12`、来源与时间 `11`、常态歌词 `11`、展开歌词 `13`（当前句）/ `12`（其余），字距 `0`。

## 设置页

- 岛是设置里的一级页，不并入「功能格子」。
- 卡片行沿用功能格子设置：名称与副行在左，右侧控件组依次为开关、`↑ / ↓`、`›`。开关即该卡是否上岛。
- 卡片二级页页头为返回 + 标题，右侧是移除图标命令与上岛开关；第二行是卡片身份与描述；其下是该卡自有设置，没有时显示「插件未提供设置条目」空态。
- 行右键菜单分两组：打开卡片设置、上移、下移，分隔线后停用此卡片；复用设置页既有自绘菜单，不另写定位与关闭逻辑。

## 禁止事项

- 不给岛加投影、光晕或超出卡片形状的装饰。
- 不在岛内放菜单、按钮组或设置入口。
- 不为单张卡堆叠大块留白或装饰性背景。
