# 文件夹门户

## 状态与基线

UX 与 UI 已获确认，门户产品实现与实机验收尚未完成。沿用[视觉规范](视觉规范.md)、公共桌面格子组件以及[门户交互契约](../adr/0019-文件夹门户采用路径绑定与原生文件操作.md)。

Penpot 文件 `c828d3cf-7d4e-8145-8008-9cae8f420254` 中的“文件夹门户 · UI 已确认”页面（`e2bb46c3-262b-8097-8008-9ee8787d31b9`）包含列表与平铺、菜单、导航命名和状态四张画板。评审字体为 Noto Sans SC，产品继续使用 Segoe UI Variable / Segoe UI；示例图像是占位，产品使用 Shell 系统图像。画稿背景是评审底色，不替代真实壁纸验证。

## 容器与内容

- 公共标题轨道 28px；工具按钮 24×24px，图标 16px，按钮间距 2px。默认悬停显示，固定与悬浮标题沿用统一格子规则。
- 导航轨道最低 28px，按钮 24×24px、图标 16px；面包屑基准字号 12px，节点间距 4px。空间不足折叠中间层级，单个超长名称截断并提供完整名称提示，导航不换行、不压缩按钮。
- 默认紧凑列表行高最低 28px，16px 系统图标、13px 名称，图标与名称间距 8px。行高至少为字体行高加 8px，随字号偏好增长。
- 平铺复用围栏网格配置；默认项目尺寸 68×90px，横向间距 6px、纵向间距 8px，系统图像 48px、名称最多两行。不把 Penpot 示例的四列固定为产品列数。
- 表面、文字与边框复用 `--fence-*`；表面透明度 58%，背景模糊 5px，不新增阴影。圆角使用 `min(8px, var(--surface-radius))`，当前默认值为 6px；不得新增门户专属近似圆角值。
- 外壳和带边框子项的容器保留至少 1px 内边距，文件内容独立滚动。Selected、Hover、Focus、Drop Target、Disabled 不改变轨道尺寸。

## 菜单与消息

- 自绘父子菜单使用界面主题，独立于门户桌面主题；表面、边框、文字和 Hover 复用 `--menu-*`，检查深浅主题交叉组合。
- 菜单项高度至少 28px，菜单外部内边距 4px，固定 16px 图标列；没有图标的项目仍保留该列。分割线为 1px，复用菜单边框颜色，上下各 4px。
- 菜单禁用透明度 0.48，键盘焦点为界面强调色 1px 内描边。子菜单沿用向左翻转和向上避让，不增加装饰动画。
- 错误与操作反馈复用 `MessageNotificationHost`：最大宽度 480px，右下各 16px，字号 12px、内边距 8px 12px、圆角 4px。消息不抢占输入焦点，保留关闭入口。
- 命名输入保留原位编辑，失败时错误正文仅走消息管道；持续目录异常在门户保留恢复入口。

## 设计验证与产品验证

Penpot 的门户、列表、标题工具、面包屑、菜单、输入、按钮和消息内部使用 Flex；平铺使用 Grid。四张画板已导出检查，紧凑门户从 300px 调整到 340px 时文件行自动扩展且无越界，随后恢复原尺寸。设计中的面包屑折叠状态是示例，不宣称 Penpot 自动执行路径折叠逻辑。

实现后仍需检查真实壁纸、系统图像、DPI、12–18px 字号、长路径、深浅主题组合、菜单边缘避让和通知焦点。原生文件操作、目录监听、大目录、网络目录及多屏场景以实际执行结果验收。
