# 主题变量契约

主题样式表只能覆盖下表里的配色令牌。字体族、字号、圆角和两组强调色由 `theme.json` 写入偏好，再由偏好副作用落到对应令牌。网格尺寸、透明宿主根表面和原生窗口外观不接受主题覆盖。

令牌名称以当前样式表和 `PreferencesProvider` 的实际写入为准。组件私有变量（收集项编辑器、音乐封面、Radix 定位）不属于本契约。

## 样式层可覆盖

这些令牌定义在样式表中。主题样式表在偏好变量写完之后挂入文档，用同等或更高优先级的选择器覆盖。不要用 `!important`。

### 调色板

定义在 `src/styles/global.css` 的 `:root` 与 `:root[data-theme="dark"]`。界面强调色 `--color-accent`、`--color-focus` 由偏好内联写入，不在此列。

| 令牌 | 用途 |
| --- | --- |
| `--color-background` | 普通页面背景 |
| `--color-surface` | 内容表面 |
| `--color-subtle` | 次级表面 |
| `--color-border` | 边框 |
| `--color-text` | 正文 |
| `--color-muted` | 次要文字 |
| `--color-ready` | 就绪状态 |
| `--color-active` | 通过、活动状态 |
| `--color-action` | 主命令表面 |
| `--color-action-hover` | 主命令悬停 |
| `--color-action-text` | 主命令文字 |
| `--color-error` | 错误文字 |
| `--color-error-surface` | 错误表面 |

### 桌面网格（围栏）

定义在 `src/features/workspace/surface/DesktopWorkspace.css` 的 `.fence-workspace`，浅色与深色分别挂在 `:root[data-desktop-theme="light"|"dark"]`。格子、桌面项目和标题栏消费这些令牌。音乐控件在自身表面上另写了一处 `--fence-border`，那是控件局部覆盖，不是第二个主题令牌。

| 令牌 | 用途 |
| --- | --- |
| `--fence-border` | 围栏与格子边框 |
| `--fence-surface` | 围栏表面 |
| `--fence-text` | 围栏文字 |
| `--fence-focus-border` | 围栏焦点边框 |
| `--fence-item-text-shadow` | 桌面项目名称阴影；浅色主题写 `none` |

### 自绘菜单

定义在 `src/features/tiles/DesktopTileMenu.css` 的 `.desktop-tile-menu`，以及 `src/features/tile-content/folder-portal/FolderPortal.css` 的 `.folder-portal__breadcrumb-menu`。浅色模式挂在 `:root[data-theme="light"]`。两组选择器都要写，只改其中一个会留下另一套菜单颜色。

| 令牌 | 用途 |
| --- | --- |
| `--menu-border` | 菜单边框 |
| `--menu-text` | 菜单文字 |
| `--menu-surface` | 菜单表面 |
| `--menu-hover` | 菜单悬停 |
| `--menu-shadow` | 菜单阴影 |

### 桌面强调色令牌

`--desktop-accent` 由偏好副作用用内联样式写到文档根，`.fence-workspace` 用它派生桌面范围内的 `--color-accent` 与焦点色。内联样式优先于主题样式表里的同名普通声明，所以改桌面强调色必须写 `theme.json` 的 `desktopAccentColor`，不要在 CSS 里再声明 `--desktop-accent`。

桌面配色与菜单配色必须各自给出，禁止用其中一组的令牌去填另一组。

## 偏好层可覆盖

`theme.json` 的 `appearance` 只接受下表字段；缺省或 `null` 表示不覆盖。数值沿用偏好校验：强调色为 `#` 加 6 位十六进制，圆角 `0`–`12`，字号 `12`–`18`，字体必须属于 `APPLICATION_FONTS` 或本主题 `fonts` 声明的字体族。

宿主把通过校验的值写成文档根的内联样式。主题样式表的普通声明盖不过这些内联值。

| 外观 | 偏好字段 | 落到的令牌 |
| --- | --- | --- |
| 界面强调色 | `accentColor` | `--color-accent`、`--color-focus`、`--interface-accent` |
| 桌面强调色 | `desktopAccentColor` | `--desktop-accent` |
| 圆角 | `cornerRadius` | `--surface-radius` |
| 字体族 | `fontFamily` | `--interface-font` |
| 字号 | `fontSize` | `--interface-font-size` |

字体族、字号和圆角两组外观共用。两组强调色分开保存。跟随 Windows 主题色的开关不在主题数据里。

## 主题自带字体

`theme.json` 可以用 `fonts` 数组声明插件自带的字体文件，宿主注册后这些字体族会进入外观页的字体列表，任何主题或内置主题都可以选用。

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| `family` | 是 | 用户可见的字体族名，1–64 字符，不得包含 `;`、`{`、`}`、`(`、`)`、`'`、`"`、`\`、控制字符或前后空格 |
| `file` | 是 | 插件文件夹内的相对路径，扩展名只能是 `.woff2`、`.woff`、`.ttf` 或 `.otf`，不接受绝对路径、`..`、链接与重解析点 |
| `weight` | 否 | `100`–`900` 的整数，缺省 `400` |
| `style` | 否 | `normal` 或 `italic`，缺省 `normal` |

- 单个字体文件上限 `16 MiB`，单个主题最多 `4` 个文件；超限的字体项让该主题注册失败。
- 宿主用 `FontFace` 按 `family`、`weight`、`style` 注册，地址为 `/plugins/<folder>/<file>?v=<version>`；主题样式表不写 `@font-face`。
- 字体只影响正文排版：`--interface-font` 写成 `<选中字体族>` 加内置回退栈，缺字时逐字符回退到系统字体，回退结果不写回偏好。
- 主题自带字体不进入外观基线：停用、卸载或切回内置主题时随主题一起撤下，字体恢复为用户原有值；基线里被写成主题字体的旧值按默认字体处理。
- 字体文件缺失或加载失败时静默回退：字体族仍出现在列表里，选中后按回退栈显示，不做错误提示，也不清空已保存的偏好。


## 不可覆盖

| 项 | 实际令牌或规则 | 原因 |
| --- | --- | --- |
| 网格尺寸 | `--desktop-grid-width`、`--desktop-grid-height`、`--desktop-grid-column-gap`、`--desktop-grid-row-gap`、`--fence-grid-width`、`--fence-grid-height`、`--fence-grid-column-gap`、`--fence-grid-row-gap` | 由网格偏好内联写入 |
| 透明宿主根表面 | `html[data-desktop-host="true"]` 及其 `body`、`#root` 的 `background: transparent` | 壁纸必须透出，不是令牌 |
| 原生窗口外观 | 无对应 CSS 令牌 | 标题栏、阴影、托盘菜单由系统绘制 |

动效时长 `--interface-transition-duration` 由界面动画开关控制，也不接受主题覆盖。
