# 主题变量契约

主题样式表覆盖下表里的配色令牌；本主题自己的表现层（覆盖层、切角、扫描线等）与专属类名也写在同一个样式表里，随主题撤下自然消失。字体族、字号、圆角和两组强调色由 `theme.json` 写入偏好，再由偏好副作用落到对应令牌。网格尺寸、透明宿主根表面和原生窗口外观不接受主题覆盖。

令牌名称以当前样式表和 `PreferencesProvider` 的实际写入为准。组件私有变量（收集项编辑器、音乐封面、Radix 定位）不属于本契约。

## 样式层可覆盖

这些令牌定义在样式表中。主题样式表在偏好变量写完之后挂入文档，用同等或更高优先级的选择器覆盖。不要用 `!important`。`data-button` 的 `danger` 及原生 `:disabled` 状态由 `src/styles/global.css` 表达，既有 `primary`/`secondary`/`ghost`/`icon` 视觉由组件 CSS 表达；主题只改令牌与可撤销的特效，不再写一套变体填充、文字与描边选择器。主题可以自带设置条目写入文档根的**主题私有表现变量**（停用主题时清理），它不属于本契约的宿主可覆盖令牌。可撤销表现层的全屏叠加与循环动画必须鼠标穿透、只画装饰不铺底，并受界面动画开关与系统减少动效约束，关闭时整层撤下、不残留半透明纹理。45° 切角使用 `corner-shape` 与分角半径，不用裁切控件内容/命中区的 `clip-path`；`data-button="row-hit"`、结构面与原生 Toast 不参与，关闭切角后参与控件回到直角。按钮悬停冷光等特效必须排除 `:disabled`，按下亮度不得变换尺寸或把透明表面变成实色。

主题样式表的自引用 URL 携带缓存失效版本：`/plugins/<folder>/<stylesheet>?v=<stylesheetCacheKey>`。`stylesheetCacheKey` 是宿主只读派生值——在注册插件时由清单 `version`、样式表文件大小和修改时间组合而成（仅读文件元数据，清单里没有对应键，插件无法声明）；页面组装主题 `<link>` 与宿主首帧拼进窗口地址使用同一串。改主题文件后版本串自动变化，无需 bump 清单版本。

各主题的特效开关与主题私有变量取值见主题自带说明文档（如 `plugin/主题-夜之城/说明.md`）。

### 调色板

定义在 `src/styles/global.css` 的 `:root` 与 `:root[data-theme="dark"]`。界面强调色 `--color-accent`、`--color-focus` 由偏好内联写入，不在此列。

| 令牌 | 用途 |
| --- | --- |
| `--color-background` | 普通页面背景 |
| `--color-surface` | 内容表面 |
| `--color-subtle` | 次级表面 |
| `--color-border` | 边框 |
| `--color-text` | 正文 |
| `--color-muted` | 次要文字 |
| `--color-ready` | 就绪状态指示点；不作按钮填充，也不用于设置开关已选滑块（滑块用 `--color-focus`） |
| `--color-active` | 通过、活动状态 |
| `--color-action` | 主命令表面 |
| `--color-action-hover` | 主命令悬停 |
| `--color-action-text` | 主命令文字 |
| `--color-error` | 错误文字 |
| `--color-error-surface` | 错误表面 |

### 桌面网格（围栏）

定义在 `src/features/workspace/surface/DesktopWorkspace.css` 的 `.fence-workspace`，浅色与深色分别挂在 `:root[data-desktop-theme="light"|"dark"]`。格子、桌面项目和标题栏消费这些令牌。音乐控件在自身表面上另写了一处 `--fence-border`，那是控件局部覆盖，不是第二个主题令牌。

| 令牌 | 用途 |
| --- | --- |
| `--fence-border` | 围栏与格子边框 |
| `--fence-surface` | 围栏表面 |
| `--fence-text` | 围栏文字 |
| `--fence-active` | 桌面层活动/通过状态；格子状态点与结论字 |
| `--fence-warning` | 桌面层警告状态；探测被拒、未配对提示、WARNING 日志 |
| `--fence-error` | 桌面层错误状态；平台错误、ERROR 日志、token 无效 |
| `--fence-muted` | 桌面层次要文字、离线/未知状态点与相对高低条 |
| `--fence-focus-border` | 围栏焦点边框 |
| `--fence-item-text-shadow` | 桌面项目名称阴影；浅色主题写 `none` |

桌面层插件内容只读取本组 `--fence-*` 令牌，不得回退到界面调色板的 `--color-*`；非桌面层的设置页、消息和自绘菜单也不读取本组令牌。

### 自绘菜单

定义在 `src/features/tiles/DesktopTileMenu.css` 的 `.desktop-tile-menu`，以及 `src/features/tile-content/folder-portal/FolderPortal.css` 的 `.folder-portal__breadcrumb-menu`。浅色模式挂在 `:root[data-theme="light"]`。两组选择器都要写，只改其中一个会留下另一套菜单颜色。菜单内距与行高由组件持有：容器内距 `4px`、命令最小行高 `28px`，主题只覆盖五个配色令牌和不改布局的装饰，不能用主题规则改菜单内距。

| 令牌 | 用途 |
| --- | --- |
| `--menu-border` | 菜单边框 |
| `--menu-text` | 菜单文字 |
| `--menu-surface` | 菜单表面 |
| `--menu-hover` | 菜单悬停 |
| `--menu-shadow` | 菜单阴影 |

主题可以在上述两个自绘菜单容器的 `background-image` 上绘制四角细 L 等不改变尺寸、内距或命中范围的装饰；结构面保持直角，不参与交互控件的切角。不能将该装饰加到按钮、`data-button="row-hit"` 命中层或原生 Toast。菜单项是普通按钮，不标成 `primary` 或 `row-hit`。

### 桌面强调色令牌

`--desktop-accent` 由偏好副作用用内联样式写到文档根，`.fence-workspace` 用它派生桌面范围内的 `--color-accent` 与焦点色。内联样式优先于主题样式表里的同名普通声明，所以改桌面强调色必须写 `theme.json` 的 `desktopAccentColor`，不要在 CSS 里再声明 `--desktop-accent`。

桌面配色与菜单配色必须各自给出，禁止用其中一组的令牌去填另一组。

## 偏好层可覆盖

`theme.json` 的 `appearance` 只接受下表字段；缺省或 `null` 表示不覆盖。数值沿用偏好校验：强调色为 `#` 加 6 位十六进制，圆角 `0`–`12`，浮岛圆角 `0`–`16`，字号 `12`–`18`，字体必须属于 `APPLICATION_FONTS` 或本主题 `fonts` 声明的字体族。

宿主把通过校验的值写成文档根的内联样式。主题样式表的普通声明盖不过这些内联值。

| 外观 | 偏好字段 | 落到的令牌 |
| --- | --- | --- |
| 界面强调色 | `accentColor` | `--color-accent`、`--color-focus`、`--interface-accent` |
| 桌面强调色 | `desktopAccentColor` | `--desktop-accent` |
| 圆角 | `cornerRadius` | `--surface-radius` |
| 浮岛圆角 | `islandRadius` | `--island-radius` |
| 字体族 | `fontFamily` | `--interface-font` |
| 字号 | `fontSize` | `--interface-font-size` |

字体族、字号和界面圆角两组外观共用；浮岛圆角（默认 `12`）独立于界面圆角，经 `themeBaseline` 捕获与还原，只作用于浮岛的展开卡，hover 与常态的圆角是形态固定值。两组强调色分开保存。跟随 Windows 主题色的开关不在主题数据里。

## 主题可声明的原生消息外观

原生 Toast 由 Rust 绘制，页面 CSS 覆盖不到它；配色、字重与可选切角由 `theme.json` 的 `notification` 段声明。页面 CSS 不得给消息加结构装饰。

整套只有一份，不随深浅模式切换；未声明的配色字段回落当前深浅模式的内置色。只有同时声明 `cornerStyle: "bevel"` 与合法 `cornerSize` 才绘制切角，缺少任一字段都保持原有圆角。主题切换时在屏消息按新外观重绘。

| 字段 | 用途 |
| --- | --- |
| `surface` | 消息表面 |
| `border` | 消息边框 |
| `text` | 正文 |
| `muted` | 次要正文 |
| `subtle` | 后层消息与悬停表面 |
| `success` | 成功状态图标 |
| `warning` | 警告状态图标；未声明时沿用 `muted` 的现有回落 |
| `error` | 错误状态图标 |
| `weight` | 正文字重，取 `normal`、`medium`、`semibold`、`bold` 之一，缺省 `normal` |
| `cornerStyle` | `round` 或 `bevel`；`bevel` 只把左上与右下改为 45° 直切，其余两角保留圆角 |
| `cornerSize` | `1`–`24` 的整数，单位 DIP；仅在 `cornerStyle: "bevel"` 时生效，缺省时不画切角 |

除 `weight`、`cornerStyle` 与 `cornerSize` 外每个颜色字段均为 `#` 加六位十六进制；非法颜色、非法枚举、`cornerSize` 越界或类型非法、未知键都使整份主题注册失败。切角量独立于外观圆角偏好：`appearance.cornerRadius` 为 `0` 时，合法的 `cornerStyle: "bevel"` 与 `cornerSize` 仍会绘制左上、右下切角；其余两角继续使用外观圆角。切角随折叠层等比缩放，不改变默认宽 `296 DIP`、最小高 `64 DIP` 与 `250ms` 进退场动画；字体族与字号仍走偏好。

## 主题可声明的启动覆盖层时长

桌面首屏的 `#boot-splash` 覆盖层默认显示 `900ms`。主题可以在 `theme.json` 里用 `boot.durationMs` 改这个总时长：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `durationMs` | `0`–`10000` 的整数 | 覆盖层从出现到消失的总时长；`0` 表示本主题不播；缺省用 `900` |

宿主在建窗口时把它拼进页面地址，页面据此写 `--boot-splash-duration` 并安排移除时机，所以不需要入口脚本，也不会出现“CSS 改长了但 JS 提前收走”。超过 `10000` 会让整份主题注册失败。覆盖层只在主显示器、本进程启动后两秒内且未要求减少动效时出现。

## 主题自带字体

`theme.json` 可以用 `fonts` 数组声明插件自带的字体文件，宿主注册后这些字体族会进入外观页的字体列表，任何主题或内置主题都可以选用。

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| `family` | 是 | 用户可见的字体族名，1–64 字符，不得包含 `;`、`{`、`}`、`(`、`)`、`'`、`"`、`\`、控制字符或前后空格 |
| `file` | 是 | 插件文件夹内的相对路径，扩展名只能是 `.woff2`、`.woff`、`.ttf` 或 `.otf`，不接受绝对路径、`..`、链接与重解析点 |
| `weight` | 否 | `100`–`900` 的整数，缺省 `400` |
| `style` | 否 | `normal` 或 `italic`，缺省 `normal` |

- 单个字体文件上限 `16 MiB`，单个主题最多 `4` 个文件；超限的字体项让该主题注册失败。
- 宿主用 `FontFace` 按 `family`、`weight`、`style` 注册，地址为 `/plugins/<folder>/<file>?v=<version>`；主题样式表不写 `@font-face`。
- 字体只影响正文排版：`--interface-font` 写成 `<选中字体族>` 加内置回退栈，缺字时逐字符回退到系统字体，回退结果不写回偏好。
- 主题自带字体不进入外观基线：停用、卸载或切回内置主题时随主题一起撤下，字体恢复为用户原有值；基线里被写成主题字体的旧值按默认字体处理。
- 字体文件缺失或加载失败时静默回退：字体族仍出现在列表里，选中后按回退栈显示，不做错误提示，也不清空已保存的偏好。


## 不可覆盖

| 项 | 实际令牌或规则 | 原因 |
| --- | --- | --- |
| 网格尺寸 | `--desktop-grid-width`、`--desktop-grid-height`、`--desktop-grid-column-gap`、`--desktop-grid-row-gap`、`--fence-grid-width`、`--fence-grid-height`、`--fence-grid-column-gap`、`--fence-grid-row-gap` | 由网格偏好内联写入 |
| 透明宿主根表面 | `html[data-desktop-host="true"]` 及其 `body`、`#root` 的 `background: transparent` | 壁纸必须透出，不是令牌 |
| 原生窗口外观 | 无对应 CSS 令牌 | 标题栏、阴影、托盘菜单由系统绘制 |

动效时长 `--interface-transition-duration` 由界面动画开关控制，也不接受主题覆盖。
