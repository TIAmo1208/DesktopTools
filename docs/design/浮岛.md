# 浮岛

本文记录浮岛的形态、尺寸与令牌。浮岛的定位、窗口、拖动与偏好归属见 [ADR-0036](../adr/0036-浮岛作为独立呈现位.md)；内容层与状态决策见 [ADR-0044](../adr/0044-浮岛内容层锚点与状态.md)，合并通知与显示开关见 [ADR-0046](../adr/0046-浮岛消息通知锚点与显示开关.md)，展开窗口覆盖整个工作区见 [ADR-0047](../adr/0047-浮岛展开态固定高度.md)；主题可覆盖的外观项见[主题变量契约](主题变量契约.md)。

## 定位与令牌归属

浮岛是继透明桌面工作区、普通应用界面、原生消息之后的第四个独立表面：独立原生窗口与独立页面来源，置顶显示、不抢焦点，不在桌面宿主页面内，也不进工作区快照、布局与撤销。窗口与信任边界见 [ADR-0036](../adr/0036-浮岛作为独立呈现位.md)。

它跟随桌面主题、使用 `--fence-*` 令牌而不是界面主题，这是令牌归属，不代表它属于透明桌面工作区；该域的三条禁止事项（大圆角、悬浮面板构图、装饰性阴影）对浮岛豁免。豁免范围只到卡片形状为止：仍不加投影、光晕或任何超出卡片形状的装饰。

## 窗口生命周期

- 岛窗口没有用户关闭入口：外部关闭请求（`WM_CLOSE`，含误发与外部工具）一律忽略并记日志，不销毁窗口；若窗口仍被外部销毁，事件投递检测到失效句柄后清理旧 WebView 并按当前偏好重建，岛不会永久消失、也不再持续刷投递失败日志。关闭浮岛只走设置里的「显示浮岛」开关。

## 形态与位置

- 两种形态由偏好 `islandForm` 决定，设置页「浮岛形态」分段切换：`capsule` 胶囊浮岛与工作区边保持 `6 DIP` 间隔；`notch` 贴边刘海与工作区边零间距。
- 刘海在非展开态把贴边侧两角切成直角，并在贴着卡片贴边角的位置补一块 `12 DIP` 的圆弧面，使卡片本体经圆弧向外鼓出、平滑衔接到屏幕边。窗口只在沿边方向各外扩 `12 DIP`，卡片本体仍贴边并向内让出圆弧区；弧面与原卡片之间的角部是新增的透明像素。展开态统一使用浮岛圆角，不再外扩窗口，也不做外凸圆弧。两者除圆弧外只差贴边间距（胶囊 `6 DIP`、刘海 `0`）。
- 贴边方向由偏好 `islandEdge` 决定，设置页「显示位置」分段切换上、下、左、右；空串按顶部处理。拖动只沿当前边移动，不改变贴边方向。
- `islandOffset` 是相对沿边居中的 DIP 偏移：`0` 表示贴在边的中点，正值向沿边正向偏移。空串 `islandEdge` 按顶部应用同一偏移，不把空串固化为显式 `top`；拖动落点按拖动后窗口的卡片中心计算，松手不重新以鼠标为中心定位，只把贴边轴吸附到设置边。

- 固定视口：常态与 hover 是贴边侧 `440 DIP` 宽、沿边覆盖整个工作区的带；展开态页面视口铺满整个工作区（宽=工作区宽、高=工作区高），内容列固定 `400 DIP`，按 `islandEdge` 贴边/居中。视口随边、偏移和形态变化，窗口在视口中的偏移由页面 margin 表达。
- 子窗口固定在视口原点，允许超出父窗口，超出部分由父窗口裁剪；可见区域、命中与指针归属仍以父窗口矩形为准。

## 三态

- 常态胶囊：高 `44 DIP`；内边距 `8`；内容为一排 `28` 锚点圆与一行主信息（见「内容设计语言」）。贴上下用横向胶囊，贴左右用竖向胶囊（宽 `44 ＝ 28 + 8 × 2`）。只读，不出现控制。
- 音乐胶囊有当前歌词时显示歌词，未到首句或无歌词时仅显示歌名，缺标题时显示播放状态；两者都不显示百分比。常态尺寸按播放状态固定为档位值：横向播放中 `240`、未播放 `168`；竖向播放中 `176`、未播放 `96`；竖向最小 `52`。固定件（内边距 `8 × 2` ＋ 锚点圆 `28` ＋ 间距 `8`）合计 `52`，歌词内容盒 ＝ 档位 − `52`（横向 `188` / `116`，竖向 `124` / `44`）。音乐胶囊只按播放状态与贴边方向选档，歌词长短、晚到或消失都不重设窗口，短内容留在固定内容盒内、超出部分滚动；其余胶囊的宽度随锚点行与主信息自然收放（见「内容设计语言」）。
- 内容盒放不下的当前行按播放进度滚动：横向文本向左平移（阅读位置从左往右推进），竖向自上而下推进；暂停与停止冻结在当前偏移，切歌与跳转按新位置重新对齐，末句后停在末位。无同步词（含首句前与回落文本）改为慢速往返循环；减少动效时改为单行截断、不滚动。
- 滚动只用合成层 `transform`，不改变卡片与窗口尺寸：音乐胶囊只随播放状态与贴边方向选档，滚动与换句都不重新测量、不提交窗口。这是「避免逐句重设窗口造成高度抖动」的落地方式——若按当前句文本或滚动偏移重设窗口，胶囊会在播放中持续抖动，因此固定档位尺寸并把超出内容放进内容盒内位移。其余胶囊的宽度按锚点行与主信息的自然尺寸收放，不因歌词换句或滚动位移重设窗口。
- 常态内容切换按锚点接力：同来源换文时上一行立刻上移 `100%` 渐出、下一行从下方 `100%` 渐入，两段各 `300ms` 并重叠；换来源时旧内容先 `240ms` 收回该锚点、新内容再 `300ms` 展开。位移限制在锚点行盒内，不越出浮岛；离场层绝对定位，不参与内容盒与内容宽测量，滚动动画照常运行。减少动效时直接切换，不保留离场层。
- hover：常态进入与 hover 回落都使用 `180ms` 延迟；延时内反向越过边界会取消原目标，避免边缘抖动。贴上下与贴左右使用同一张水平卡片，高度由顶部锚点列表与下方内容行实测，不再固定 `72`；内边距 `12`、圆角 `16` 跟随外框；顶部列出全部锚点，下方只显示选中锚点的摘要与基础控制。宽度跟随当前可见锚点详情的自然宽度最大值（不保留历史峰值）：内容变长即加宽，删掉最宽内容允许收窄，但不得小于当前内容宽；宽度不窄于胶囊，上限由视口带宽约束。高度始终随当前详情。
- hover 窗口取胶囊态与 hover 内容区的并集，指针停在原胶囊范围任意位置都不会离开窗口；hover 结束回落胶囊时窗口收缩回胶囊范围。
- 展开：内边距 `16`；媒体图 `88`，与右侧信息列等高并保持 `1:1`；卡片圆角取浮岛圆角。展开原生窗口覆盖整个工作区；根节点铺满工作区接收指针，卡片列按 `islandEdge`/`islandOffset` 通过内联偏移定位，宽取自然内容列宽加滚动条槽，不占满父窗宽。卡片按原顺序与间距排列：贴顶从顶部排，贴底的末卡距工作区底边 `6 DIP`，贴左右时整列垂直居中。内容超高时从顶部开始并滚动；终态窗口保持工作区，不随列宽收缩。
- 展开歌词换句分已播放/未播放两段位移：已播放行立即位移 `220ms`，当前句与未播放行延迟 `80ms` 再位移 `240ms`；两段重叠、不等前段结束，延迟段以 `fill: backwards` 停在起始位移，避免回跳空档。当前句字号/颜色/透明度 `200ms`（同样延后 `80ms`），其余句 `140ms` 立即回落。减少动效时直接切换。
- 信息与歌词的溢出：展开态的歌名、艺人、来源超出列宽时慢速往返滚动（约 `20px/s`，往返周期不短于 `4s`，两端各留一段停顿）；展开歌词只让当前句在超出时滚动，其余句保持单行截断。常态胶囊与胶囊锚点按「内容设计语言」单行省略；hover 只让当前条目/摘要行在详情内往返滚动，其余 hover 锚点内容仍单行省略；常态歌词按上面的按进度滚动。滚动只用合成层 `transform`，不改变内容盒、卡片尺寸与窗口提交；关闭界面动画或系统要求减少动效时全部改为单行截断。
- 圆角阶梯：常态半高 → hover `16` → 展开 = `islandRadius`（默认 `12`，`0`–`16`）。锚点圆在胶囊与 hover 都为 `50%`，媒体图圆角跟随所在卡片外框。
- 表面不透明度：胶囊 `98%`、hover `94%`、展开 `90%`。只作用于卡片表面与贴边补面层，正文、图标与描边不受该值影响；切态不做透明度过渡。
- 三态同一时刻只有一种；展开态移出浮岛体回落常态，常态与 hover 按双向延迟消抖。拖动期间不切态。切态动画期间圆弧补面贴着卡片角移动，不按并集窗口角固定，避免弧面脱离卡片。
- 不透明轮廓由页面按卡片圆角矩形与贴边补面的可见弧面合成：圆角外的四角、卡间隙和补面方形内的透明扇区都算透明像素，仍归浮岛命中，但不属于内容盒。
- hover 的透明边距是命中特例：指针在 hover 窗口内、不透明轮廓外连续停留满 `120ms` 后回落常态；期间回到内容盒立即取消计时，不抖动。退回不改变既有 `180ms` 进入消抖：hover 退回路径可以落门闩，但常态不评估透明判定、也不受门闩限制，重新进入 hover 仍按既有 `180ms`；门闩逻辑与单测保留、常态停用（不是删除）。退回与移出窗口走同一套状态提交路径，几何、并集与原生命中一致。
- 常态关闭透明判定的原因：常态透明边距不承载本次切态语义，检测会与既有 `180ms` 进入、拖动释放重判冲突，因此常态不评估透明像素、不写门闩、不影响 `180ms` 进入；判定逻辑与单测保留，由状态门控关闭，以后可恢复。
- 展开态透明带取内容列以外的区域：内容列占满工作区高度、上下无余量，左右两侧各一条透明列；贴底的 `6 DIP` 边距不触发退回。只有从卡片内容进入透明列才开始 `120ms` 计时；在列内移动不重启，回到任一卡片或开始操作即取消。停留到点后回落胶囊；若指针仍在胶囊范围，先离开再进入才触发 hover。卡间隙、圆角外像素不触发；卡片外侧的整条滚动条槽（包括尚未出条时的空槽）不触发。展开态页面视口铺满整个工作区，透明区（卡片与内容列以外）连续停留 `120ms` 同样回胶囊；回到卡片或内容列即取消。透明区单击由页面接收指针并立即回胶囊，不做别的动作；原生命中仍是窗口矩形，不做系统级点击穿透，桌面收不到该次点击。拖动排序卡片的 `400ms` 手势期间保持例外、不退回；第二指针在排序期间移到空白也不启动/续期计时，排序结束或取消后恢复。
- 展开滚动条只在展开且内容溢出（`scrollHeight > clientHeight`）时出现，是固定在页面视口的覆盖层，不占 grid 行列；它位于卡片外侧的 `16 DIP` 槽内（`4 DIP` 间距加 `12 DIP` 轨道），槽把展开窗口加宽同样的宽度，卡片本体宽度不变。贴右边时槽在卡片左侧，卡片仍贴边。滑块可拖动，滚轮滚动与原生 `scrollTop` 行为不变。出现与渐入渐出时序见「切态动画」。
- 有保留中的通知时，胶囊与 hover 共用一枚消息通知锚点。展开仍用一张消息卡呈现原生通知，默认折叠到最新一条。

## 切态动画

- 动画服从现有 `animationsEnabled`，由 `interfaceAnimations`、`followSystemReducedMotion` 与系统减少动态效果共同解析，不另设偏好字段；有效动画关闭时立即提交最终形态，不加形变、模糊或淡入。
- 胶囊消息换文与歌词换句都走同一套上下交接：上一行立刻上移 `100%` 渐出、下一行从下方 `100%` 渐入，两段各 `300ms` 并重叠（同 §31）。歌词的盒内按进度横向滚动是另一套动画，两层互不影响：交接只动外层容器，滚动仍只作用在当前行。消息交接的触发只看条目身份与结果修订，同一条目的进度刷新不重播；歌词交接在句序号变化且文本变化时播放，减少动效时两处都直接替换。
- 展开分两段：当前卡先用 `240ms` 从 hover 尺寸切到展开尺寸；其他卡延迟 `100ms` 起步、与相位 1 末尾重叠，从当前卡展开矩形（视觉上在其背后）按同一曲线弹到各自槽位，卡片与内容同步淡入并 `5px → 0` 去模糊；展开总时长 `340ms`，收起与其余切态仍为单段 `240ms`。动画期间当前卡 `z-index` 高于其他卡，结束恢复自然流。
- 形状使用 `240ms` 的 ease-out-back 曲线，归一化进度为 `1 + 2.2 × (t − 1)³ + 1.2 × (t − 1)²`，终点前峰值约超出 `5.3%` 后回弹。尺寸额外限制在端点范围的 `±6%` 与工作区内；贴边轴保持边缘锚点，默认顶部居中保持同一中心，不逐帧重新取中心。
- 浮岛页面坐标相对一个固定屏幕视口：常态与 hover 是贴边侧 `440 DIP` 宽、沿边覆盖整个工作区的带，展开态铺满整个工作区；页面根节点用 margin 表达窗口在视口中的偏移，WebView 子窗口固定在视口原点，父窗口只移动并裁剪。窗口盒与页面坐标因此解耦：换视口前先整层遮蔽（`visibility:hidden`、`pointer-events:none`），收到原生回包并同步目标布局后才一次性解除；遮蔽期间不提交新坐标、不响应透明区回退/点击/拖排，解除后重测一次。窗口放大或刚展开的 `300ms` 内，按最近指针坐标判定 `pointerleave`：坐标仍在窗口/内容列内视为假离开，不收起。展开首帧先按 `islandEdge`/`islandOffset` 把内容列定位到目标偏移，再提交两态并集窗口，逐帧只改变卡片区域与圆角；结束后先把内容画到目标屏幕位置，再提交目标窗口盒收缩裁剪，收缩本身不再移动内容，避免结束一帧横移。展开时并集已经覆盖整个工作区，终帧保持工作区窗口、只重绘内容列；退出展开时窗口在终帧回到紧凑目标。展开稳态的卡内收放、排序、滚动等不提交同一窗口盒，内部实测只更新滚动与页面命中。并集起点帧按起点态自己的贴边锚点取内容，窗口比当前更大时先提交窗口再绘制目标布局，窗口更小时先绘制目标布局再提交窗口，避免新布局被旧窗口裁切出一帧。
- 贴边侧角使用带符号圆角：正值是普通圆角，负值是外凸负圆角；切态时按同一形变进度在两端之间插值，圆弧补面随负半径出现、贴着卡片角移动，展开态与胶囊形态没有补面。绘制补面的帧不画卡片 `1px` 内描边。
- 动画期间内容与形变同步淡入并去模糊：同一进度驱动内容层透明度与 `5px → 0` 模糊，终帧清除内联 `opacity/filter`，静态态与关闭动画时保持完全清晰；除这一层内容过渡外不叠加透明度/模糊或其它合成层，避免终帧切换造成闪烁。成功提交后回到自然文档流，常态与 hover 继续随内容伸缩、展开态恢复 CSS 滚动，hover 并集在重测时重放最近窗口几何。
- 当前以不超过 `30fps` 同步提交完整窗口盒、固定视口与卡片局部区域、圆角，串行等待上次提交，跳过重复几何；同一物理窗口盒不重复调用 `SetWindowPos`；子窗口在局部矩形（相对父窗口的偏移或视口尺寸）变化时重设，父窗口移动只改变偏移、视口尺寸不变时不重设尺寸。子窗口可以大于父窗口，超出部分由父窗口裁剪，输入仍只归父窗口；结束补一次精确最终态。连续切态取消旧帧链并从最近完成的几何衔接，失败停止帧链并最多自动补一次合法常态请求，持续失败不循环重试。
- 每次切态只渲染一套目标内容，先按最终态实测并冻结文字布局；外框形变时裁切内容，不叠加新旧文字，不增加背景色光晕或卡外像素。
- 拖动结束后的首次测量跳过并集动画，直接按拖动落点提交，避免跨边或位置变化时先放大再收缩。
- 展开滚动条不参与帧链：展开动画（`340ms`）结束并成功提交后才开始 `150ms` 渐入；收起时先独立完成 `150ms` 渐出、opacity 到 `0` 后才提交收起并开始卡片形变，没有可见条时不等待，等待可取消且反向请求不会执行迟到的收起；有效动画关闭时直接隐藏并立即切态。`transitionend` 丢失时的兜底计时同样先做与关闭动效一致的瞬时隐藏再提交，不假定计时器到时条已透明。帧链期间不出条，条的几何与展开退回带的扣除共用同一份纯函数结果，渲染不参与测量；内容变高但裁剪后原生几何不变时，仍按最新溢出刷新可见性、滑块范围与命中排除矩形，刷新不产生原生提交。

## 内容设计语言

适用于胶囊（`44`）与 hover 两态的内容；hover 高度随锚点列表与内容行调整。展开沿用「卡片」规则，只复用内容单元与状态符号，不复用尺寸与密度。新增浮岛显示内容按本节准入，不按插件自定。

- 三层职责：胶囊只读，整条点击展开；hover 顶部列出所有暂留锚点，下方显示选中锚点的内容与控制；展开承担完整内容与需要确认的操作。「上浮岛显示」分功能控制紧凑两态（插件卡按卡控制），不改变展开卡与插件运行。
- 内容单元：每个锚点最多携带一个内容单元——锚点 `28 × 28` 圆形（安全区 `20 × 20`）、右侧一行主信息、可选一个附加项（数值 / 计数 / `12` 小图标）。胶囊可并排多个锚点，锚点之间留 `12`；每个锚点只承载自己的内容，不跨锚点拼第二行。胶囊最多并排 `3` 个锚点，第 `4` 个起折成「＋N」锚点（圆内数字），展开看全部。锚点内图形按功能身份绘制：音乐用媒体图填满圆（无图或加载失败回到音符与 `--fence-border` 圆底），消息通知用 Lucide `bell`；插件锚点可由插件通过 `setIslandSummary` 的 `navigation.uri` 声明去向：有声明时锚点可单击/Enter/Space，宿主与前端都按 `dsh:`/`https:` 白名单、≤512 字符且无控制字符校验，前端非法地址不发命令；未声明时保持只读，点击仍只选中，不切换选中、不打开卡片、不抢焦点。打开失败只在当前 hover 详情或展开卡显示 `role=status` 文案，胶囊不画文字、仅用既有 live region 播报；不弹 Toast、不新开窗口。插件卡在连接正常时用清单 `iconPath` 的身份图标（`20 × 20` 原色 `<img>`、`object-fit: contain`、透明背景，不做反色），告警与断连仍用状态符号；未声明或加载失败回落通用插件图标。普通事件仍用状态符号。
- 锚点内容不限，圆形只作绘制区域的蒙版，不额外加圆形描边或外框；内容须在安全区内可辨识：环与描边 `3`、细线 `1.5`–`2`，只用实色，不用渐变、阴影或纹理；需要更大尺寸才能读的内容移到锚点右侧，不放大锚点。
- 文本单行不换行，中文上限 `18` 字、英文上限 `36` 字符，超出省略；歌词例外，按播放进度换句、超长在盒内滚动；hover 详情当前活动项的摘要行与消息正文也例外，按 `20 DIP/s` 在盒内往返滚动，离开/切换即复位、减少动效不动，二者都不撑宽。数值只允许整数百分比、`99+` 计数与 `mm:ss` 剩余时间。消息通知另按条目显示实际计数，超过 99 条显示「99+」。
- 程序内置基础状态集：待开始、进行中、暂停、完成、失败、取消、等待确认、未连接、未授权、无总量运行中；插件可在基础集上扩展状态与显示内容，但新增状态必须同时给出锚点内的视觉差异（弧长或符号）、一句话短词、结束后的去向（停留、收成圆点、直接消失），缺一不算状态。
- 内容切换按锚点接力：旧信息向旧锚点收回（`200`–`280ms`），旧锚点保留、不消失，可与其他锚点并排；新锚点在右侧自下向上渐入，随后新内容从新锚点向右展开（`280`–`320ms`）；浮岛宽度跟随内容实时变化，不留并集空白；收束时反向执行。通知型锚点不因接力延长寿命。
- 生命周期由语义决定：音乐随播放或暂停的媒体会话出现，停止、未知或无会话即收回；插件锚点随其卡片状态；天气变化与新收录只向消息通知锚点投递，不单独占锚点。
- 消息通知不按来源拆锚点。新条目更新同一枚锚点的计数与最新正文，更新正文沿用锚点内的滚动节奏。
- 排序决定谁显示：拖放 > 确认 > 消息通知 > 普通事件 > 插件常驻。消息通知抢占前台时，音乐只收回胶囊文字，不改变播放与进度。
- hover 顶部用功能图标列出可见锚点。图标等比适配 `20 × 20` 安全区，不套内层圆形裁剪；选中和聚焦轮廓画在 `28 × 28` 的按钮外侧。从胶囊进入 hover，优先选中胶囊正在显示正文的锚点；找不到对应项时保留仍可见的选择，无有效选择则回落首项，空态时钟不成为选中项。指针移到其他锚点立即更新选中标识。功能图标未选中为 `20px`，选中缩至 `16px`，沿用 `28 × 28` 按钮的图标档位；选中圈、底色和图标用同一 `300ms ease-out` 过渡，取消选中时同步反向变化。宽度跟随当前所有锚点详情的最大值（不保留历史峰值），并保留胶囊下限；高度按列表和当前详情实测。插件自绘仅挂载当前详情，离场结束即卸载；其实际宽度与其他锚点一样可抬高本轮 hover 的宽度下限。
- hover 内切换详情按锚点行顺序接力：选右侧时旧详情左移渐出，新详情由右侧渐入；选左侧时反向。位移复用[视觉规范](视觉规范.md)的跨内容 `4 DIP`，退缓沿用 `ease-out`，旧详情先走 `140ms`，结束后，新详情再走 `180ms`。一次只挂载一套详情，高度只在正文交接时按新内容重测，不插值、不逐帧提交窗口。界面有效动效关闭时，详情、选中圈、底色和图标均直接到位。
- hover 期间过期通知不消失，新通知并入同一 bell，不切换当前选中的功能锚点。
- hover 选中消息通知时列最近 5 条，逐条可关闭。音乐保留顶部锚点行，仅下方内容块对齐 Penpot「07 UI 三态」：左侧 `48 × 48`、圆角 `16` 的媒体图，中间为歌名 `13px`、艺人 `12px`、媒体输出应用 `11px` 三行，右侧为三个 `28 × 28` 控件（图标 `16px`，不可用时禁用）。卡片内边距 `12` 由外壳统一提供，不采用稿面固定宽高。普通事件最多两行，插件自绘、未提供时回落主信息行。需要确认、删除、批准的操作进展开。
- 零锚点：所有锚点消失后，胶囊显示一个空态圆锚点，内容为当前时间 `hh:mm`（显示在圆右侧、字号 `13`），仍可单击展开；没有活动音乐、消息通知或其他可见锚点时，回到该空态。
- 只剩锚点：允许胶囊只有圆、没有展开内容，宽度按锚点数量收缩，不做自动隐藏。
- 拖放：拖入时切换为接收态——锚点换成松手图标，主信息写「松开加入收集箱」或「交给音乐播放」；没有匹配插件时显示「无法接收」，松手回退且不执行。
- 展开回退：收起保留锚点顺序；若直接回到 hover，不重新选择当前项。从胶囊再次进入 hover 时按胶囊当前内容初选。
- 系统隐藏恢复：隐藏期间收到的通知恢复时一次并入同一 bell，已过期的普通条目丢弃，不逐个补播。
- 键盘：hover 中锚点列表可用左右方向键切换，`Enter` 进入该锚点内容。
- 新锚点：插入不抢焦点、不打断当前播报；读屏在下一次播报时带「新增 N 条」。
- 通知期限按条目计算：正文期默认 `5` 秒（`islandMessageContentSeconds`），到点只留锚点图标；锚点期默认 `30` 秒（`islandMessageAnchorSeconds`），到点移除；失败、待确认与带确定且未走满进度的加载只豁免锚点期。阅读期不抽走详情，也不暂停或续期两段计时，回常态再按当前时刻清到期，离开展开另清已读的普通原生通知。
- 数据过期：内容层不单独标识过期，是否显示过期由插件状态决定。
- 胶囊与 hover 的锚点整体只读、不进 Tab 顺序；只有声明了 `navigation.uri` 的锚点可单击/Enter/Space 单独打开（例外见「内容设计语言」），其余锚点内容不可单独点击，hover 中的锚点只被指针触发切换。整体按 `status` 播报「来源 + 状态 + 关键值」，连续进度只在 `25%`、`50%`、`75%`、完成与失败时播报；控件按视觉顺序 Tab，焦点 `2` 外描边加 `2` offset；「消息通知上浮岛显示」关闭时播报不包含该锚点，回落到其余前台内容或空。
- 颜色：锚点与正文用 `--fence-text`，轨道与音乐无图时的圆底用 `--fence-border`；语义色只用于运行 `--fence-active`、等待确认 `--fence-warning`、失败 `--fence-error`，不新增颜色令牌。hover 进度轨改用透明轨道 + 正文色 45% 的 1px 描边、填充用正文色：填充对轨内面浅色约 `4.54:1`、深色约 `5.79:1`（合成预算，图形阈值 `3:1`），不再使用 `--fence-active` 对 `--fence-border` 的 `1.25–1.58:1`；45% 描边对外轮廓仅约 `1.94/2.49`，只作轨道轮廓、不承担对比度；4px 轨在 16px 行内垂直居中，与右侧百分比留 `8 DIP`，不与文本或动作区重叠。
- 动效只复用既有节奏：生长 `280`–`320ms`、收缩 `200`–`280ms`、并行提示停留 `1.6`–`2.4s`、消抖 `300`–`1200ms`；锚点插入与列表高度变化复用同一节奏，新内容不带新时长；状态变化取消未完成动画并直接落到终态。通知 30 秒是保留期限，不是动效时长。
- 准入清单：新增一种显示内容须交齐锚点形态（`20 × 20` 内）、一行主信息模板、可选附加项、状态差异（若有）、锚点归属与叠加行为、hover 内容形态与控制归属、结束后去向、出现条件（活动或常驻）与收回时机，缺一不进。
- 禁止：胶囊内放按钮或第二行、hover 下方同时显示多个锚点的内容、锚点用渐变或阴影、为单一内容新增颜色令牌或时长、把危险操作放进 hover、只在 hover 暴露唯一入口、用近义词替代固定短词。

## 卡片

- 一个功能一张完整卡片：卡自带表面、圆角与内边距，卡间距 `8`，不连成一块。
- 展开态外框不绘制表面与描边，只作矩形命中区域；卡间隙透出壁纸，点击与拖动仍归浮岛。窗口始终为矩形，不使用 `SetWindowRgn` 或点击穿透；卡片圆角外的透明区域仍属于浮岛窗口，不把点击交给桌面。
- 内容左对齐，宽度取各卡最大值统一，高度各自；超宽内容在卡内省略，不撑宽浮岛。
- 按钮 `28 × 28`，图标 `16`。常态与 hover 在非控件区域按下后记录起点，按住满 `250ms` 才进入原生拖动；期间指针位移超过 `4 DIP` 会取消长按，未进入拖动并在非控件区域抬起则单击展开。歌词、锚点行与空白均可使用这条交互；按钮、输入、链接、插件交互区与明确标注的不可拖区域不参与拖窗或展开。原生拖动期间卡片降低背景亮度作为拖动反馈。
- 拖动只沿当前设置的贴边方向移动，不改变贴边方向。常态与 hover 的非交互区都可单击展开。原生拖动结束取消挂起延时，按拖动后的窗口位置计算沿边偏移，松手不重新以鼠标为中心定位，只把贴边轴吸附到设置边；只按 `begin_island_drag` 返回的 `pointerInside` 判态：`true` 进入或保持 hover，`false` 立即回落常态；不依赖拖动后的 `:hover` 或边界事件猜测，释放不能再次触发单击展开。之后普通移入、移出仍按 `180ms` 消抖。
- 展开态每张卡共用一条 `32 HIGH` 卡头：左侧拖卡句柄（可见 `36 × 4`、半径 `2`，命中 `56 × 28`，`--fence-text` 35%，hover/焦点 65%，拖动 85%），右侧动作区最多两个 `28 × 28` 按钮（内图 `16`，间距 `4`），其中一个固定为收起/展开（`aria-expanded` 随状态变化）。DSH 卡先提供「打开 DSH」安全动作，能力缺失、宿主暂停或同动作在途时禁用；不提供确认/批准或 Toast。卡头在文档流里占固定高度，标题与正文下移避让。
- 收起/展开统一走同一事务：点击立即登记最新目标并进入 pending（按钮 `aria-busy`），测量内容自然高、动画到目标，结束后以实际自然高回落清理；连续点击只替换目标、取消旧动画并从当前渲染高度续接，旧 `finished` 与旧测量不能覆盖新目标；测不到目标时直接回落自然流。高度沿用 `240ms ease-out`，期间只裁切过渡、不做永久卡内滚动，不提交窗口盒；关闭界面动效时立即到位。收起状态逐卡写入偏好 `islandCardCollapsed`；记忆关闭时回默认（收集箱与消息通知默认收起，其余默认展开），消息通知卡缺省收起到最近一条。
- 内容容器按宿主给出的工作区可用高度布局；展开卡只改自身内容高度与页面滚动范围，不自行改变原生窗口尺寸。
- 插件卡在常态与 hover 也有一个移出视口的隐藏宿主，不是 `display:none`：插件可持续轮询并调用 `setIslandSummary` 提供胶囊与 hover 主信息行的一行摘要；hover 自绘只作只读视图，不得替换或清理常驻 `renderTile` 宿主，未调用时回落清单名称；`setIslandSummary(null)` 或空串表示显式隐藏该锚点，不回落清单名，也不影响卡片、轮询与提醒。展开态复用同一次挂载、不同时挂两份。浮岛隐藏、锁屏、全屏隐藏或卡片停用时卸载，恢复后重新挂载一次，由插件按自己的快照重建基线、不补播旧提醒。
- 展开态通过卡头句柄排序：主键按住满 `400ms` 进入拖卡（提前位移超过 `4 DIP` 取消），拖动期间保持当前展开态、不触发透明边距回退回胶囊，释放按实时纵向落点提交一次完整 `islandCardOrder`；拖出卡列/窗口、Esc、失去捕获、切态或锁屏取消并回到最后保存顺序。折叠在途禁用卡头动作与句柄拖动，结束后恢复。句柄也可聚焦后用上下方向键移动，与设置页「上移/下移」写同一份顺序。键盘排序对完整保存顺序交换相邻可见卡，消息槽与其它未显示项保持原位；消息卡显示时自身也参与移动。窗口拖动只在常态与 hover 通过非控件区长按进入。
- 常态宽随内容，但音乐卡有媒体会话时，其常态胶囊按两档固定宽度：播放中 `240 DIP`、暂停 `168 DIP`（贴左右时 `176` / `96`，内容盒为档位减固定件 `52`）。档位只看播放或暂停，不看歌词是否已到：切歌、换歌词行、歌词晚到都不让胶囊重排，收起时不再出现第二次宽度调整；无会话或停止时不出现音乐锚点，没有其他锚点时回到空态时钟。展开态所有卡片列宽固定 `400 DIP`（内容变化只改高度，列偏移与窗口盒 `400 + 16 DIP` 滚动条槽不随文字宽变化）。
- 展开音乐卡的进度条在播放器声明可跳转且系统给出有效可跳转区间时换成同尺寸滑块，量程取系统区间；播放器没给区间但有有效时长时退回用时长。拖动或方向键只改本地草稿，松手或键盘提交时发一次 `seek_music_position`，收到提交之后的系统时间轴样本再交回真实位置；不支持时保持只读进度并提示原因。歌词源兜底的量程只用于显示，不参与可拖动判断。
- 断言页的长内容卡只在开发断言页按查询参数注入（浮岛页面 `?island-debug=N`，断言页 `?mode=interaction-scroll&island-debug=6`），注入由 `import.meta.env.DEV` 与查询参数共同门控，卡片带 `data-island-debug`、不参与排序或持久化。移除方式是删掉纯函数 `islandDebugCardCount` 与展开态渲染分支，不涉及偏好、契约或快照；发布构建经 `import.meta.env.DEV` 剔除，包内没有该分支与文案。

## 收集箱卡

- 这张卡只在设置中启用 `official.collect-box` 后出现；呈现列表并支持拖入拖出，不复制桌面收集箱的菜单、选择、删除与排序，这些仍留在桌面格子。
- 收集箱无独立胶囊锚点与 hover 提醒列表。新收录进入同一消息通知锚点，关闭通知不删除收集项；编辑窗口仍可从展开收集箱卡打开。
- 展开卡内容宽 `300 DIP`，最多 `50` 条，三列网格混排：文本与文件映射整行显示标题 `12`、摘要 `11`；图片项只显示缩略图、不显示名称，单项占总宽三分之一并保持 `3:2` 比例。条目可单击打开，不可用条目降到 `48%` 不透明度并禁用；列表超过工作区高度时沿用浮岛展开滚动条。
- 卡内收起时只列最近 `islandCollectCollapsedCount` 条（`3` / `5` / `10`，默认 `3`），仍按三列混排、仍可拖出；加载态与空态同样占 `300 DIP` 内容宽，首次实测即得到最终宽度，展开动画结束后不再二次调宽。
- 展开态条目使用 `data-island-no-drag`，不触发卡片排序；按住条目拖动超过 `4 DIP` 后走系统 OLE 拖出，复用桌面收集箱的 `prepare_collect_drag` 与 `start_desktop_item_drag`，原条目保留。
- 拖入由浮岛窗口承担：设置中启用这张卡后，常态、hover 与展开态都可把桌面收集箱支持的内容拖到浮岛任意卡片上；不需要先展开收集卡。收入规则、类型白名单、编辑窗锁与失败反馈都与桌面收集箱共用，投放只返回复制效果，不删除源文件。
- 投放进入时在锚点行前插入一枚接收锚点（不再有独立接收卡）：常态先切 hover，锚点换成松手图标、主信息只有一句「松开加入收集箱」，不叠加收集箱的最近条目；接收锚点参与正常几何测量，窗口贴合锚点行。投放期间不按悬停消抖和透明边距退回，放下或离开后按真实光标位置回落。

## 天气卡

- 这张卡只在设置中启用 `official.weather` 后出现；卡内不放入口、按钮或菜单。
- 天气无独立胶囊锚点与 hover 卡。成功摘要的主信息或天气代码变化时投递本地通知，首次读取和摘要缺失不投递。天气代码图形与来源署名仍在展开天气卡。
- 来源与城市在设置页的卡片二级页选择，保存在 `islandWeatherSource` 与 `islandWeatherCityId`；展开卡只显示当天摘要，24 小时与 7 天预报继续由桌面天气格子承载。
- 缺失态各显示一句说明：未配置天气 API、请选择天气 API、请选择城市、天气 API 已删除、城市已移除；不在浮岛内提供跳转或选择控件。
- 浮岛天气使用与桌面天气相同的预报事件和活动调度；桌面天气开关关闭时，只要这张卡在 `islandCardOrder` 中仍保持活动更新。

## 消息

- 原生消息来自 Toast 队列的只读投影，不改原生弹出、去重或离场。天气变化、新收录与插件投递（`island-plugin-message`）另在浮岛侧并入同一锚点，不新增原生 Toast、不新建队列。插件条目按 `plugin:<source>:<key>` 给身份，跨插件同 key 不互相覆盖；正文剥离控制字符后为空即拒收，超长直接拒收而不是截断。
- 消息卡以 `official.island-messages` 进入 `islandCardOrder`，与其它岛卡共用同一套展开顺序、上移/下移与键盘排序，但不占 `maxTiles`、没有桌面格子与持久布局；展开态不显示抓取光标，也不新增拖卡。首次采用时插在天气之后；无天气时插在第一个插件卡之前，无插件则末尾，由 `islandMessageCardInitialized` 保证只插一次（保存成功后才置标记，失败下次重试；顺序满 32 项时不插、不挤掉既有卡）。是否在展开态显示由 `islandMessageCardVisible` 控制，与 bell 锚点开关互不影响。
- 常态：各来源合并为一枚 `28 × 28` 消息锚点。两段时长各自从到达时刻起算、互不串接：正文展示时间默认 `5` 秒，锚点显示时间默认 `30` 秒；条目寿命取两者较长者的截止时刻——正文长于锚点时正文结束锚点一起消失，正文短于锚点时正文收起后锚点继续留到自己的期限。两段都不进设置，hover 与展开不暂停或续期；失败、待确认与带确定且未走满进度的加载只豁免锚点期。正文期结束后胶囊正文让位给下一枚有内容的锚点；没有其它内容时只剩锚点圆，随后回到空态时钟。锚点图标按最新条目类型：系统通知条目显示来源应用 Logo（`20 × 20` 安全区、`3px` 圆角），普通与天气、收录等本地条目用 bell，成功用对勾，警告用 `triangle-exclamation-point`，错误用 `circle-x`，加载在有确定 `0–1` 进度时画进度环、没有进度时用 `resources/loading.svg` 每秒一圈（关闭动效时静止）；颜色沿用正文色/通过绿/警告黄/错误红。合并计数超过 99 条显示「99+」，只在正文期随正文出现。
- `＋N` 折叠：消息锚点与其它锚点一样参与三枚上限；被折叠时仍按原顺序参与 hover。
- hover：选中 bell 显示最近 5 条「来源 · 内容 · 时间」，最新在前，正文单行省略，时间当天为时分、跨天补月日，右侧逐条关闭（`28 × 28`）；没有剩余条目时撤下锚点。左侧按条目实际类型显示图标。天气通知有展望时在当前摘要下补一行模型原文，图标改用展望对应的天气代码；无展望时不占行。展望只用该通知到达时同城、同来源的预报事实，复用现有分钟刷新更新相对时间，不新增通知、不延长期限；胶囊仍只显示原摘要。插件投递的条目按 `plugin:<source>:<key>` 去重、按到达时间排序；带 `uri` 的条目可点击，按来源实例调用 `open_uri`，无 `uri` 的条目正文只读，点击失败只在页内 `role=status` 提示、不自动移除条目；本地条目与原生条目的正文保持只读。加载只有收到有效进度事实才画进度环，否则使用等速旋转图标（关闭动效时静止）。有图标时列表共用 `16px` 前轨，正文、时间与关闭键依然对齐；无图标事实不渲染占位元素，整列无图标时移除前轨。
- 展开：最近 `5` 条原生消息收进按 `islandCardOrder` 排序的消息卡，默认折叠只显示最新一条；无消息且无通道故障时该槽不画空卡但保留顺序。卡头固定 `28px`，距首条 `6px`；仅多于一条时显示 `28 × 28` 的展开/折叠按钮（图标 `16`、`aria-expanded`）。展开后按最新在前排列，不改卡片顺序或持久化。
- 展开消息行固定为 `20px / minmax(0, 1fr) / 28px` 三轨，间距 `8px`；状态图标 `16px` 居于 `20 × 20` 光学盒并对齐正文首行中心；关闭按钮 `28 × 28` 从行首对齐。条目间 `4px + 1px` 分隔线 `+ 4px`，首尾无多余留白。正文 `12/18` 保留原文与换行，最多显示四行；正文与副行的段落外边距都为 `0`，相距 `2px`。副行用独立区域显示来源与时刻，分隔点两侧各 `4px`，只省略过长来源；等宽数字的时刻当天显示时分，跨天补月日。
- 插件事件是推送通道，不进恢复重读：锁屏、浮岛隐藏与全屏隐藏期间不接收新条目，恢复只显示插件自己的现状，不补发暂停期间的提醒。
- 键盘关闭当前聚焦的条目后，焦点依次尝试下一条、上一条、列表开关、岛内下一可用控件，最后回落岛根。鼠标关闭不触发续焦；后台消息进入不主动移动焦点。
- 阅读暂存：hover 和展开期间不移除当前阅读的条目；回常态按期限清理，离开展开另清已读的普通原生通知。关闭原生条目沿用原命令，关闭本地条目不调用原生。
- 消息通道失败不在常态胶囊显示提示，只在展开态追加「消息通道不可用」卡，不阻塞岛卡。
- 展开消息卡与展开列表的图标按类型取 `resources/info.svg`、`editor-check.svg`、`message-warning.svg`、`message-error.svg`，关闭用 `editor-x.svg`；颜色只取 `--fence-text`，加载中图标降到 `60%` 不透明度，不新增动画。

## 颜色与材质

- 卡片表面 `--fence-surface`（深 `rgb(32 38 40 / 58%)`、浅 `rgb(185 185 185 / 58%)`），三态用 `--island-surface-alpha` 覆盖其 alpha（`98%` / `94%` / `90%`），正文与描边不随该值变化；描边 `1px --fence-border`；正文 `--fence-text`，次要文字同色 `78%` 不透明度。刘海的外凸圆弧补面无法与卡片矩形描边连续，绘制补面的帧不绘制这条 `1px` 内描边；胶囊、展开态与无补面的帧仍绘制。
- 进度轨道正文色 `18%`，已播 `80%`；频谱柱正文色 `42%`，底部对齐。
- 展开滚动条轨道透明、不加底色，滑块为正文色 `50%` 不透明度、悬停与拖动 `75%`；轨道宽 `12 DIP`、滑块宽 `6 DIP`、滑块圆角 `3px`，只用 `--fence-text` 混合，不引入新配色。
- 窗口背景透明，不使用系统材质与类画刷；卡片表面与描边仍由 `--fence-*` 令牌绘制。圆角由页面 CSS 绘制并自然抗锯齿，圆角外为透明像素、透出壁纸；不添加投影或光晕。透明像素只改变视觉，不改变矩形窗口的输入归属。
- 浮岛根持有与桌面围栏相同的整组 `--fence-*`（`--fence-border`、`--fence-surface`、`--fence-text`、`--fence-active`、`--fence-warning`、`--fence-error`、`--fence-muted`、`--fence-focus-border`、`--fence-item-text-shadow`），浮岛自身只用表面、描边与正文三项，插件卡可以按桌面同样的语义使用状态色；令牌来源与不可覆盖项见[主题变量契约](主题变量契约.md)「浮岛」。
- 主题表现层不作用于浮岛：浮岛窗口会加载同一张主题样式表，主题的全屏叠加、切角与悬停特效必须用 `:where(html:not([data-island="true"]))` 门控（零权重包裹，不抬高原选择器特异性）。浮岛只接收配色令牌与 `islandRadius`。

## 系统截图

- 截图热键（Win+Shift+S 与 PrtSc）由低级键盘钩子提前识别，浮岛在截图工具冻结画面之前隐藏；即使前台事件晚到，冻结画面也不会包含浮岛。截图工具（`ScreenClipper`、`Snipping Tool`、`ScreenSketch`）在前台期间保持隐藏；工具未出现或离开前台后，由浮岛窗口计时器兜底恢复，不等可能漏发的前台事件。隐藏与恢复只改可见性，不重建窗口，也不因重复的刷新事件再次置顶刷新。
- 隐藏是可见性策略，不改变保存的胶囊/hover/展开状态与拖动位置；恢复只改可见性，尺寸与 hover 状态在下一次指针或策略事件时校正。

## 字体

- 沿用 `Segoe UI Variable`，字距 `0`。常态胶囊通知正文与 hover 正文同为 `13px`，符合[视觉规范](视觉规范.md)的 `12px` 至 `13px` 正文基线；胶囊计数用 `12px`，始终在单行末尾完整显示。
- 歌名 `13px`、艺人 `12px`、来源与时间 `11px`。常态歌词单独用 `11px`；展开歌词当前句 `13px`，其余 `12px`。

## 设置页

- 浮岛是设置里的一级页，不并入「功能格子」。
- 一级页顶部保留「浮岛形态」与「显示位置」分段控件；切换位置时把沿边偏移重置为居中。「全屏时隐藏」之后为「锚点显示」二级页入口。二级页提供音乐、消息通知两个固定「上浮岛显示」开关，并按当前已启用的插件卡逐卡提供「<卡片名>上浮岛显示」开关，只控制紧凑两态；没有插件卡时显示空态说明，不残留全局插件开关。功能格子音乐面板也可修改同一音乐开关。消息两段时长不提供设置项，使用固定默认值。
- 卡片行沿用功能格子设置：名称与副行在左，右侧控件组依次为开关、`↑ / ↓`、`›`。开关即该卡是否上浮岛。
- 卡片二级页页头为返回 + 标题，右侧是插件卡才有的卸载卡片图标命令（`settings__icon-button` 尺寸、告警色，沿用插件卸载的视觉语义；官方卡不提供该入口，可用上浮岛开关或列表菜单「停用此卡片」停用）与上浮岛开关；第二行是卡片身份与描述，描述只讲这张卡片本身，不写具体播放器；其下是该卡自有设置，没有时显示「插件未提供设置条目」空态。
- 音乐卡的二级页列出「显示歌词」「显示实时频谱」「频谱段数」「频谱帧率」四项，与桌面音乐格子共用同一份偏好；「显示歌词」带说明按钮（`SettingsInfo`）：歌词来自公开歌词源，播放软件需在自身设置里开启系统媒体控制（SMTC），网易云要拿到准确播放进度需以 `--remote-debugging-port=9222` 启动客户端。
- 天气卡的二级页列出「天气 API」与「城市或地区」两个选择行：API 只列设置中已配置的来源，切换来源会清空城市；城市只列该来源已保存的城市。没有来源或城市时在行下给出去「功能格子 → 天气」添加的说明。
- 每张卡的二级页第一个设置块是「记忆收起状态」开关，缺省开启；关闭后该卡收起态不写偏好，按默认值显示。
- 收集箱卡的二级页在记忆开关之后提供「默认收起」开关与「收起时显示条数」分段（`3` / `5` / `10`），并保留一句拖入与打开方式的说明；卡片开关仍只控制是否上浮岛。
- 行右键菜单分两组：打开卡片设置、上移、下移，分隔线后停用此卡片；复用设置页既有自绘菜单，不另写定位与关闭逻辑。

## 禁止事项

- 不给浮岛加投影、光晕或超出卡片形状的装饰。
- 不在浮岛内放菜单、按钮组或设置入口。
- 不为单张卡堆叠大块留白或装饰性背景。
