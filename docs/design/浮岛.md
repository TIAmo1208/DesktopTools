# 浮岛

本文记录浮岛的形态、尺寸与令牌。浮岛的定位、窗口、拖动与偏好归属见 [ADR-0036](../adr/0036-浮岛作为独立呈现位.md)；主题可覆盖的外观项见[主题变量契约](主题变量契约.md)。

## 定位与令牌归属

浮岛是继透明桌面工作区、普通应用界面、原生消息之后的第四个独立表面：独立原生窗口与独立页面来源，置顶显示、不抢焦点，不在桌面宿主页面内，也不进工作区快照、布局与撤销。窗口与信任边界见 [ADR-0036](../adr/0036-浮岛作为独立呈现位.md)。

它跟随桌面主题、使用 `--fence-*` 令牌而不是界面主题，这是令牌归属，不代表它属于透明桌面工作区；该域的三条禁止事项（大圆角、悬浮面板构图、装饰性阴影）对浮岛豁免。豁免范围只到卡片形状为止：仍不加投影、光晕或任何超出卡片形状的装饰。

## 形态与位置

- 两种形态由偏好 `islandForm` 决定，设置页「浮岛形态」分段切换：`capsule` 胶囊浮岛与工作区边保持 `6 DIP` 间隔；`notch` 贴边刘海与工作区边零间距。
- 刘海在非展开态把贴边侧两角切成直角，并在贴着卡片贴边角的位置补一块 `12 DIP` 的圆弧面，使卡片本体经圆弧向外鼓出、平滑衔接到屏幕边。窗口只在沿边方向各外扩 `12 DIP`，卡片本体仍贴边并向内让出圆弧区；弧面与原卡片之间的角部是新增的透明像素。展开态统一使用浮岛圆角，不再外扩窗口，也不做外凸圆弧。两者除圆弧外只差贴边间距（胶囊 `6 DIP`、刘海 `0`）。
- 贴边方向由偏好 `islandEdge` 决定，设置页「显示位置」分段切换上、下、左、右；空串按顶部处理。拖动只沿当前边移动，不改变贴边方向。
- `islandOffset` 是相对沿边居中的 DIP 偏移：`0` 表示贴在边的中点，正值向沿边正向偏移。空串 `islandEdge` 按顶部应用同一偏移，不把空串固化为显式 `top`；拖动落点按拖动后窗口的卡片中心计算，松手不重新以鼠标为中心定位，只把贴边轴吸附到设置边。

- 固定视口是贴边侧 `420 DIP` 宽、沿边覆盖整个工作区的带；常态、hover 与展开的窗口都落在其中。视口随边、偏移和形态变化，状态切换不改变视口；窗口在视口中的偏移由页面 margin 表达。
- 子窗口固定在视口原点，允许超出父窗口，超出部分由父窗口裁剪；可见区域、命中与指针归属仍以父窗口矩形为准。

## 三态

- 常态胶囊：高 `44 DIP`，宽随一行内容伸缩；内边距 `8`；媒体图 `28` 圆形。贴上下用横向胶囊，贴左右用竖向胶囊（宽 `44 ＝ 28 + 8 × 2`，高随竖排歌词字数，最小 `52`）。只读，不出现控制。
- hover：常态进入与 hover 回落都使用 `180ms` 延迟；延时内反向越过边界会取消原目标，避免边缘抖动。贴上下时高 `72`、控制键在标题行右侧；贴左右时高沿用胶囊高度、控制键下移到第二排。内边距 `12`，媒体图 `48`、圆角 `16` 跟随外框；只显示当前卡，出现基础控制，不出现完整内容。
- hover 窗口取胶囊态与 hover 内容区的并集，指针停在原胶囊范围任意位置都不会离开窗口；hover 结束回落胶囊时窗口收缩回胶囊范围。
- 展开：内边距 `16`；媒体图 `88`，与右侧信息列等高并保持 `1:1`；卡片圆角取浮岛圆角。展开态不区分贴边方向，高度按内容实测，不受竖胶囊或左右贴边 hover 的高度限制。
- 圆角阶梯：常态半高 → hover `16` → 展开 = `islandRadius`（默认 `12`，`0`–`16`）。媒体图圆角始终跟所在形态的外框。
- 三态同一时刻只有一种；展开态移出浮岛体回落常态，常态与 hover 按双向延迟消抖。拖动期间不切态。切态动画期间圆弧补面贴着卡片角移动，不按并集窗口角固定，避免弧面脱离卡片。
- 不透明轮廓由页面按卡片圆角矩形与贴边补面的可见弧面合成：圆角外的四角、卡间隙和补面方形内的透明扇区都算透明像素，仍归浮岛命中，但不属于内容盒。
- hover 的透明边距是命中特例：指针在 hover 窗口内、不透明轮廓外连续停留满 `120ms` 后回落常态；期间回到内容盒立即取消计时，不抖动。退回不改变既有 `180ms` 进入消抖：hover 退回路径可以落门闩，但常态不评估透明判定、也不受门闩限制，重新进入 hover 仍按既有 `180ms`；门闩逻辑与单测保留、常态停用（不是删除）。退回与移出窗口走同一套状态提交路径，几何、并集与原生命中一致。
- 常态关闭透明判定的原因：常态透明边距不承载本次切态语义，检测会与既有 `180ms` 进入、拖动释放重判冲突，因此常态不评估透明像素、不写门闩、不影响 `180ms` 进入；判定逻辑与单测保留，由状态门控关闭，以后可恢复。
- 展开态的透明退回只认“并集窗口 − 目标内容盒”的额外带：贴上下时按横向切分，取内容盒左右两侧；贴左右时按纵向切分，取内容盒上下两侧。方向由边与形态的几何推导，不硬编码某一侧。进入额外带与 hover 共用同一条 `120ms` 连续停留计时（同一常量与状态机，不另设超时）：进带开始计时、计时内回到内容盒取消、满 `120ms` 才退回。额外带以外的透明像素（圆角外、卡间隙、正交余量）保持原行为：归浮岛命中、不退回。额外带内的滚动条矩形是可交互区域，从退回判定中扣除，按住滑块不退出展开。
- 展开滚动条只在展开且内容溢出（`scrollHeight > clientHeight`）时出现，是固定在页面视口的覆盖层，不占 grid 行列、不改变窗口盒与内容布局；滑块可拖动，滚轮滚动与原生 `scrollTop` 行为不变。出现与渐入渐出时序见「切态动画」。
- 浮岛测试卡由后端按 Debug 构建注入：`official.debug-island` 清单只在 `cfg!(debug_assertions)` 注册，`island_instances` 在卡片顺序之后追加一张 `island.official.debug-island` 合成实例，因此 `npm.cmd run tauri:dev`（加载 `build/frontend` 产物的 debug 构建）启动浮岛并展开即可看到。它不写偏好、不进 `islandCardOrder`、不进设置页卡片列表、不是工作区格子能力，也不参与排序与持久化；浮岛页只在展开态显示它，胶囊态不显示。移除方式是删掉清单文件、Debug 注册与实例注入，并在浮岛页删掉对应渲染分支。断言页另有查询参数注入的长内容卡（`?island-debug=N`，`1`–`8`），只用于溢出与多卡测试，与 Debug 构建的测试卡相互独立。

## 切态动画

- 动画服从现有 `animationsEnabled`，由 `interfaceAnimations`、`followSystemReducedMotion` 与系统减少动态效果共同解析，不另设偏好字段；有效动画关闭时立即提交最终形态，不加形变、模糊或淡入。
- 形状使用 `240ms` 的 ease-out-back 曲线，归一化进度为 `1 + 2.2 × (t − 1)³ + 1.2 × (t − 1)²`，终点前峰值约超出 `5.3%` 后回弹。尺寸额外限制在端点范围的 `±6%` 与工作区内；贴边轴保持边缘锚点，默认顶部居中保持同一中心，不逐帧重新取中心。
- 浮岛页面坐标相对一个固定屏幕视口：视口是贴边侧 `420 DIP` 宽、沿边覆盖整个工作区的带，页面根节点用 margin 表达窗口在视口中的偏移，WebView 子窗口固定在视口原点，父窗口只移动并裁剪。窗口盒与页面坐标因此解耦：切态先提交两态并集窗口，逐帧只改变卡片区域与圆角；结束后先把内容画到目标屏幕位置，再提交目标窗口盒收缩裁剪，收缩本身不再移动内容，避免结束一帧横移。展开终态例外：窗口保留入态并集，不收缩到内容盒；内容仍按目标 margin 落位，并集内多出的透明边距仍归浮岛命中，展开态滚动、快照与重测都沿用同一并集。并集起点帧按起点态自己的贴边锚点取内容，窗口比当前更大时先提交窗口再绘制目标布局，窗口更小时先绘制目标布局再提交窗口，避免新布局被旧窗口裁切出一帧。
- 贴边侧角使用带符号圆角：正值是普通圆角，负值是外凸负圆角；切态时按同一形变进度在两端之间插值，圆弧补面随负半径出现、贴着卡片角移动，展开态与胶囊形态没有补面。绘制补面的帧不画卡片 `1px` 内描边。
- 动画期间内容与形变同步淡入并去模糊：同一进度驱动内容层透明度与 `5px → 0` 模糊，终帧清除内联 `opacity/filter`，静态态与关闭动画时保持完全清晰；除这一层内容过渡外不叠加透明度/模糊或其它合成层，避免终帧切换造成闪烁。成功提交后回到自然文档流，常态与 hover 继续随内容伸缩、展开态恢复 CSS 滚动，hover 并集在重测时重放最近窗口几何。
- 当前以不超过 `30fps` 同步提交完整窗口盒、固定视口与卡片局部区域、圆角，串行等待上次提交，跳过重复几何；同一物理窗口盒不重复调用 `SetWindowPos`；子窗口在局部矩形（相对父窗口的偏移或视口尺寸）变化时重设，父窗口移动只改变偏移、视口尺寸不变时不重设尺寸。子窗口可以大于父窗口，超出部分由父窗口裁剪，输入仍只归父窗口；结束补一次精确最终态。连续切态取消旧帧链并从最近完成的几何衔接，失败停止帧链并最多自动补一次合法常态请求，持续失败不循环重试。
- 每次切态只渲染一套目标内容，先按最终态实测并冻结文字布局；外框形变时裁切内容，不叠加新旧文字，不增加背景色光晕或卡外像素。
- 拖动结束后的首次测量跳过并集动画，直接按拖动落点提交，避免跨边或位置变化时先放大再收缩。
- 展开滚动条不参与帧链：`240ms` 展开动画结束并成功提交后才开始 `150ms` 渐入；收起时先独立完成 `150ms` 渐出、opacity 到 `0` 后才提交收起并开始卡片形变，没有可见条时不等待，等待可取消且反向请求不会执行迟到的收起；有效动画关闭时直接隐藏并立即切态。`transitionend` 丢失时的兜底计时同样先做与关闭动效一致的瞬时隐藏再提交，不假定计时器到时条已透明。帧链期间不出条，条的几何与展开退回带的扣除共用同一份纯函数结果，渲染不参与测量；内容变高但裁剪后原生几何不变时，仍按最新溢出刷新可见性、滑块范围与命中排除矩形，刷新不产生原生提交。

## 卡片

- 一个功能一张完整卡片：卡自带表面、圆角与内边距，卡间距 `8`，不连成一块。
- 展开态外框不绘制表面与描边，只作矩形命中区域；卡间隙透出壁纸，点击与拖动仍归浮岛。窗口始终为矩形，不使用 `SetWindowRgn` 或点击穿透；卡片圆角外的透明区域仍属于浮岛窗口，不把点击交给桌面。
- 内容左对齐，宽度取各卡最大值统一，高度各自；超宽内容在卡内省略，不撑宽浮岛。
- 按钮 `28 × 28`，图标 `16`。常态与 hover 在非控件区域按下后记录起点，按住满 `250ms` 才进入原生拖动；期间指针位移超过 `4 DIP` 会取消长按，未进入拖动并在非控件区域抬起则单击展开。歌词、媒体图与空白均可使用这条交互；媒体图不触发原生图片拖动。按钮、输入、链接、插件交互区与明确标注的不可拖区域不参与拖窗或展开。原生拖动期间卡片降低背景亮度作为拖动反馈。
- 拖动只沿当前设置的贴边方向移动，不改变贴边方向。常态与 hover 的非交互区都可单击展开。原生拖动结束取消挂起延时，按拖动后的窗口位置计算沿边偏移，松手不重新以鼠标为中心定位，只把贴边轴吸附到设置边；只按 `begin_island_drag` 返回的 `pointerInside` 判态：`true` 进入或保持 hover，`false` 立即回落常态；不依赖拖动后的 `:hover` 或边界事件猜测，释放不能再次触发单击展开。之后普通移入、移出仍按 `180ms` 消抖。
- 展开态没有左侧句柄：拖动卡片本体的非控件区域只调整卡片顺序，不移动窗口；卡片本体可聚焦，使用上下方向键调整顺序。拖动与键盘都写同一份 `islandCardOrder`。
- 常态宽随内容，展开卡宽度上限 `360 DIP`，实测后按内容动态调整。
- 断言页的长内容卡只在开发断言页按查询参数注入（浮岛页面 `?island-debug=N`，断言页 `?mode=interaction-scroll&island-debug=6`），注入由 `import.meta.env.DEV` 与查询参数共同门控，卡片带 `data-island-debug`、不参与排序或持久化。移除方式是删掉纯函数 `islandDebugCardCount` 与展开态渲染分支，不涉及偏好、契约或快照；发布构建经 `import.meta.env.DEV` 剔除，包内没有该分支与文案。

## 颜色与材质

- 卡片表面 `--fence-surface`（深 `rgb(32 38 40 / 58%)`、浅 `rgb(185 185 185 / 58%)`），描边 `1px --fence-border`；正文 `--fence-text`，次要文字同色 `78%` 不透明度。刘海的外凸圆弧补面无法与卡片矩形描边连续，绘制补面的帧不绘制这条 `1px` 内描边；胶囊、展开态与无补面的帧仍绘制。
- 进度轨道正文色 `18%`，已播 `80%`；频谱柱正文色 `42%`，底部对齐。
- 展开滚动条轨道透明、不加底色，滑块为正文色 `50%` 不透明度、悬停与拖动 `75%`；轨道宽 `12 DIP`、滑块宽 `6 DIP`、滑块圆角 `3px`，只用 `--fence-text` 混合，不引入新配色。
- 窗口背景透明，不使用系统材质与类画刷；卡片表面与描边仍由 `--fence-*` 令牌绘制。圆角由页面 CSS 绘制并自然抗锯齿，圆角外为透明像素、透出壁纸；不添加投影或光晕。透明像素只改变视觉，不改变矩形窗口的输入归属。

## 系统截图

- 截图热键（Win+Shift+S 与 PrtSc）由低级键盘钩子提前识别，浮岛在截图工具冻结画面之前隐藏；即使前台事件晚到，冻结画面也不会包含浮岛。截图工具（`ScreenClipper`、`Snipping Tool`、`ScreenSketch`）在前台期间保持隐藏；工具未出现或离开前台后，由浮岛窗口计时器兜底恢复，不等可能漏发的前台事件。隐藏与恢复只改可见性，不重建窗口，也不因重复的刷新事件再次置顶刷新。
- 隐藏是可见性策略，不改变保存的胶囊/hover/展开状态与拖动位置；恢复只改可见性，尺寸与 hover 状态在下一次指针或策略事件时校正。

## 字体

- 沿用 `Segoe UI Variable`；歌名 `13`、艺人 `12`、来源与时间 `11`、常态歌词 `11`、展开歌词 `13`（当前句）/ `12`（其余），字距 `0`。

## 设置页

- 浮岛是设置里的一级页，不并入「功能格子」。
- 一级页顶部用与天气供应商同款的分段控件提供两个全局切换：「浮岛形态」（胶囊浮岛 / 贴边刘海）与「显示位置」（上 / 下 / 左 / 右）；切换位置时把沿边偏移重置为居中。
- 卡片行沿用功能格子设置：名称与副行在左，右侧控件组依次为开关、`↑ / ↓`、`›`。开关即该卡是否上浮岛。
- 卡片二级页页头为返回 + 标题，右侧是移除图标命令与上浮岛开关；第二行是卡片身份与描述；其下是该卡自有设置，没有时显示「插件未提供设置条目」空态。
- 行右键菜单分两组：打开卡片设置、上移、下移，分隔线后停用此卡片；复用设置页既有自绘菜单，不另写定位与关闭逻辑。

## 禁止事项

- 不给浮岛加投影、光晕或超出卡片形状的装饰。
- 不在浮岛内放菜单、按钮组或设置入口。
- 不为单张卡堆叠大块留白或装饰性背景。
