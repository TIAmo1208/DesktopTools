# Desktop Tools 视觉规范

本文档只记录当前有效的视觉、布局和交互约束。修改 UI 时，先阅读对应场景规则，再复用当前组件和全局 CSS 变量；具体颜色、尺寸和间距以代码中的语义变量与组件规则为准。

## 全局设计语言

- 产品气质：Windows 原生感、安静、精密、紧凑。
- 字体：`"Segoe UI Variable", "Segoe UI", sans-serif`。
- 字号：正文以 `12px` 至 `13px` 为主，根据信息层级使用现有组件字号。
- 字间距：保持 `0`，不使用负字间距。
- 圆角：主要使用 `0` 至 `6px`；外观设置允许配置 `0` 至 `12px`，围栏上限为 `8px`。
- 图标：使用统一图标来源，不使用 Emoji 作为界面图标。
- 动效：只表达状态变化，不作装饰；状态变化不得引起布局跳动。
- 布局：保持稳定尺寸和紧凑信息密度，不使用营销页面式构图、大面积留白、装饰性卡片、渐变、光球或模糊背景图形。
- 所有自定义右键菜单按功能分组；不同功能组之间使用分隔线，同组命令连续呈现。隐藏空组后不得出现首尾或连续分隔线，分隔线不接收焦点；一级和二级菜单使用同一规则。

## 天气组件

### 接入与配置

- 使用用户提供的和风天气 API Host 与凭据。
- API Host 提示用户从控制台完整复制主机名、保留所有标签，不解释中间标签含义；示例使用虚构地址，输入上限与后端 DNS 主机名的 253 字节边界一致。
- 配置入口位于软件设置的“功能格子 → 天气”二级设置，不建立独立顶级页面。
- 天气入口沿用功能格子的统一列表、显示开关和箭头；API 字段旁复用 `SettingsInfo` 提供来源和格式提示，提示按钮样式由共享控件负责。
- 凭据使用密码输入框的默认遮蔽模式，沿用设置行、输入框、界面主题和禁用反馈。
- 采用 JWT 认证。配置状态区分已保存凭据与已验证能力，不能仅凭认证成功启用全部天气能力。
- 验证范围包括城市搜索、当前天气、24 小时预报、包含今天的 7 天预报、来源署名和对应城市详情链接。
- 草稿必须通过临时城市完成全部验证后才能保存启用；字段改变后验证失效，不保存未验证草稿。
- 私钥显隐只作用于当前草稿，不回填已保存原文；保存成功后清空敏感草稿，失败时保留旧配置和草稿。
- 取消验证拒绝迟到结果；未保存离开和清除凭据必须明确确认；切换配置不得展示迟到的旧配置结果。
- 密码遮蔽不代表存储加密。完整数据与运行边界见 [ADR-0025](../adr/0025-天气组件采用单源基础预报与网页详情.md)。

### API 设置视觉参数

- 设置行高 `70 DIP`，行间隔 `4 DIP`；私钥行高 `108 DIP`。
- 输入和命令按钮高 `38 DIP`，输入圆角 `4px`，设置行圆角 `6px`。
- 正文 `13px`，次要文字 `12px`，页面标题 `18px`，图标 `16px`，私钥显隐命中区 `32px`。
- 确认框宽 `468 DIP`；窗口高度不足时滚动内容。
- 能力验证结果复用界面主题：通过文字与勾选使用绿色 `--color-active`，未验证及验证中保留当前正文色，不通过及错误原因使用红色 `--color-error`；颜色只作用于结果，项目名称保持原色。

### 天气格子

- 默认显示当天摘要；当前天气、小时预报、7 天预报为三个独立模块，按可用宽高组合呈现，各自保留加载、缓存和失败反馈。
- “切换显示模式”二级菜单仅显示四个模式名称，不显示尺寸；默认字号、固定标题的外框分别为当天摘要 `192 × 120 DIP`、小时预报 `404 × 172 DIP`、7 天预报 `224 × 352 DIP`、完整预报 `454 × 372 DIP`；日预报包含今天，最小展开态不替代公共折叠态。
- 内容区进入门槛按完整、7 天、小时、摘要优先级在单条 if / else if / else 条件链中选择：完整 `430 × 320 DIP`、小时 `380 × 120 DIP`、日预报 `200 × 300 DIP`、摘要下限 `168 × 68 DIP`。每档宽高必须同时满足；自动模式不使用历史模式或滞回，尺寸变化立即重新判断。“固定显示模式”勾选项位于“切换显示模式”上方；勾选固定当前模式并跳过尺寸判断，限制缩放下限；取消恢复自动判断。固定状态与模式沿用组件 state 保存，缺少配置默认自动。小时布局当前天气列按内容宽度收紧，模块间沿用 `8 DIP` 间距。
- 默认外框按内容宽度加 `24 DIP`、高度加 `52 DIP`（含固定标题）换算；悬浮或隐藏标题按实际内容区计算，字号 `12px` 至 `18px` 时按实际内容测量阈值和最小高度。
- 格子沿用现有主题和 `58%` 表面透明度；模块用留白和 `1px` 分隔线区分，不嵌套卡片。
- 正文 `13px`、次要文字 `12px`、时间 `11px`；摘要温度 `26px`，其他当前温度 `32px`；标题轨道 `28px`，按钮命中区 `24px`，图标 `16px`，当前天气主图标 `28px`，禁用透明度 `48%`。
- 城市弹窗为 `400 × 352 DIP`，内边距 `16 DIP`，输入和命令按钮高 `38 DIP`，结果行高 `54 DIP`，圆角 `6px`；菜单行高 `28px`，使用独立界面主题和既有分隔样式。
- 跨模块组合采用 `180ms ease-out`、`4 DIP` 位移和淡入淡出，受有效动画设置控制；关闭动画时立即切换。文字和图标不缩放，连续切换收敛到最新尺寸，退出模块不保留交互焦点。
- 网页入口统一命名为“查看详情”。各尺寸共用公共标题栏右上角按钮与右键入口，来源署名单独保留在紧凑底栏；底栏贴内容区底边，高度不随格子高度变化，不在底栏放置详情按钮。底栏署名固定使用“和风”，不直接渲染接口 `attributions` 返回值——该值是指向供应商署名页的 URL，不适合固定高度的紧凑底栏。
- 内容限定为手动选择城市的当前天气、未来 24 小时和未来 7 天预报，使用摄氏度、公制及城市时区；保留来源署名、获取时间、缓存过期和失败反馈。
- 右键菜单或按钮通过系统浏览器打开当前城市 `fxLink`；数据优先读取本地磁盘缓存，缩放和切换显示粒度不触发请求。
- 复用官方组件公共格子、菜单和主题规则。

## 收集箱

- 收集箱是临时中转站；产品定位、收入与取出规则见 [ADR-0021](../adr/0021-收集项以Markdown文件为事实.md)。
- 独立图片直接展示，并与文本内图片区分。单击选择，双击或 `Enter` 打开单项，支持多选和主动清理确认。
- 默认混排；分离时按文本、图片、文件映射排列，组内置顶优先并沿用当前排序。
- 类型筛选默认全选，允许全部取消；无匹配时显示“无匹配收集项”和“重置筛选”。隐藏条目取消选择，`Ctrl+A` 只选择可见项。
- 排列和筛选按格子独立保存并在重启后保留，选择集合不持久化。
- 格子右键菜单提供“混排”“分离”，分隔线划分不同类型；右上角菜单将排序单选项和类型复选项放在一起，用圆点和勾选区分，切换条件时保持菜单打开。
- 默认格子 `360 × 280 DIP`，窄版 `240 × 280 DIP`，折叠高 `56 DIP`；标题 `28px`，工具按钮 `24px`，图标 `16px`，内容左右留白 `10 DIP`，条目间距 `6 DIP`，类型分隔线 `1px`，底部投放带和状态栏各 `24 DIP`。
- 独立图片在 `78 × 52 DIP` 区域内等比完整显示；列表保持静态缩略图，文档编辑窗呈现原图。加载和失败保持相同轨道。
- 收集箱设置提供“图片预览宽度（DIP）”，范围 `48–156`，默认 `78`；失焦或 `Enter` 保存，非法输入恢复已保存值，图像槽高度为宽度的 `2/3`。图片项悬停沿用文本项的 `500ms`、定位和关闭规则，在 `520 × 420 DIP` 浮层内等比完整显示；非 GIF 大图长边最多读取 `768` 物理像素，GIF 播放原图动画。列表保持静态缩略图，加载和失败保持浮层尺寸，关闭时释放前端引用并拒绝迟到结果。
- 列表单独滚动，投放带和状态栏固定在底部。折叠态摘要只显示首行并省略超宽文字与后续行；展开态最多三行，压缩无意义空行，不改写原文和完整导出正文。
- 条目不显示手风琴箭头或常驻编辑按钮，直接显示标题和最多三行紧凑纯文本摘要。悬停 `500ms` 显示无标题、可滚动、可选择复制的 Markdown 只读预览，图片使用文字占位；离开条目、菜单、拖动、收起、失焦和销毁时关闭预览。
- 筛选菜单宽 `208 DIP`，内容右键菜单宽 `232 DIP`，菜单行高 `28px`，正文 `13px`，圆角 `6px`。沿用独立界面主题，桌面半透明表面沿用桌面主题。
- 选中使用强调色 `18%` 底色及边框，键盘焦点使用独立内环；悬停和选择不改变尺寸。
- 删除确认显示总数、类型数量和共享影响，默认焦点为取消。投放只突出命中的文本项或空白投放带，结束时清理；空白带只在命中时显示“新建收集项”。
- 投放跳过不匹配项并继续处理匹配项，同次操作内后续同类型被拒绝项直接跳过；汇总处理、跳过和失败，不宣称整批成功。

## 普通应用界面

普通应用界面包括启动状态、设置、错误、诊断页面和其他非透明应用窗口。

### 权威参考

- 全局主题：`src/styles/global.css`。
- 应用根布局：`src/app/App.css`。
- 具体控件：组件同名 CSS 文件。

### 基础规则

- 页面背景使用 `--color-background`，内容表面使用 `--color-surface`。
- 边框、文本和状态颜色使用全局 CSS 中已有的语义变量，不在组件中重复声明近似颜色。
- 面板和控件圆角以 `4px` 至 `6px` 为主；主要命令按钮高度不低于 `38px`。
- 同时维护浅色和深色模式下的对比度、边框可见性和焦点边界。
- 内容区保持清晰层级和紧凑间距，不将页面分区统一包装成悬浮卡片。
- 收集项编辑窗口遵循[收集项编辑窗口](收集项编辑窗口.md)的正文、命名、保存和关闭规则。

### 设置、消息与托盘

- 收集箱二级设置提供“图片文件收入方式”；本地时间只提供时间格式和显示秒数。沿用设置行、下拉框、串行保存和错误反馈；无原始路径的图像数据写入资源目录。
- 收集箱拖动进入时临时展开呈现条目；命中文本项按类型追加，命中图片或映射项跳过，其他格子内位置按类型新建；离开或取消后恢复折叠。音乐收到单个支持的媒体文件后交给系统默认程序打开。
- 原生消息的 loading 图标使用 `resources/loading.svg`，保留逐段透明度并按当前界面图标色着色；按 DPI 缓存栅格化蒙版，旋转帧只变换缓存图像。
- 设置页标题、标签和说明文字不可选中；输入框、文本区域和可编辑内容保留文本选择与编辑能力。
- 消息显示时长由 `durationMs` 按毫秒传入，省略时使用 `4000ms`；各消息独立离场，悬停暂停计时。loading 每秒旋转一圈，折叠隐藏或动画关闭时不刷新。消息颜色只跟随已解析的界面与菜单主题。
- 性能页提供“有应用全屏、最大化时暂停刷新”“有应用获取焦点时暂停刷新”“跟随系统减少动态效果控制”“界面动画”。前两项默认关闭，后两项默认开启跟随系统；跟随系统开启时禁用“界面动画”，关闭后恢复并立即应用保留值。
- 外观设置分为“桌面网格主题”和“界面与菜单主题”两组。每组独立设置深浅模式、使用 Windows 主题色和自定义主题色；开关启用时禁用色块但保留自定义颜色。
- 桌面主题作用于未归类桌面项目、文件围栏和功能格子；界面主题作用于普通应用界面及自绘右键菜单。Windows 原生桌面、文件和托盘菜单由系统呈现。
- 桌面主题缺失时使用跟随系统、`#2563eb`、关闭 Windows 主题色的固定默认值；两组独立保存，保存成功后同步各窗口，失败时保留已保存状态并显示错误。
- 两组主题色分别控制各自作用域的焦点和选中表面；圆角、字体和字号共用。系统图标字体、窗口原生按钮和时钟数字不参与普通正文缩放。
- 设置窗口使用 Tauri 无装饰窗口与 Windows 原生阴影，前端标题栏高 `38px`；拖动、最小化、最大化和还原委托 Tauri 原生接口。窗口按需创建，关闭时销毁页面但不退出后台程序，重新打开时读取偏好。
- 设置界面反馈统一通过消息显示模块呈现，消息不抢占输入焦点，动画跟随 `interfaceAnimations` 和系统减少动态效果设置。
- 原生 Toast 默认宽 `296 DIP`、最小高 `64 DIP`、圆角 `6px`，使用界面与菜单主题的表面、边框、正文和次要文本颜色。长正文按 DirectWrite 测量换行增高，超过工作区可用空间时省略，关闭轨道不被正文挤占。
- Toast 前景完整显示；折叠时露出两层旧消息表面，比例为 `100%/94%/88%`，每层向上露出 `14 DIP`。悬停展开，离开收起，展开间距 `14 DIP`。关闭使用 Lucide `circle-x` 的 `18px` 图标和 `32 × 32px` 命中区；折叠后层及离场消息不可关闭。右侧、底部距主显示器工作区 `16 DIP`。
- Toast 进场 `250ms ease-out`，从下方 `16 DIP` 上移并淡入；离场 `250ms ease-in`，下移并淡出。每条消息独立动画，连续反向从当前呈现状态衔接；动画关闭时立即落位。
- 桌面网格和围栏平铺网格独立设置格子宽高及横纵间距（DIP）；列表模式保持行布局。默认桌面步进 `78 × 98`，围栏步进 `74 × 98`。
- 文件围栏、本地时间、Debug 和音乐共用 `DesktopTileBase` 表面、`28px` 标题轨道、覆盖式滚动视口和八向缩放区域。功能开关只隐藏实例并保留布局；Debug 只在 Rust Debug 构建中注册。
- 围栏、文件夹门户和功能格子共享折叠动效：外框高度和内容透明度使用 `120ms ease-out`，内容裁剪且不缩放。默认折叠高 `28px`，收集箱为 `56px`。
- 设置导航在 `224px` 与 `64px` 宽度之间使用 `120ms ease-out` 收展；分类切换只过渡内容区，旧内容向上 `4px` 淡出，新内容从下方 `4px` 淡入。
- `followSystemReducedMotion` 为 `true` 时使用 Windows 减少动态效果状态，否则使用保留的 `interfaceAnimations`；动画关闭时立即进入目标状态。
- 设置采用左侧导航、右侧标题和设置行布局；导航用强调条标识当前页面，设置行使用轻边框和现有圆角，不将整页包装成卡片。
- 托盘右键菜单使用 Windows 原生菜单；左键只切换设置窗口，不影响透明桌面工作区。

## 透明桌面工作区

透明桌面工作区包括桌面项目、围栏、桌面组件、桌面菜单和状态提示。

### 权威参考

- 工作区：`src/features/workspace/`、`src/features/tile-content/fence/`、`src/features/tiles/` 及同名 CSS 文件。
- 公共外壳、标题、菜单和滚动视口：`src/features/tiles/` 下对应组件及同名 CSS。
- 工作区主题：`src/features/workspace/surface/DesktopWorkspace.css`。
- 围栏成员与投放状态：`src/features/tile-content/fence/FenceTile.css`。
- 桌面项目：`src/features/desktop-items/DesktopItemGrid.css`。

### 基础规则

- 根表面保持透明，Windows 壁纸是实际背景。
- 围栏使用半透明表面和轻量背景模糊，默认不使用阴影；圆角 `2px`，标题栏高 `28px`。
- 围栏最小内容视口 `164 × 110px`，外壳每侧 `1px` 边框和 `1px` 留白；固定标题时整体最小尺寸 `168 × 142px`，悬浮标题时 `168 × 114px`。后端持久数据底线为 `80 × 48 DIP`，临时投射可以按更小视口裁剪，折叠尺寸独立。
- 标题栏图标按钮 `24 × 24px`，内部图标 `16 × 16px`。公共标题默认固定显示，按钮默认悬停显示；悬浮标题覆盖顶部 `28 DIP`，内容不位移，离开顶部 `200ms` 后隐藏。
- 格子移动期间显示开始移动时的完整静态帧，结束或取消后恢复当前内容；尺寸调整使用真实组件实时排版，释放时一次提交，取消恢复原始尺寸。跨屏移动使用目标屏可见格子的同一吸附规则。
- 临时自动展开的格子位于焦点格子上方、菜单和拖动预览下方；收起后恢复原层级，保持键盘焦点和保存的布局顺序。
- 文件夹门户遵循[文件夹门户](文件夹门户.md)的导航、紧凑列表、分组菜单和消息通知规则。
- 父子菜单共用界面与菜单主题，不随桌面网格主题变化；右侧不足向左展开，底部不足上移，菜单保留固定图标列。
- 格子和所属一级、二级菜单共用悬停范围；离开整个范围后收起。菜单外点击、焦点移出菜单组或窗口失焦时关闭菜单，父子菜单间转移不关闭。

### 格子与项目

- 文件标题工具依次为排序、布局切换、折叠/展开；时钟、Debug、音乐只提供折叠/展开。折叠时自动展开通过菜单设置。
- 围栏排序图标使用 `resources/fence-sort.svg`（Lucide `list-sort-descending`），通过 `currentColor` 继承同组图标色调；启用排序使用正常前景色，否则使用弱化前景色。
- 音乐控制使用 `resources/music-*.svg`（Lucide `skip-back`、`play`、`pause`、`skip-forward`），图标 `16 × 16px`，按钮保留中文名称并隐藏图标的辅助技术文本。
- 音乐宽布局无内边距，左侧封面、右上信息、右下按钮；紧凑布局以封面作为裁切背景，信息和按钮贴底，内边距 `6px`。文字元素高 `1lh`，三行间距 `2px`，按钮高 `24px`。
- 音乐设置提供“显示媒体来源”；关闭后只隐藏来源名称，播放状态继续显示，专辑封面始终按当前快照显示。
- 未归类桌面项目和围栏平铺使用 `48 × 48px` 图像外框，围栏列表使用 `36 × 36px`；缩略图等比居中，不拉伸或裁切，加载或提取失败时显示系统图标。
- 桌面项目图像不显示音乐角标、视频胶片边框或快捷方式箭头，不额外绘制装饰。
- 桌面项目名称使用 `12px`、最多两行，并通过文字阴影保证壁纸上的可读性。
- Hover、Selected、Focus、Drop Target 和 Disabled 状态必须可区分，且不得改变项目轨道尺寸。
- 右键菜单使用 Windows 菜单的紧凑密度，不使用卡片化表现；所有菜单项预留 `16px` 图标列和 `8px` 间距。
- Desktop Tools 子菜单按“移动到已有围栏、移出围栏、新建围栏并移入”排列；不提供“编辑布局”。框选复用现有选框颜色、边框和填充，围栏内选框裁剪到内容视口。
- 公共格子菜单按“重命名、标题显示方式、功能选项显示”和“折叠时自动展开、折叠/展开”分组；收集箱追加“恢复最近删除”以及“新建收集项、移除”操作组。各组复用 `DesktopTileMenu` 的 `separatorBefore`、菜单主题、紧凑间距和键盘导航。
- 桌面主题独立维护围栏表面、边框、文字及交互状态；自绘菜单按界面主题维护变量，不继承围栏颜色。

### 禁止事项

- 不给透明桌面工作区增加不透明页面背景。
- 不将围栏改成普通白色内容卡片。
- 不使用大圆角、装饰性阴影或悬浮面板构图。
- 不通过 Hover 缩放控件或项目。
- 不以视觉统一牺牲壁纸可见性、文字可读性或交互状态辨识度。

## 实现验收

- 明确修改属于普通应用界面还是透明桌面工作区。
- 复用已有 CSS 变量和组件规则，不创建语义重复的近似值。
- 对照当前组件实现和既有视觉行为，确认无意外回归。
- 分别检查桌面网格与界面菜单的浅色、深色、跟随系统设置，以及两组采用不同深浅模式和强调色的组合。
- 在真实壁纸背景下检查透明工作区的文字、边框、选择和焦点状态。
- 检查 Hover、Focus、Selected、Disabled、Drop Target 和错误状态。
- 检查目标窗口尺寸下的遮挡、溢出和布局跳动。
