# Desktop Tools 视觉规范

## 使用方式

修改 UI 前依次检查：

1. 当前用户要求。
2. 本文档对应场景规则。
3. 当前组件及全局 CSS 变量。

不得仅凭通用 UI 设计经验改变现有风格。具体色值、尺寸和间距以代码中的 CSS 变量与现有组件规则为准，本文档只记录设计语义、使用边界和稳定基线。

## 全局设计语言

- 产品气质：Windows 原生感、安静、精密、紧凑。
- 字体：`"Segoe UI Variable", "Segoe UI", sans-serif`。
- 字号：正文以 `12px` 至 `13px` 为主，根据信息层级使用现有组件字号。
- 字间距：保持 `0`，不使用负字间距。
- 圆角：主要使用 `0` 至 `6px`，不使用胶囊式容器。
- 图标：使用统一图标来源，不使用 Emoji 作为界面图标。
- 动效：只表达状态变化，不作装饰；状态变化不得引起布局跳动。
- 布局：保持稳定尺寸和紧凑信息密度，避免营销页面式构图。

## 普通应用界面

普通应用界面包括启动状态、设置、错误与诊断页面，以及其他非透明应用窗口。

### 权威参考

- 全局主题：`src/styles/global.css`。
- 应用根布局：`src/app/App.css`。
- 具体组件：组件同名 CSS 文件。

### 视觉规则

- 页面背景使用 `--color-background`，内容表面使用 `--color-surface`。
- 收集项编辑窗口的 UX 与 UI 均已确认，正文、命名、保存与关闭流程遵循[收集项编辑窗口](收集项编辑窗口.md)；浏览器预览已验证，原生窗口实机验收仍单独记录。
- 边框、文本和状态颜色使用 `src/styles/global.css` 中已有的语义变量。
- 面板和控件圆角以 `4px` 至 `6px` 为主。
- 主要命令按钮高度不低于现有的 `38px` 基线。
- 同时维护系统浅色和深色模式下的对比度与边框可见性。
- 内容区保持清楚的层级和紧凑间距，不堆叠装饰性卡片。

### 禁止事项

- 不在组件中重复声明已有全局语义颜色。
- 不使用大面积渐变、装饰光球或模糊背景图形。
- 不使用营销页面式大标题和大面积留白。
- 不将页面分区统一包装成悬浮卡片。

### 设置窗口与系统托盘

- 收集箱二级设置拥有“图片文件收入方式”，本地时间仅拥有时间格式和显示秒数。复用现有设置行、下拉框、保存互斥和错误反馈；无原始路径的图像数据统一写入资源目录。此纠错与统一拖放接收由用户授权复用现有界面，跳过单独 UX/UI 设计确认。
- 收集箱接受的拖动进入时临时展开以呈现条目，命中条目则追加，其他格子内位置则新建；离开或取消恢复折叠状态。音乐收到单个支持的媒体文件后交给系统默认程序打开，不增加播放承诺或新界面。禁止目标沿原生禁止光标反馈，不穿透格子。

- 原生消息的 loading 图标使用 `resources/loading.svg`，保留资源路径与逐段透明度，按当前界面图标色着色。按 DPI 缓存栅格化蒙版，旋转帧只变换缓存图像，不重绘另一套近似线段。

- 设置页的标题、标签和说明文字不可选中；输入框、文本区域及可编辑内容保留文本选择和编辑能力。
- 消息显示时长由 `durationMs` 按毫秒传入，省略时前端使用 4000ms；不同期限独立触发离场，悬停暂停计时。loading 在可见内容层每秒旋转一圈，折叠隐藏或有效动画关闭时不刷新。消息颜色只跟随程序已解析的“界面与菜单主题”深浅色，不单独读取或监听系统颜色。

- 性能页使用既有设置行、SettingsSwitch 与 SettingsInfo 提供“有应用全屏、最大化时暂停刷新”和“有应用获取焦点时暂停刷新”。默认关闭；前者仅暂停被前台窗口完全覆盖的屏幕，后者暂停全部桌面并明确提示可见内容也会停更。沿用已有串行保存、失败反馈和禁用状态，不新增桌面浮层。此需求由用户明确授权复用现有视觉规则并跳过单独 UX/UI 确认。
- 性能页使用相同设置行提供“跟随系统减少动态效果控制”和“界面动画”。前者默认开启；开启时保留并禁用后者，由 Windows 减少动态效果设置决定实际动画。关闭跟随后恢复“界面动画”操作并立即应用其保留值。该设置沿用现有串行保存、失败反馈和禁用状态；用户明确授权复用现有视觉规则并跳过单独 UX/UI 确认。

- 外观设置按「桌面网格主题」「界面与菜单主题」上下分组，每组独立提供深浅模式、使用 Windows 主题色开关和自定义主题色色块。沿用现有设置行，开关启用时禁用该组色块并保留自定义颜色。
- 桌面主题作用于未归类桌面项目、文件围栏及功能格子；界面主题作用于普通应用界面及自绘右键菜单和子菜单。Windows 原生桌面、文件与托盘菜单由系统呈现。
- 桌面主题缺失时使用固定默认值：深浅模式跟随系统、自定义主题色为 `#2563eb`、使用 Windows 主题色关闭，不复制界面主题。两组独立保存，保存成功后同步各窗口，失败保留已保存状态并显示错误。

- 外观偏好按作用域应用：两组主题色分别控制各自的焦点和选中表面，圆角、字体和字号仍共用，控制普通表面、正文及桌面项目名称。系统图标字体、窗口原生按钮与时钟展示数字不作为普通正文缩放。
- 外观配置圆角范围为 0 至 12px，字号为 12 至 18px；围栏圆角上限维持 8px，避免过大圆角侵入标题栏与缩放手柄。

- 设置窗口采用 Tauri 无装饰窗口与 Windows 原生阴影；前端提供 38px 自定义标题栏和窗口命令，拖动、最小化、最大化与还原委托 Tauri 原生接口。窗口按需创建，关闭销毁页面，不退出后台程序；重新打开读取偏好。此方案不是 Electron Window Controls Overlay，不承诺原生最大化悬停菜单；Windows 可能保留用于阴影的 1px 系统边缘。
- 设置界面的操作反馈统一通过消息显示模块呈现，消息由统一消息管道创建，支持信息、成功、警告和错误状态；消息不抢占输入焦点，动画跟随 `interfaceAnimations` 与系统减少动态效果设置。
- 原生 Toast 使用“界面与菜单主题”的表面、边框、正文和次要文本颜色；字体、字号、圆角沿用界面外观偏好，默认宽 296 DIP、最小高 64 DIP、圆角 6px。长正文按 DirectWrite 测量换行增高，超过当前工作区五条堆栈的可用空间时省略，关闭轨道不能被正文挤占。浅深主题切换同步作用于现有消息，不重播动画或重置计时。
- Toast 前景完整显示，折叠只露出两层旧消息表面，比例 100%/94%/88%，每层向上露出 14 DIP；后层内容在让位过程中淡出。悬停展开，离开收起，展开间距 14 DIP。关闭采用 Lucide circle-x 的 18px 路径与 32×32px 命中区；折叠后层及离场消息不可关闭。右侧、底部距主显示器工作区 16 DIP。
- Toast 进场为 250ms ease-out，从下方 16 DIP 向上移动并从透明变为不透明；离场为 250ms ease-in，向下移动并淡出。每条消息独立动画，新消息到来时旧层从当前大小平滑缩至 94%/88% 并上移，关闭后反向补位；整栈不横移或共同淡入。悬停切换同为 250ms，连续反向从当前呈现帧衔接；有效动画关闭时立即落位。上述规则已确认，程序实机验收与设计确认分别记录。
- 桌面网格与围栏平铺网格独立设置格子宽高及横纵间距（DIP），列表模式保持原有行布局。默认桌面步进为 78 × 98，围栏步进为 74 × 98；名称在小格子中适度收紧字号以避免溢出。应用网格变更时同步权威落位与命中边界，空间不足不提交。
- 文件围栏、本地时间、Debug 与音乐共用 `DesktopTileBase` 表面、28px 标题轨道、覆盖式滚动视口和八向缩放区域，沿用围栏主题变量及边缘对齐规则。功能开关只隐藏实例并保留布局；格子折叠只隐藏内容视口。Debug 格子只在 Rust Debug 构建中注册及提供设置入口。消息测试按键放在 Debug 格子内容区，随格子滚动，不在桌面额外固定显示。
- 围栏、文件夹门户和功能格子通过公共外壳执行同一折叠动效：外框高度与内容透明度使用 `120ms ease-out` 过渡，内容被裁剪且文字、图标和媒体不缩放。默认折叠高度为 28px，调用方可通过 `collapsedSize` 指定折叠尺寸；收集箱使用 56px，并以正常字号显示最新标题和文本，空时仅显示“收集箱”。连续反向切换从当前呈现状态转向最新目标，拖动和尺寸调整保持实时响应，不经过折叠过渡。
- 设置导航在 224px 与 64px 宽度之间使用 `120ms ease-out` 收展，品牌文字和分类名称同步淡出或淡入，图标、切换按钮及命中尺寸保持稳定。设置分类切换只过渡内容区，旧内容向上 4px 淡出，新内容从下方 4px 淡入；导航选中状态、标题和可访问属性立即更新。
- 上述动效统一使用 `PreferencesProvider` 解析的有效动画状态；`followSystemReducedMotion` 为 `true` 时使用 Windows 减少动态效果状态，为 `false` 时使用保留的 `interfaceAnimations`。实际动画关闭时立即进入目标状态，不补播动画。
- 采用用户参考图的左侧导航、右侧标题和设置行布局，使用 Desktop Tools 品牌，不照搬参考产品的功能栏目。
- 左侧导航以强调条标识当前页面，右侧设置行使用轻边框及现有圆角；不将整页包装为卡片。
- 控件保持系统原生感，主题使用现有全局语义变量，并同步维护浅色和深色模式。
- 托盘右键菜单由 Windows 原生菜单呈现，不使用 HTML 仿制；左键仅切换设置窗口，不影响透明桌面工作区。
- 本次实施范围与验收记录保留在项目实现和版本历史中。

## 透明桌面工作区

透明桌面工作区包括桌面项目、围栏、桌面组件、桌面菜单和状态提示。

### 权威参考

- 透明桌面工作区：`src/features/workspace/`、`src/features/tile-content/fence/`、`src/features/tiles/` 及其同名 CSS 文件。
- 公共外壳、标题、菜单与滚动视口：`src/features/tiles/` 下对应组件及同名 CSS。
- 工作区主题：`src/features/workspace/surface/DesktopWorkspace.css`；围栏成员与投放状态：`src/features/tile-content/fence/FenceTile.css`。
- 桌面项目实现：`src/features/desktop-items/DesktopItemGrid.css`。

### 视觉规则

- 根表面保持透明，Windows 壁纸是实际背景。
- 临时自动展开的格子显示在焦点格子上方、菜单与拖动预览下方；收起后恢复原层级，保持键盘焦点和保存的布局顺序。
- 文件夹门户的 UX 与 UI 已确认，导航、紧凑列表、分组菜单及消息通知遵循[文件夹门户](文件夹门户.md)；设计确认不代表产品实现或实机验证完成。
- 围栏使用半透明表面和轻量背景模糊；默认不使用阴影。
- 围栏圆角使用当前 `2px` 基线，标题栏高度使用当前 `28px` 基线。
- 围栏最小内容视口为 `164 × 110px`，包含内容内部留白，不含外壳及标题。外壳每侧 `1px` 边框与 `1px` 留白另计；固定标题占 `28px`，整体最小尺寸为 `168 × 142px`，悬浮标题覆盖内容而不占位，整体最小尺寸为 `168 × 114px`。该约束只控制有效呈现和交互，后端持久数据底线统一为 `80 × 48 DIP`；临时投射可按更小视口裁剪，折叠尺寸独立。
- 围栏标题栏图标按钮使用当前 `24px × 24px` 基线，内部图标使用当前 `16px × 16px` 基线。
- 公共标题默认固定显示，按钮默认悬停显示；悬浮标题覆盖顶部 28 DIP，内容不位移。进入顶部立即显示，离开后延迟 200ms 隐藏，连续拖动期间冻结标题显示状态，释放后的下一次普通鼠标移动才重新判断。
- 格子移动期间统一显示开始移动时的完整静态帧，本屏和跨屏使用同一帧，时间、封面和内容动画不更新移动中的画面；结束或取消后恢复当前内容。尺寸调整使用真实组件实时排版，围栏内容始终按当前视口裁剪，音乐组件随宽度切换布局；释放时一次提交，取消恢复原始尺寸。跨屏移动预览与释放使用目标屏实际可见格子的同一吸附规则，并以指针所在屏幕决定归属。
- 收集箱折叠态摘要仅显示首行，超宽文字与后续行省略，正文不得溢出 56px 格子；展开态摘要仍按原文换行，最多三行。
- 文件标题工具依次为排序、布局切换、折叠/展开；时钟、Debug、音乐只提供折叠/展开。折叠时自动展开通过菜单设置。
- 父子菜单同时显示并共用「界面与菜单主题」，不随桌面网格主题变化；右侧不足向左展开，底部不足上移。菜单预留固定图标列，功能选项在悬浮标题模式下保留偏好标记并禁用修改。
- 围栏排序图标使用 `resources/fence-sort.svg`（Lucide `list-sort-descending`），通过 `currentColor` 继承同组图标色调；启用排序使用正常前景色，无排序使用弱化前景色。
- 收集箱工具区复用围栏排序图标与公共排序菜单，依次为排序、新建和折叠。新建与置顶标记使用现有图标；条目不显示手风琴箭头或常驻编辑按钮，直接显示标题和最多三行保留原文换行的纯文本摘要，单击整条打开编辑窗，右键菜单增加“打开”。悬停 500ms 显示无标题、可滚动、可选择复制的 Markdown 只读预览，图片使用文字占位；鼠标离开条目立即关闭预览，菜单、拖动、收起、失焦和销毁立即清理悬停状态。条目、摘要和预览样式归属 `CollectBox.css`，标题与命令轨道由公共标题组件负责。
- 音乐控制使用 `resources/music-*.svg`（Lucide `skip-back`、`play`、`pause`、`skip-forward`），沿用 `16px × 16px` 图标基线和 `currentColor`；图标隐藏于辅助技术，按钮保留中文名称。
- 音乐内部呈现和最小内容尺寸测量归属 `MusicControl`，通过 `onMinimumSizeChange({ width, height })` 上报结果。`MusicWidget` 转交事件；`MusicTile` 仅叠加标题栏和外壳占用，交给公共几何逻辑限制缩放并保存外框尺寸，不查询音乐组件内部 DOM 或 CSS 类名。封面、动画变换及外框拉伸产生的空白不参与内容最小尺寸计算。
- 音乐控件当前定稿包含宽布局与紧凑布局。宽布局无内边距，左封面、右上信息、右下按钮；紧凑布局以封面作为裁切背景，信息与按钮整体贴底，内边距 `6px`。文字元素高度为 `1lh`，三行间距 `2px`；按钮高度统一为 `24px`，图标 `16px`。具体尺寸、最小高度计算、阈值与待验证边界见 [音乐控件](音乐控件.md)。
- 音乐控制设置提供“显示媒体来源”偏好。媒体来源关闭后仅隐藏来源名称，播放状态继续显示；设置保存后通过偏好事件即时应用到音乐格子。专辑封面始终按当前音乐快照显示。
- 未归类桌面项目和围栏平铺的系统图像沿用 `48px × 48px` 外框，围栏列表沿用 `36px × 36px` 外框。缩略图在外框内保持比例并居中，不拉伸或裁切内容；加载中或提取失败显示系统图标。此范围同时覆盖这些项目的原生拖动图像，不包含文件夹门户的独立图标呈现。此项按用户授权直接落实已有布局与明确显示要求，无需单独 Penpot 评审，仍须完成[系统缩略图验收](../validation/系统缩略图验收.md)。
- 桌面项目的系统封面、缩略图和回退图标不显示音乐应用角标、视频胶片边框或快捷方式箭头，避免附加装饰遮挡内容；此约束作用于程序呈现，不更改 Windows 全局设置。当前使用内容缩略图和无叠加请求的图标，不额外绘制装饰；不同 Shell 处理器及快捷方式的实机显示仍须验收。
- 桌面项目名称使用当前 `12px`、最多两行的规则，并通过文字阴影保证不同壁纸下的可读性。
- Hover、Selected、Focus、Drop Target 和 Disabled 状态必须可区分，且不得改变项目轨道尺寸。
- 右键菜单贴近 Windows 菜单的紧凑密度，不使用卡片化表现。
- 项目原生菜单的 Desktop Tools 子菜单按“移动到已有围栏、移出围栏、新建围栏并移入”排列，不提供无效的“编辑布局”。框选复用现有选框颜色、边框和填充，围栏内选框裁剪到内容视口；不增加弹窗或长按反馈。本项已获用户授权直接复用现有样式并跳过单独 Penpot UX/UI 确认。
- 公共格子菜单按“重命名、标题显示方式、功能选项显示”和“折叠时自动展开、折叠/展开”分组；音乐控制直接沿用。收集箱在其后追加“恢复最近删除”内容组，以及“新建收集项、移除”操作组；“新建收集项”与工具栏新建按钮共用动作，工具未就绪时禁用。“移除”仅作用于当前格子，保留共享内容，可通过布局撤销恢复。各组之间复用 `DesktopTileMenu` 的 `separatorBefore` 分割线，沿用菜单主题、紧凑间距和键盘导航，不新增样式。
- 桌面独立深浅主题维护围栏表面、边框、文字及交互状态；自绘菜单在自身样式中按界面深浅主题维护对应变量，不继承围栏颜色。

### 禁止事项

- 不给透明桌面工作区增加不透明页面背景。
- 不将围栏改成普通白色内容卡片。
- 不使用大圆角、装饰性阴影或悬浮面板构图。
- 不通过 Hover 缩放控件或项目。
- 不为视觉统一牺牲壁纸可见性、文字可读性或交互状态辨识度。

## 修改验收

原生消息的透明背景及 SVG loading 实际动画观感已获用户实机确认；自动检查范围与未验证场景见[原生消息验收](../validation/原生消息验收.md)。

### 浅色围栏与菜单补充

- 围栏内项目使用围栏主题的深色文字，浅色模式取消文字黑色阴影；未归类桌面项目保持壁纸可读性规则。
- 普通围栏菜单和排序菜单共用主题表面、边框及交互变量；不得仅对排序菜单切换主题。
- 所有菜单项预留固定 `16px` 图标列及 `8px` 间距，没有图标的命令也保持文字起点一致。
- 浅色模式降低边框、阴影、悬停和选中表面对比度，保留文字可读性及焦点边界。

### 验收清单

- 明确修改属于普通应用界面还是透明桌面工作区。
- 复用已有 CSS 变量和组件规则，不创建语义重复的近似值。
- 对照当前组件实现和既有视觉回归检查，确认已有视觉行为未被无意改变。
- 分别检查桌面网格与界面菜单的浅色、深色和跟随系统设置，以及两组采用不同深浅模式与强调色的组合。
- 透明桌面工作区需要在真实壁纸背景下检查文字、边框、选择和焦点状态。
- 检查 Hover、Focus、Selected、Disabled 和错误状态是否完整。
- 检查目标窗口尺寸下是否存在遮挡、溢出或布局跳动。

主题分组功能已获用户实机确认，验证范围及自动检查结果见[外观主题独立设置](../validation/外观主题独立设置.md)。
