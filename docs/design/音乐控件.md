# 音乐控件

## 定稿范围与实现来源

当前音乐控件的布局与视觉参数已由用户定稿，以 `src/features/tile-content/music/MusicControl.tsx`、同名 CSS 和 `musicLayout.ts` 的当前实现为准。视觉定稿不等同于所有原生交互与动画场景已完成验收。

公共表面、标题栏、主题和缩放规则沿用 [视觉规范](视觉规范.md) 与 [共享格子外观并隔离布局撤销](../adr/0018-共享格子外观并隔离布局撤销.md)。本文件不重新定义设置窗口的视觉方案。

## DOM 与布局归属

```text
music-control
├── music-control__artwork
└── music-control__body
    ├── music-control__metadata
    └── music-control__actions
```

封面直接归属根容器。右栏负责信息与按钮的纵向编排；宽布局顶部为信息、底部为按钮，紧凑布局将整个右栏贴底。

| 属性         | 宽布局                                 | 紧凑布局                     |
| ------------ | -------------------------------------- | ---------------------------- |
| 根容器内边距 | 0                                      | 6px                          |
| 封面         | 左侧正方形，顶部对齐                   | 绝对定位铺满根容器，居中裁切 |
| 左右列间距   | 12px                                   | 单列                         |
| 按钮宽度     | 三列，各列最大 88px，按钮最小宽度 24px | 固定 40px                    |
| 按钮高度     | 24px                                   | 24px                         |
| 按钮间距     | 11px                                   | 4px                          |
| 按钮组内边距 | 3px                                    | 3px                          |
| 按钮圆角     | 3px                                    | 3px                          |
| 图标         | 16 × 16px                              | 16 × 16px                    |

封面 CSS 当前公式为 `min((100cqw - 24px) × 0.4, max(0px, 100cqh))`。容器查询宽高来自外部音乐内容容器；宽布局根容器本身没有 padding，公式中的 24px 是显式扣除项。封面只读取已分配空间，不参与外框最小尺寸计算。紧凑布局覆盖该尺寸，使用根容器的全部宽高。

## 字体与显式间距

歌曲名称和艺人继承 `--interface-font-size`，默认 13px；来源字号为该变量的 `12 / 13`，默认 12px。字体继承项目界面字体，歌曲名称字重为 400；艺人和来源透明度为 0.78。

三行均使用 `line-height: max(16px, 1.2em)` 与 `height: 1lh`，元素高度对应一行行盒，空文本保留相同高度。网格行使用 `max-content`，不通过更大的固定轨道制造文字下方留空；当前行间距为 `gap: 2px`。文字单行截断，保留原生完整文本提示。

## 最小尺寸职责

`MusicControl` 使用私有 refs 和 `ResizeObserver` 测量信息及按钮组，通过 `onMinimumSizeChange` 上报内容需求；使用 `offsetHeight` 排除动画变换，不测封面或被外框拉伸后的右栏空白。

```text
内容最小宽度 = ceil(max(168, CSS min-width))
内容最小高度 = ceil(max(94, 信息区高度 + 按钮组高度 + 根容器上下 padding))
外框最小宽度 = 内容最小宽度 + 24
外框最小高度 = 内容最小高度 + 24 + 固定标题栏的 28
```

外层 24px 包含视口上下各 10px 的内边距，以及外壳两侧各 1px padding 和 1px border。`MusicWidget` 透传结果，`MusicTile` 只叠加外壳占用并交给公共几何交互。

默认字号下，信息区为 `16 × 3 + 2 × 2 = 52px`，按钮组为 `24 + 3 × 2 = 30px`。宽布局内容需求 82px，紧凑布局内容需求 94px，均取 94px 保底，因此固定标题外框最小基线为 `192 × 146px`。较大字号可能提高高度下限；降低下限不会自动缩小已保存的外框。折叠状态只显示 28px 标题轨道。

## 模式切换与动画

`musicLayout.ts` 依据扣除当前根容器左右 padding 的内容宽度及字号判断模式，高度不参与选择。当前下界公式为 `ceil((144 × fontSize / 13 + 12) / 0.7) + 5`。

默认 13px 字号：宽布局在内容宽度 ≤228px 时进入紧凑，紧凑在 ≥244px 时进入宽布局，中间保持原模式；初次以 236px 为分界。大字号提高阈值。

仅跨模式时执行 180ms ease-out 过渡：封面平移与缩放，信息和按钮所在区域仅平移，字体与图标不缩放。连续切换采样当前呈现位置并取消旧目标。有效动画状态由 `PreferencesProvider` 按 `followSystemReducedMotion` 选择 Windows 减少动态效果状态或 `interfaceAnimations`；动画关闭时立即切换。

## 主题、媒体与可访问状态

表面沿用围栏 58% 半透明主题。紧凑且封面成功加载时，使用白色文字与黑色遮罩：顶部透明度 12%，40% 位置为 35%，底部为 82%。无封面或加载失败时恢复对应主题，不显示失效图像；信息和按钮不移位。

无会话时保留空信息与禁用按钮。按钮保持中文可访问名称，图标不参与辅助技术及指针命中；禁用透明度 0.48，键盘焦点为 2px 描边、1px 偏移。播放中按钮为暂停，其他状态为播放；不支持的动作和命令执行期间禁用。错误继续交给现有消息管道。

## 验证边界

统一原生拖放按 [ADR-0017](../adr/0017-分离系统拖放与布局投放结果.md) 的媒体白名单接收单个文件，复用系统默认打开入口，不增加新的播放界面。打开后沿用现有媒体会话更新，不保证自动播放，也不向原全局会话补发播放命令。此次用户授权复用已有界面并跳过单独 UX/UI 设计确认；真实播放器响应仍需实机验收。

当前代码的封面比例为 40%，而阈值函数仍保留按 30% 封面推导的 `/ 0.7`。此外，宽布局 padding 为 0，紧凑为 6px，因此相同根容器宽度下，两种模式传入判定的宽度相差 12px；16px 的函数滞回不等于根容器上的同等切换间隔。这些是当前实现事实，临界宽度下右栏可读性及实际切换区间需单独验收，不能视为已验证一致。

需在当前原生宿主核对：阈值往返拖动、窄高与宽矮、12–18px 字号、长文本、封面失败、连续动画中反向切换、动画开关跨窗口同步、跟随开关与系统减少动态效果组合及真实壁纸对比度。本次文档定稿只核对源码与文档一致性，不补记未经执行的运行时验收结果。
