# 围栏排序

## 用户行为

- 围栏右上角提供排序按钮，使用 `resources/fence-sort.svg`（Lucide `list-sort-descending`）。按钮为 `24 × 24`，图标为 `16 × 16`，颜色继承同组图标的 `currentColor`。
- 下拉菜单提供“按名称排序”和“无排序”。首次选择名称排序为升序，再次选择切换为降序，继续选择交替切换；菜单显示当前方向和选中项。
- 默认无排序，图标透明度为 `0.48`；启用排序时为 `1`。切回无排序保留当前排列，不恢复之前的手动顺序。
- 名称排序沿用 Shell 项目列表的忽略大小写规则；同名保持稳定顺序，没有 Shell 名称记录时使用稳定引用作为后备名称。
- 无排序围栏保留手动插入标记与指定位置插入。启用排序时隐藏手动插入标记，在释放后的布局事务中按名称排列，释放前不重排成员。
- 排序适用于平铺和列表布局、单项和组拖入。排序状态随围栏保存，参与布局撤销、重做及备份恢复；Shell 重命名刷新后重新排序。

## 实现归属

- `src/features/fences/FenceWorkspace.tsx` 和同名 CSS 负责标题栏入口、下拉菜单、主题状态及焦点恢复；右键菜单复用同一排序入口。
- `src/features/workspace/interaction/useWorkspaceDrag.ts` 控制手动插入预览。排序围栏的提交不指定手动后继成员。
- `src/features/workspace/surface/useDesktopHostSurface.ts` 在菜单挂载、移除及定位变化时同步宿主命中图。
- 前后端工作区契约使用 `set-fence-sort` 命令及 `none`、`name-ascending`、`name-descending` 状态。
- `src-tauri/src/commands/workspace.rs` 将 Shell 显示名称传入工作区；`src-tauri/src/workspace/mod.rs` 在权威布局事务、Shell 协调及恢复路径统一排序，React 不自行改变成员顺序。
- 默认排序字段在 Rust 序列化时省略，旧数据反序列化为无排序，保持旧备份的规范化校验值兼容；前后端均拒绝非法排序状态。
- 冻结原型只提供排序占位入口，本功能的名称排序实现位于正式工作区领域，不修改冻结原型。
