# 设置界面规范

## 1. 范围与依据

本文记录设置窗口的页面、设置行与控件。以实际渲染的 TSX、对应 CSS 及全局样式为准；只在样式表中定义、但未被页面使用的类不算当前界面。尺寸为 CSS 像素；字段中标明的 DIP 或 px 是设置值的单位，不是控件尺寸。桌面格子、围栏、菜单的通用规则见[视觉规范](视觉规范.md)，主题覆盖范围见[主题变量契约](主题变量契约.md)。设置页用 `--color-*` 调色板，不用桌面 `--fence-*` 令牌。

## 2. 页面骨架与导航

- 根 `.settings` 高 `100vh`、`overflow: hidden`，两列 `224px minmax(0, 1fr)`，两行 `38px minmax(0, 1fr)`。使用 `--color-background`、`--color-text`、`--interface-font-size`。右列上方为 `38px` 自绘标题栏，窗口阴影由系统负责；窗口按钮各宽 `46px`。
- 侧栏跨两行，`padding: 16px 4px`、纵向 `gap: 8px`；先放同一行的 `20 × 20px` 应用图标与 `18px/600` 名称，再放 `44 × 38px` 收展按钮及分类导航。侧栏纵向可滚动，横向裁切。导航列表 `gap: 4px; padding: 1px`；导航按钮最小高 `42px`，内距 `8px 15px`，图文间距 `16px`，圆角 `4px`。图标盒 `20 × 20px`，导航 SVG 为 `18px`。悬停以 `--color-text` 混入透明底 `5%`；当前项为 `8%`，左侧强调条宽 `3px`、上下各留 `13px`，用 `--color-focus`。
- 展开时品牌及导航标签最大宽 `140px`；收起为 `64px` 图标侧栏，标签宽度、透明度、可见性与图文间距同步改变。分类按钮保留 `aria-label`，当前项用 `aria-current="page"`。切换分类时，启用动效才做内容区视图过渡（淡入淡出并上下位移 `4px`），不做整窗过渡；时长取 `--interface-transition-duration`。
- 右列内容区 `.settings__content` 自己滚动，`min-width: 0; min-height: 0; overflow: auto; padding: 24px`。共享 `.settings__rows` 左对齐、上限 `900px`，网格间隔 `4px`，`padding: 1px`；功能格子、浮岛、网格和插件也各自限制正文宽度为 `900px`，不是固定行宽。插件一级页的标题、按钮和提示走外壳网格，不受其正文上限约束。
- 窗口宽度 `≤600px` 时强制 `64px` 图标侧栏，内容内距改为 `20px 12px`；共享 `.settings__row` 可换行，间距 `12px`、内距 `14px 12px`，但目录行保持不换行。该断点下 `.settings__select` 左距 `32px`、宽 `calc(100% - 32px)`，不适用于所有页面自有的选择框。共享错误块可换行。外观行、网格字段本身允许换行；功能格子、插件、浮岛列表的自有行不套用 `.settings__row` 的断点规则。

## 3. 一级页、二级页与页头

### 3.1 一级页

外壳以导航分类名渲染一次 `h1`，`26px/600`、行高 `1.3`，通常下距 `22px`。功能格子一级页下距为 `16px`。插件一级页标题本身无外边距：第一行是左侧 `h1` 与右侧「＋ 添加插件」拆分按钮；第二行是来源安全提示；第三行是目录与列表正文；网格行距 `22px`。提示有 `1px --color-border` 上分隔线、上内距 `12px`，`16px` 信息图标和 `12px/18px` 次要文字间隔 `8px`，不计入按钮行高度。

| 分类 | 页面内容与入口 |
| --- | --- |
| 常规 | 配置目录、开机启动与双击相关设置；目录用独立命令，布尔项用开关行。 |
| 外观 | 「外观主题包」下拉与信息提示；分「桌面网格主题」「界面与菜单主题」两组，每组依次为「‹作用域›：深浅模式」「‹作用域›：使用 Windows 主题色」「‹作用域›：强调色」，作用域前缀为「桌面网格」「界面菜单」，分组 `h2` 滚动时吸顶；其后「通用」分组列圆角、字体、字体大小；末尾「桌面网格」「围栏内网格」整行进入各自表单。主题包生效时在首行下方给 `role="status"` 常驻说明并附「恢复我原来的外观」，通用三行标签后标「由主题设置」。 |
| 功能格子 | 本地时间、音乐控制、收集箱、文件夹映射、天气；调试构建另有 Debug 测试。每项都有独立开关和进入详情的行命中层。 |
| 浮岛 | 显示浮岛、浮岛形态、显示位置、全屏时隐藏、浮岛圆角（展开卡）；其后为「卡片」列表。页面单列网格 `minmax(0, 1fr)`，直接子项间隔 `18px`。 |
| 插件 | 安装入口和任务进度、来源提示、插件目录、已安装列表；有失效实例时另列「失效插件」。 |
| 性能 | 四个带信息按钮的开关：全屏或最大化时暂停、其他应用获焦时暂停、跟随系统减少动态效果、界面动画。跟随系统时禁用界面动画开关；系统减少动效生效时另显示状态文字。 |
| 诊断与维护 | 桌面工作区状态、显示器数量与逐屏信息、应用日志「打开目录」；「刷新状态」独立左对齐、上距 `12px`。只读值用 `--color-muted` 右对齐、最大宽 `55%`，允许长值折行。 |
| 关于 | 无框产品信息：`64px` 应用图标，产品名 `20px/600`，版本和平台用 `dl`（`80px minmax(0, 1fr)` 双列、间隔 `12px`）。不是简介折叠组件。 |

### 3.2 二级页

功能格子、插件、浮岛卡片隐藏外壳 `h1` 的视觉显示，各自渲染 `h2`。页头为 `flex`、垂直居中、`gap: 12px; min-height: 38px; margin-bottom: 16px`。返回键 `38 × 38px`、圆角 `4px`；标题 `18px/600`、行高 `38px`、无外边距。身份列可收缩（`flex: 1; min-width: 0`）。右侧命令组用自动起始边距贴右、间隔 `8px`；插件和浮岛固定高 `38px`，功能格子由控件撑高。图标按钮 `32 × 32px`、无内距；开关仅显示 `40 × 22px` 轨道，仍保留 `38px` 最小高及无障碍名。`16px` 是页头本身的下外边距，不是所有页头到下一段正文的实际距离；浮岛卡片二级页把它归零，由网格间隔统一提供。

| 二级页 | 页头与下方内容 |
| --- | --- |
| 功能格子 | 「返回功能格子」、名称与状态置于页头，右侧先可选添加按钮、后开关。普通状态为「已启用 / 已停用」，天气可换为天气状态文字。天气的加号打开「添加天气来源」；可添加且不由开关自动补建的格子可有「添加格子到桌面」。本地时间、音乐控制、Debug 测试不显示格子加号；文件夹映射用自己的创建行；收集箱另有带说明的添加行。 |
| 插件 | 「返回插件」、插件名、右侧依次卸载、添加到桌面、启停。加号在不可创建、停用、创建中或额度全满时禁用；有多种格子类型时打开菜单。作者/标识与可选 `18 × 18px` 仓库按钮在页头之后单独一行，不塞进标题或命令组；标识 `12px/18px` 且单行省略。下一行才是简介，其后为插件设置内容。 |
| 浮岛卡片 | 「返回浮岛」、卡片名与「已启用 / 已停用」置于页头，右侧依次「从浮岛移除」文字命令与上岛开关。移除直接关闭该卡的上岛状态，不卸载插件、不弹确认，因此不用删除图标；卡片未上岛或不可操作时禁用移除。描述是页头后独立的网格子项，之后才是作者设置或空态；二级页网格间隔 `12px`，页头不再叠加下外边距，描述自身再留 `4px` 上外边距。 |
| 外观网格 | 例外：外壳 `.settings__heading` 保留 `26px` 的 `h1`，标题自身无外边距，整行下距 `22px`；左侧为 `38 × 38px`「返回外观」，没有状态或页头命令。 |

页头内功能格子与浮岛状态均为 `12px/18px`、`--color-muted`、无外边距；浮岛身份列为网格，标题与状态间隔 `2px`。插件作者/标识行不是启停状态行。页头加号与插件卸载图标为 `18px`（按钮仍 `32 × 32px`），浮岛移除是文字命令、不带图标；插件及浮岛返回图标为 `16px`。

## 4. 设置行与控件

### 4.1 普通行与进入详情行

- `.settings__row` 左文右控件，`display: flex; align-items: center; min-width: 0; min-height: 70px; gap: 20px; padding: 16px 20px`，边框 `1px solid var(--color-border)`、表面 `--color-surface`、圆角 `--surface-radius`。标题占余宽、`min-width: 0; overflow-wrap: anywhere`，字号 `calc(var(--interface-font-size) + 1px)`。外观、网格、功能格子及插件行的间距是 `12px`；外观、网格用容器 `gap: 4px`，功能与插件行用下外边距 `4px`。
- 无独立控件时可整行用原生按钮，如外观网格入口 `.settings__row--link`。有开关或图标命令时，功能格子、插件、浮岛用独立 `button[data-button="row-hit"]` 绝对定位 `inset: 0`；文案与箭头在上层但不截获指针，开关、卸载及排序各自接收点击。不把按钮嵌套进按钮，也不用文字按钮的伪元素扩大命中。
- 功能格子一级行右侧是标准开关与固定 `38px` 的系统字体箭头轨道。插件行从左至右为名称/副文案、卸载、开关、`16 × 16px` 箭头；插件名称 `14px`、副行 `12px` 且上距 `4px`。插件列表停用时名称与箭头弱化，行仍可打开详情。失效行仅有标识、次要说明和「移除」按钮，不设详情命中层。
- 浮岛卡片行最小高 `70px`，内距 `12px 16px`，间隔 `12px`；左侧粗体名称与 `12px` 副文案相隔 `3px`。右侧开关和 `32 × 32px` 上移/下移按钮间隔 `6px`，最末是 `20px` 的 `›`；不能移动时禁用相应按钮。列表间隔 `4px`，内距 `1px`。卡片分组标题 `12px/600`、无外边距；已安装插件分组标题 `12px/600`、下距 `8px`；插件「设置条目」标题上距 `16px`、下距 `8px`。

### 4.2 开关行（SettingsSwitch）

名称在左，开关整体贴右。标准开关组 `flex: 0 0 72px`、最小高 `38px`，开/关文字到轨道间隔 `12px`；插件一级行改用内容宽、间隔 `8px`。页头变体宽 `40px`、间隔 `0`、隐藏开/关文字。

- 轨道 `40 × 22px`、圆角 `11px`、内距 `4px`；关态 `--color-muted` 描边、`--color-surface` 背景。`12px` 圆形滑块距块起始、行内起始各 `4px`，用 `--color-muted`。
- 开态轨道填充与描边均为 `--color-focus`，滑块行内偏移改为 `22px`、用 `--color-surface`。焦点环画在轨道上，`2px solid var(--color-focus)`、外偏 `2px`。
- 禁用不用整体降低透明度作为共享开关样式：文字 `--color-muted`、默认指针；轨道 `--color-border` 描边与 `--color-subtle` 底，滑块 `--color-surface` 加 `1px --color-border` 细边。高对比度模式使用 `Canvas`、`ButtonText`、`Highlight`、`GrayText`。主题对共享胶囊的可撤销表现层不属于内置尺寸。
- 用原生 `input[type="checkbox"][role="switch"]` 维持键盘与受控状态；`aria-label` 是具体设置名而非「开」或「关」。轨道 `aria-hidden`，并不拦截指针。外部标签可通过 `id` / `htmlFor` 关联。

### 4.3 原生选择、文本、数值与颜色

- 原生下拉不套用任务菜单的定位规则。功能格子下拉最小高 `38px`、内距 `6px 10px`、圆角 `4px`、`--color-subtle` 底；本地时间选 12/24 小时制，音乐的采集设备、段数与帧率在频谱关闭时禁用。音乐控制还提供媒体来源、歌词、频谱开关。外观主题/模式下拉宽 `176px`、字体下拉宽 `210px`；最大宽 `100%`，与外观数字框共用 `38px` 最小高、`6px 10px` 内距及 `min(4px, var(--surface-radius))` 圆角。
- 数字输入用 `type="number"`。外观数字框宽 `80px`，圆角 `0 至 12`、字号 `12 至 18`，步长 `1`，单位 `px`；失焦提交合法值，Enter 触发失焦，非法值恢复已保存值。收集箱图片预览宽度输入宽 `88px`、最小高 `38px`、内距 `6px 12px`；范围 `48 至 156 DIP`、步长 `1`，同样在失焦或 Enter 时提交。浮岛圆角输入宽 `88px`、高 `38px`、横内距 `10px`、`4px` 圆角；范围 `0 至 16`、步长 `1`，`onChange` 处理范围内整数，不套用外观的失焦草稿规则。
- 桌面/围栏网格各有宽度 `64 至 160`、高度 `90 至 180`、横纵间距各 `0 至 48` 四个 DIP 字段，必填、步长 `1`。数字框宽 `80px`、最小高 `38px`、内距 `6px 10px`、圆角 `min(4px, var(--surface-radius))`；输入和单位间隔 `12px`。页尾「恢复默认」「应用」右对齐、间距 `8px`、上距 `12px`；编辑走草稿，应用校验后提交整组；恢复默认只把默认值填进草稿并在下方给 `role="status"` 提示「已填入默认值，点「应用」生效」，不直接写入。非法输入提示为 `role="alert"`。
- 外观色块 `24 × 24px`、圆角 `4px`，自定义原生颜色输入 `32 × 26px`；控件组可换行，间隔 `8px`、内距 `2px`。选中以 `aria-pressed` 和外偏 `2px` 的 `2px --color-text` 轮廓显示；使用 Windows 主题色时禁用对应组的色块和自定义颜色输入。
- 天气配置单行文本和遮蔽输入高 `38px`、内距 `6px 12px`、圆角 `4px`、`--color-subtle` 底及 `1px --color-border` 边。左标签列 `168px`，右侧输入组合占余宽且 `min-width: 0`。多行私钥草稿高 `78px`、内距 `8px 12px`、行高 `1.4`、不允许拖拽缩放，字段行顶对齐；显隐按钮 `28 × 28px` 配 `16px` 图标，只有草稿可见性改变，不回读已保存值。天气字段、外观主题、性能等行的 `SettingsInfo` 是独立信息按钮（`24 × 24px`、`16px` 图标），不等于详情简介折叠。

### 4.4 分段控件

浮岛形态「胶囊 / 刘海」、显示位置「上 / 下 / 左 / 右」，以及天气添加弹窗的供应商切换使用同一组几何：轨道 `inline-flex`、内距与间隔各 `2px`、圆角 `6px`、`--color-background`；选项高 `34px`，横内距 `16px`、圆角 `4px`、无边框，轨道总高 `38px`。选中项 `--color-surface`、`--color-text`、`0 1px 2px rgb(0 0 0 / 12%)` 阴影；未选项透明、`--color-muted`，可用且未选中时悬停用 `--color-subtle` 与 `--color-text`。组用带名称的 `role="tablist"`，按钮用 `role="tab"` 和 `aria-selected`；源码未实现左右方向键切段，不把该行为写成现有能力。选择浮岛显示位置同时将偏移归零；编辑天气来源时不显示供应商切换。

### 4.5 目录、按钮与带说明行

- 常规配置目录和插件目录共用 `.settings__directory`：左侧标题及路径可收缩；路径可选中，单行省略，完整路径放在 `title`；右侧依次复制、选择、恢复默认、保存。图标按钮宽 `38px`、最小高 `38px`、内距 `6px`，`18px` SVG 蒙版跟随 `currentColor`；按钮不收缩。未改目录时保存禁用；插件目录标示下次启动生效，优先显示草稿，否则显示本次生效路径（未取得时回退到配置值）。剪贴板不可用或复制失败时提示手动复制。
- `.settings__button` 最小高 `38px`、最大宽 `100%`、内距 `6px 12px`、圆角 `4px`，使用 `--color-border` 描边、`--color-subtle` 底、`--color-text` 文字；内联布局间隔 `8px`。可用时悬停改 `--color-background`。目录图标、二级页命令与行内小图标分别按对应尺寸，不强行统一到 `38px`。
- `data-button` 用途：`row-hit` 标记整行导航/条目命中；`icon` 标记返回、关闭、卸载、排序等图标命令；`switch` 标在开关 input；`ghost` 用于描述折叠、添加等轻量命令；`primary` 用于主命令或分段选项；`secondary` 用于常规命令；`danger` 用于破坏性确认等。该属性不决定命中尺寸，也不替代原生 `disabled`；普通菜单命令不套 `primary` 或 `row-hit`。全局样式补充危险与禁用表现，其余视觉由实际组件持有。
- 功能格子的收集箱「添加」和文件夹映射创建为左标题、副说明、右命令；副说明 `12px`、上距 `4px`、`--color-muted`。收集箱数据位置的提示是设置行之前的独立段落，`12px/18px`、下距 `12px`。文件夹映射有数据时显示两列「名称 / 路径」表格，分隔线高 `1px`、上下距 `8px`；表头及数据行最小高 `44px`、横内距 `16px`，路径单行省略，支持整行选中与右键命令。

### 4.6 作者设置条目

- 插件二级页的条目外框 `1px --color-border`、圆角 `4px`、`--color-surface`，下距 `8px`。按钮式条目头高 `52px`、内距 `0 16px 0 20px`、标题 `14px`，末端 `16px` 箭头展开时转 `90°`。条目各自展开，用 `aria-expanded`；切换详情对象或返回列表时清空展开状态。停用时条目头禁用、弱化，作者内容不渲染。展开体内距 `12px 16px 16px`，允许选择文字。插件作者提供 `render` 时交给作者渲染，否则宿主给兜底文案。
- 浮岛二级页条目不是插件页的折叠行：直接显示 `h3` 和作者容器；条目间隔 `4px`、内距 `16px 20px`、圆角 `--surface-radius`，标题 `12px`、`--color-muted`、下距 `12px`。卡片上岛开关不锁定该作者区域。

### 4.7 天气来源与城市行

天气是「功能格子」二级页，不在侧栏单独建页。内容继承功能格子的宽度，不重复页头；添加来源入口在功能格子页头，列表底部不另放「添加 API」。

- 来源列表间隔 `4px`；每项自然高度，内距 `16px`、`1px --color-border`、`--surface-radius`、`--color-surface`。主行间隔 `12px`，左列为名称和 `12px` 单行省略的地址、间隔 `2px`；右侧依次为 `24px` 高的模式徽标、`8px` 状态圆点及 `12px` 状态文字、展开城市按钮、详情箭头。徽标横内距 `8px`、圆角 `4px`；可用/不可用/未确认分别用 `--color-active`、`--color-error`、`--color-muted`。主行用独立 `button[data-button="row-hit"]` 铺满整行作命中层，点击、Enter / Space 都由该按钮触发编辑；行本身不是按钮角色，也不在行上挂键盘处理，以免抢走展开按键的按键事件。末端 `16px` 箭头只作指示。
- 城市展开按钮 `24 × 24px`、图标 `16px`，展开时转 `90°`（`120ms ease-out`）。鼠标点击阻止冒泡，不触发编辑；按钮标有 `aria-expanded` 和含来源名的无障碍名。城市区在来源边框内、距主行 `12px`，与编辑弹窗复用城市列表。城市行最小高 `44px`、次要行政区 `12px`；删除为 `24 × 24px` 图标按钮。列表为空仍保留末行「添加城市或地区」。来源和城市右键菜单复用公共两级菜单。

## 5. 文字、状态与键盘

### 5.1 描述与长文本

- 浮岛一级卡片行的副文案是卡片描述，无描述时用 ID；左列 `min-width: 0`，副行用 `overflow: hidden; white-space: nowrap; text-overflow: ellipsis`，不挤宽行或右侧命令，不提供「显示」按钮。浮岛一级行末端的箭头与插件列表行同一 `16 × 16px` 图标和盒尺寸。插件一级行的副文案是条目数量、停用等摘要，不是插件简介；功能格子一级行只有名称、开关和箭头。不能把浮岛描述的单行省略规则套给所有一级行的副文案。
- 插件和浮岛卡片详情共享 `SettingsAbout`：无有效文字不渲染；容器 `min-width: 0; max-width: 100%`，上距 `4px`，文字 `12px/18px`、`--color-muted`，与按钮间隔 `8px`。默认一行省略；收起态测得 `scrollWidth > clientWidth + 1` 才显示「显示」，展开后恢复正常换行并保留「收起」。文字可收缩，按钮 `flex: none`、无边框和内距、透明底、`--color-text`。展开用 `overflow-wrap: anywhere` 允许长 URL/标识断行并完整显示；收起态在文本、开合状态与容器宽度变化时重新测量（`ResizeObserver`），测量时临时隐藏按钮，按未扣除按钮占位的整行宽判断是否需要「显示」。
- 设置窗口默认禁止选中文字；输入、文本域、可编辑区、目录路径、插件条目展开体和二级页说明正文明确允许选择。正文描述、路径提示、插件来源安全提示分别归各自位置，不能用额外设置行包住简介或把提示计入按钮高度。

### 5.2 空态、读取、失败

- 插件与浮岛空态用实线 `1px --color-border`、`--color-surface`、`--surface-radius`、内距 `16px 20px`；插件空态字号 `12px`，第二句 `small` 上距 `4px`。浮岛读取卡片时用同一块表面加 `role="status"`；读完无卡与详情无设置条目是两种空态。天气无来源用居中虚线框、内距 `24px 16px`，不复用插件空态。
- 外壳读取用 `.settings__status`、`--color-muted`；在插件页该外壳状态视觉隐藏。插件详情仅脚本实际待加载时显示「正在加载插件设置…」；已注册条目直接显示。脚本失败用 `role="alert"`，`12px 16px` 内距、`4px` 圆角、`--color-error` 描边与文字、`--color-error-surface` 底，并提供「重新加载」；无脚本主题不进入该加载/失败分支。
- 共享 `.settings__error` 为可换行的错误块：内距 `12px`、下距 `12px`、间隔 `12px`、圆角 `4px`，错误色文字及边框、错误表面填充。设置命令失败时在内容区标题下方就地渲染该错误块，右侧给「重试」按钮重跑同一意图（执行中禁用），成功即清除；外层消息模块只作补充，不把失败的唯一反馈留在窗口外。天气列表及弹窗另有 `12px` 状态行，失败用 `--color-error`，通过用 `--color-active`；弹窗动作反馈留在命令区左侧，不用这个页面错误块。

### 5.3 悬停、禁用与无障碍

- 共享按钮、输入、下拉键盘焦点为 `2px solid var(--color-focus)`、外偏 `2px`。例外：窗口按钮内偏 `3px`、插件条目头内偏 `2px`；外观控件轮廓用 `--color-text`；天气来源主行以外框变 `--color-focus` 表达焦点，展开城市按钮用表面与文字变化；开关焦点显示在视觉轨道上。内置不带主题冷光，主题特效须排除禁用控件。
- 普通不可点击设置行不加整行悬停。外观入口及功能格子、插件命中行用 `--color-subtle`；浮岛卡片行在支持悬停且指针精确时用同色。插件一级卸载按钮命中区 `32 × 32px`、图标 `16px`，常态 `--color-muted`，悬停/焦点 `--color-error`，焦点环仍用 `--color-focus`。插件二级卸载图标常态使用错误色；浮岛移除是文字命令，不用错误色。
- 控件不可操作用原生 `disabled` 或所属 `fieldset` 禁用，不用颜色模拟禁用；共享按钮与开关用次要色，外观与网格另有局部透明度规则（分别 `0.5`、`0.6`）。插件停用、条目锁定、命令忙碌是不同状态，不将整页统一禁用。
- 可见标签通过原生 `label` 包裹或 `htmlFor` 关联输入；纯图标与透明命中按钮提供动作及对象名，例如「返回浮岛」「打开〈卡片名〉卡片设置」「〈卡片名〉上移」「卸载〈插件名〉」。装饰 SVG/箭头不参与可访问名称。原生按钮保留 Enter / Space，开关保留 Space；折叠按钮用实际可见文字作名称，插件条目和天气城市展开按钮另有 `aria-expanded`，简介按钮没有该属性。

## 6. 模态与浮层

- 插件确认框用原生 `showModal()`，宽 `468px`，最大宽高分别为视口减 `32px`，圆角 `6px`、`1px --color-border`、无投影、遮罩 `20%` 黑。卸载高 `304px`，失效移除高 `194px`；添加弹窗自然高度、最小高 `194px`。标题 `18px/600`、正文 `12px`；头、正文、尾内距 `16px 24px`，仅正文滚动。命令区间距 `8px`、按钮最小高 `38px`，取消在前、主确认在末；卸载默认焦点为「卸载」，不是「卸载并清理配置」。确认框内 Tab / Shift+Tab 循环，Esc 取消，执行中禁用命令并拦截相应键盘操作；关闭后触发元素仍连接时恢复焦点。
- 天气配置框宽 `620px`，确认框 `468px`；最大宽为视口减 `32px`、最大高为视口减 `64px`。圆角 `--surface-radius`、遮罩 `20%` 黑、标题 `18px`、关闭按钮 `28 × 28px`。头、滚动正文及固定命令区内距 `16px 24px`；命令高 `38px`，主命令用 `--color-action` 与 `--color-action-text`。配置内打开城市选择时仍使用设置窗口的模态层级。天气来源和城市删除用确认框，不将此规则外推到浮岛移除。
- 就地二次确认用于不值得开模态的不可恢复命令，不新开对话框：共享 token 的「清除」先在原地换成「确认清除」与前一个「取消」，二次点击才执行；文件夹映射的「移除映射」在同一右键菜单内换成「确认移除」（危险色）与前一项「取消」，不关闭菜单。可逆命令（浮岛移除）不加二次确认，改用文字命令说明动作。
- 插件拆分按钮高 `38px`，主段随文案、横内距 `12px`，右段宽 `32px`、`16px` 箭头。任务面板右边缘对齐按钮组、距按钮 `4px`，最小宽为按钮组宽，最大高 `min(320px, 40vh)`，内部滚动；菜单下缘超出内容区且上方空间大于下方时才向上翻转。任务块内距 `8px 16px 12px`，头最小高 `38px`；取消按钮高 `38px`、圆角 `4px`，有悬停、按下、禁用状态。进度条高 `4px`、上距 `8px`，用 `--color-accent` 表示进度；任务行内距 `6px 16px`，组间 `1px --color-border` 分隔。

- 插件行右键菜单和多格子类型菜单复用 [DesktopTileMenu](../../src/features/tiles/DesktopTileMenu.css)。容器最小宽 `164px`、内距 `4px`、圆角 `--surface-radius`；命令最小高 `28px`、圆角 `2px`；分隔线高 `1px`、上下距各 `4px`。菜单配色由 `--menu-*` 令牌提供，危险命令用错误色。已安装插件打开右键菜单时，该行保留 `--color-subtle` 选中底；浮岛卡片和天气来源的右键入口也复用公共菜单，天气来源一级菜单另设 `232px` 宽。
