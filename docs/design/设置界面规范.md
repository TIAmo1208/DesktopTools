## 3. 设置行类型清单

通用约束（下列每种行都适用）：

- 一行内部遵循「文本在左、控件贴右」：文本列 `flex: 1`、`min-width: 0`，控件组整体右对齐。
- 行：`display: flex; align-items: center; min-height: 70px; padding: 16px 20px; border: 1px solid var(--color-border); border-radius: var(--surface-radius); background: var(--color-surface)`。
- 相邻行间距由容器 `gap: 4px` 承担，不用每行外边距；插件行额外用 `margin-bottom: 4px`。
- 行内文本不可选中（`user-select: none`）；输入框、文本区域、路径与作者内容区保留文本选择。
- 字号：行标题 `calc(var(--interface-font-size) + 1px)`（内置基准下即 `14px`）；次要说明 `12px`；正文 `13px`。
- 键盘焦点：`button`/`input`/`select` 的 `:focus-visible` 统一 `outline: 2px solid var(--color-focus); outline-offset: 2px`。
- 悬停：行或命令一律用 `--color-subtle`（命令按钮悬停改用 `--color-background`）。

### 3.1 开关行

- 结构：左侧名称 + 可选副标题；右侧开关（`SettingsSwitch`）。
- 开关整体：`flex: 0 0 72px`、`gap: 12px`、`min-height: 38px`、`justify-content: flex-end`、`user-select: none`；文字与轨道作为一个整体贴右。
- 轨道：`40 × 22`、`padding: 4px`、`border: 1px solid var(--color-muted)`、`border-radius: 11px`、`background: var(--color-surface)`。
- 滑块：`12 × 12` 圆点，`border-radius: 50%`，`background: var(--color-muted)`，位于 `inset-block-start: 4px; inset-inline-start: 4px`。
- 已选：轨道 `border-color` 与 `background` 均为 `var(--color-focus)`；滑块靠右 `inset-inline-start: 22px`、`background: var(--color-surface)`。
- 键盘焦点：`outline: 2px solid var(--color-focus); outline-offset: 2px`，不改变几何。
- 禁用：整组文字 `--color-muted`、`cursor: default`；轨道 `border-color: var(--color-border)`、`background: var(--color-subtle)`；滑块 `background: var(--color-surface)` 加 `box-shadow: 0 0 0 1px var(--color-border)` 细边，保证轨道与滑块仍可分辨；不整体降透明度。
- 高对比度：`forced-colors: active` 下保留系统色。
- 二级页头部变体：`flex-basis: 40px`、`gap: 0`、隐藏开/关文字。
- 主题可以覆盖该控件几何，撤下后恢复共享胶囊。

### 3.2 文本输入行

- 结构：左侧标签，右侧输入框。
- 控件：高 `38px`、圆角 `4px`、内边距 `6px 12px`、`border: 1px solid var(--color-border)`、`background: var(--color-subtle)`。
- 状态：默认、悬停、键盘焦点、禁用、错误（错误见 3.8 与第 5 节）。
- 焦点：内置焦点统一使用 `outline: 2px solid var(--color-focus); outline-offset: 2px`。冷光一类的聚焦特效由主题插件提供（例如「主题-夜之城 · 控件库」的表现层），**不属于内置基线**；主题做这类特效的合法入口与约束见[主题变量契约](主题变量契约.md)（按钮悬停冷光等特效必须排除 `:disabled`）。
- 禁用：`color: var(--color-muted)`、`cursor: default`，不整体半透明。

### 3.3 下拉选择行

- 与文本输入行共用 `.settings__select` 的外观：高 `38px`、圆角 `4px`、内边距 `6px 12px`、`--color-border` 边、`--color-subtle` 表面。
- 主题选择下拉固定宽 `176px`。
- 禁用同 3.2。展开面板见第 6 节。

### 3.4 多行输入行

- 结构：标签在上、多行文本框在下，占满行内可用宽度。
- 圆角 `4px`，边框与表面同 3.2；保留文本选择与编辑。
- 状态与焦点规则同 3.2。

### 3.5 目录行

- 结构：`.settings__directory`，`flex-wrap: nowrap`；左侧标题区（`min-width: 0; overflow: hidden`）内为标签与当前路径，右侧图标命令组。
- 路径：`.settings__directory-path` 单行省略（`text-overflow: ellipsis`）、`--color-muted`、`user-select: text`，悬停给全文。
- 图标命令：`.settings__icon-button` 宽 `38px`、内边距 `6px`、`flex-shrink: 0`；图标 `18 × 18`，用 SVG 蒙版跟随 `currentColor`。
- 图标资源：`resources/settings-folder.svg`（选择目录）、`resources/settings-reset.svg`（恢复默认）、`resources/settings-copy.svg`（复制路径）。
- 行为：保存按钮在路径未改时禁用；重置恢复默认目录；插件页显示本次启动实际生效的目录。复制走 `navigator.clipboard`，不可用时提示手动复制。
- 插件目录与配置目录共用同一套行结构与样式类。

### 3.6 入口行（整行可点击）

- 结构：`.settings__row--link`，整行是一个按钮（`width: 100%`、`text-align: left`、`cursor: pointer`）；左侧标题、右侧进入箭头。
- 箭头：`.plugin-settings__chevron` `16 × 16`、`color: var(--color-muted)`；展开态 `rotate(90deg)`。
- 悬停：整行 `background: var(--color-subtle)`。
- 键盘焦点：整行 `outline: 2px solid var(--color-focus); outline-offset: 2px`（沿整行，不是沿文字框）。
- 覆盖式命中层：`.plugin-settings__row--link > .plugin-settings__hit` 使用 `position: absolute; inset: 0`，其余内容 `position: relative; z-index: 1` 压在命中层之上，非交互内容加 `pointer-events: none`；不得用「文字按钮 + `::after{inset:0}` 拉伸」。
- 停用行：标题与箭头改用 `--color-muted` / `--color-border`，整行不可点击。

### 3.7 插件条目行（条目头 + 展开区）

- 条目外框：`.plugin-settings__entry`，`margin-bottom: 8px`、`border: 1px solid var(--color-border)`、`border-radius: 4px`、`background: var(--color-surface)`。
- 条目头：`.plugin-settings__entry-head`，`height: 52px`、`padding: 0 16px 0 20px`、`font-size: 14px`、整行按钮、`justify-content: space-between`。
- 条目头键盘焦点：`outline: 2px solid var(--color-focus); outline-offset: -2px`（内偏，避免出框）。
- 锁定态（插件停用）：`.plugin-settings__entry--locked .plugin-settings__entry-head` 文字 `--color-muted`、`cursor: default`，不可展开，作者内容不渲染。
- 展开区：`.plugin-settings__entry-body`，`padding: 12px 16px 16px`，`user-select: text`（作者内容可选中）。
- 多条条目各自展开；离开再回来收起；返回一级页保留滚动位置与上一行焦点。
- 作者渲染条目由插件的 `render` 画进宿主容器，宿主只保证容器与各状态；没有 `render` 时显示宿主兜底句。

### 3.8 说明 / 警示行

- 普通说明：`12px` 或 `13px`，`--color-muted`。
- 错误块：`.settings__error`，`display: flex`、`align-items: center`、`justify-content: space-between`、`gap: 12px`、`margin: 0 0 12px`、`padding: 12px`、`border: 1px solid var(--color-error)`、`border-radius: 4px`、`color: var(--color-error)`、`background: var(--color-error-surface)`、`overflow-wrap: anywhere`。
- 加载提示：`.settings__status`，`--color-muted`。
- 警示说明不参与按钮行高度与命中区。安装页的警示说明见第 5 节。

### 3.9 分组标题（节标签）

- 一级列表节标签：`h2.plugin-settings__label`，`margin: 0 0 8px`、`color: var(--color-muted)`、`font-size: 12px`、`font-weight: 600`。
- 条目节标题：`h3`，`margin: 16px 0 8px`、`--color-muted`、`12px`、`600`。
- 分组标题不占设置行高度，不参与行间距计算。

### 3.10 按钮命令行

- 主/次/幽灵按钮共用 `.settings__button`：`min-height: 38px`、`max-width: 100%`、`padding: 6px 12px`、`border: 1px solid var(--color-border)`、`border-radius: 4px`、`color: var(--color-text)`、`background: var(--color-subtle)`、`display: inline-flex; gap: 8px`。
- 悬停：`background: var(--color-background)`。
- 禁用：`:disabled` → `color: var(--color-muted); cursor: default`，不整体半透明。
- 键盘焦点：`outline: 2px solid var(--color-focus); outline-offset: 2px`。
- 顺序：非破坏性命令在前，主命令在后；确认弹窗内「取消」在前。
- 图标命令：`38 × 38`（目录行）或 `32 × 32`（二级页头部）。
- 插件页「创建到桌面」按钮：`width: 100px; height: 38px; margin-left: auto; margin-right: 20px`，外观同 `.settings__button`。

### 3.11 危险行

- 用于卸载、清理配置、失效插件移除、删除天气来源或城市、移除格子等破坏性命令。
- 行内卸载按钮：`32 × 32` 命中区、图标 `16`；常态继承行文字色，`:hover` 与 `:focus-visible` 改为 `var(--color-error)`；焦点环 `outline: 2px solid var(--color-focus); outline-offset: 2px`（焦点环仍用强调色，不用错误色）。
- 危险命令按钮标注 `data-button="danger"`；确认弹窗内危险按钮含错误色描边与错误表面，默认焦点在更彻底的那一个。
- 危险行本身不做整行点击；破坏性动作必须先经过确认弹窗。

## 4. 组件与控件

### 4.1 SettingsSwitch

见 3.1。要点：`input[role="switch"]` 原生语义 + 视觉轨道，`40 × 22` 胶囊、`12px` 圆点滑块、已选 `--color-focus`、禁用轨道 `--color-subtle` 配滑块 `--color-surface` 细边、高对比度走系统色、主题可覆盖几何。

### 4.2 按钮变体（`data-button`）

| 取值 | 用在 |
| --- | --- |
| `row-hit` | 整行可点击的命中层：设置功能入口、插件与失效插件列表项、设置导航项、插件设置条目头、城市搜索结果项 |
| `primary` | 对话框非破坏性主命令、状态页操作、天气来源与城市弹窗的主按键、分段控件 |
| `secondary` | 常规命令按钮、刷新、插件仓库入口 |
| `danger` | 危险命令：卸载、清理配置、失效插件移除、删除天气来源或城市及移除格子的确认 |
| `icon` | 图标命令：返回、关闭、卸载、色块、围栏排序、面包屑更多、展开箭头、格子标题按钮 |
| `ghost` | 文字命令：添加城市或地区、取消任务、插件简介展开 |
| `switch` | 开关控件本体（`role="switch"` 保留在同一个元素上） |

- 未标注即普通按钮；自绘菜单命令项不标 `primary` 或 `row-hit`，不参与按钮视觉。
- `primary`、`secondary`、`ghost`、`icon` 的外观由组件 CSS 持有；`danger` 与原生禁用状态由 `src/styles/global.css` 补足；主题只覆盖令牌与特效。
- `disabled` 不是 `data-button` 取值，用原生 `:disabled`。

见 3.2、3.3；展开面板见 6.3。

### 4.4 进度条

- 用于安装任务块的进度：高 `4`。

## 5. 状态与反馈

| 状态 | 当前实现 |
| --- | --- |
| 空态 | 实线 `1px var(--color-border)`、`--color-surface` 填充、`16 20` 内边距的块；第二句说明用 `small`，上间距 `4px`；不用虚线 |
| 加载 | 已加载过的外部内容（如插件设置条目）再次进入必须立即渲染；加载态只用于真实进行中的加载；初次加载提示用 `.settings__status`（`--color-muted`） |
| 错误 | `.settings__error` 块（见 3.8）留在页面上，或经消息显示模块提示；保存冲突保留草稿 |
| 未提交输入 | 其他窗口改动时：无未提交输入则静默更新、不弹消息、不抢焦点；有未提交输入则保留草稿并在展开区出现提示条与「载入最新值」；保存时值已被修改则本次保存失败、草稿保留 |
| 禁用 | 见各行的禁用规则；停用插件的条目头灰显且不可展开 |
| 悬停与焦点 | 行与命令悬停 `--color-subtle`（命令按钮悬停 `--color-background`）；所有 `:focus-visible` 统一 `2px var(--color-focus)` 外偏 `2px` |
| 动效 | 过渡时长取 `var(--interface-transition-duration, 0ms)`，不写死 |
| 消息 | 设置界面反馈统一通过消息显示模块呈现，不抢占输入焦点，动画跟随 `interfaceAnimations` 与系统减少动态效果设置 |
| 不可选中 | 设置页标题、标签、说明文字不可选中；输入框、文本区域、路径与作者内容可编辑可选择；模态弹窗内文案同样不可选中 |

## 6. 弹窗与浮层

### 6.1 确认弹窗

- 尺寸：宽 `468`、圆角 `var(--surface-radius)`、`1px` 边框、无投影、内边距 `24`；配置表单类弹窗可加宽到 `620`。
- 排版：标题 `18`、正文 `12`；动作区按钮顺序「取消在前、主命令最后」；窄窗时命令区换行。
- 危险确认（卸载）：默认焦点在「卸载」；两个危险按钮同强度。
- 失效移除确认：两键，默认焦点在「移除」，Esc 取消；执行中两键禁用。
- 键盘与焦点：打开即把焦点放到危险命令，Enter 与 Space 都执行；Tab / Shift+Tab 在弹窗内循环，背景内容 inert；Esc 取消，点击遮罩不关闭；关闭后焦点回到触发元素；执行中命令禁用且弹窗不关闭，成功关闭并消息反馈，失败保留弹窗并消息反馈。

### 6.2 安装任务菜单

- 宽随按钮组、最小等于按钮组（`136`）；右缘对齐按钮组、右内边距 `20`。
- 最大高 `min(320px, 40vh)`，超出内部滚动；下方空间不足时整体向上翻转。
- 进行中块内边距 `8 / 16 / 12`、头部高 `38`、取消按钮 `38` 高圆角 `4`、进度条高 `4`；任务条目高 `44`、块间 `1px var(--color-border)`。
- 每条任务独立成块；取消按钮具备悬停、按下与禁用三态。

### 6.3 下拉面板
