# CSS 约定

样式写在哪、归谁维护按本页执行。视觉数值与配色基线见 `docs/design/视觉规范.md`；可覆盖的主题令牌见 `docs/design/主题变量契约.md`。

## 样式职责

- 单个 CSS 文件遵循最小包含原则，只负责同名 TSX 组件直接拥有的控件、状态与内部布局样式。
- 可复用控件的视觉样式、状态变体与尺寸规则集中在控件自身的同名 CSS 文件。
- 调用方需要调整控件外观时，通过组件 Props、BEM 修饰类或公开样式变体表达；变体实现在被调用组件的 CSS 中。
- 调用方 CSS 负责页面布局、模块容器、直接子项的编排与放置。
- 顶层 CSS 负责应用主题、全局变量、窗口根容器与跨页面基础样式。
- 浮岛页面是独立来源的独立窗口，样式只写在 `src/features/island/island.css`；不导入 `tiles/` 的基类与格子 CSS，格子那套标题轨道、折叠与最小尺寸规则在浮岛上都不成立。
- 修改样式时，检查浅色模式样式表与主题变量是否需要同步调整。
- 编写或修改 CSS 前，先确认目标样式属于控件、组件、页面布局、共享主题或窗口根层；样式文件与选择器层级保持现有组件层级。
- 承载带边框子元素的布局容器设置不小于子元素边框宽度的 `padding`，为边框预留完整显示空间。
- 每个 CSS 选择器样式块前添加简短注释，说明对应控件、容器或状态；不同功能的样式块之间保留空行。

## 组件层级与复用

- 样式归属以组件拥有的 DOM、交互和视觉状态为边界。父组件 CSS 定义页面分区、模块容器及直接子项的编排与放置；子组件 CSS 负责自身表面、尺寸、内部布局、状态和主题覆盖。
- 多个同级组件共享 DOM 骨架、内部布局和视觉规则时，在共同目录提取 `<名称>Base.tsx` 与 `<名称>Base.css`。
- 基类负责共用 DOM、基础 BEM 元素、默认表面、尺寸、布局与主题覆盖；具体组件负责数据、文本、子内容和真实存在的视觉差异。
- 相同 CSS 规则保留一个权威来源并放入复用基类样式表。具体组件 CSS 只保留覆盖值和独有状态；文件中没有独有规则时，移除对应 CSS 文件及导入。
