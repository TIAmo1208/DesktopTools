# 收集项编辑窗口

## 状态与边界

编辑窗口 UX 与 UI 视觉稿均已确认，产品已按稿实现，浏览器预览已验证，Windows 原生窗口仍待实机验收。窗口沿用[按需编辑窗口决策](../adr/0022-收集项编辑使用按需窗口.md)与[Markdown 文件事实](../adr/0021-收集项以Markdown文件为事实.md)，属于普通应用界面，使用界面主题。

## 已确认的交互布局

- 保留原生窗口标题栏。文件名、重命名入口、保存状态与保存命令位于紧凑信息行；重命名入口紧邻文件名，保存区域不随文件名长度被挤掉。
- 正文优先使用窗口剩余空间并独立纵向滚动；格式工具栏固定，保留现有格式能力。窄窗文件名省略，工具栏超出可用宽度时独立横向滚动，不引入侧栏、模式切换或分屏预览。
- 重命名按需进入，扩展名固定展示；确认后退出输入，取消保留原文件名，失败保留输入并就地显示原因。重命名不保存正文草稿。
- 保存及重命名提交期间暂停编辑，禁止重复提交与关闭。保存失败保留草稿并恢复编辑，通过原保存命令重试。
- 无正文更改直接关闭；有更改按现有退出自动保存偏好执行。未开启自动保存时提供保存、不保存、取消，取消默认聚焦。保存成功后才关闭，保存失败保留当前窗口及草稿。
- 读取中与读取失败均禁止编辑、保存和改名；读取失败展示原因并允许关闭，避免将失败误判为空文件。

上述布局减少常驻命名控件占用，同时保持编辑与文件操作边界。窄窗工具可达性、字体偏好变化和真实输入焦点仍需在实现后验证；Penpot 静态稿不证明运行期行为。
