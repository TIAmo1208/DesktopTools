# 封锁橙主题说明

本文件只记录「主题-封锁橙」专属的事实（当前值、开关语义、装饰边界、消息外观、设置界面表现、令牌关系）。通用契约见 [主题变量契约](../../docs/design/主题变量契约.md)，界面外观规则见 [视觉规范](../../docs/design/视觉规范.md)，主题的气质感来源见 `docs/设计语言.md`（参考皮肤仓库内的可移植设计语言文档）。

## 参考来源与取舍

配色与材质取自参考皮肤 [blockade-orange-dsh-skin](https://github.com/oenthing/blockade-orange-dsh-skin) 公开的别名令牌（分区风格 HUD：暖灰纸 / 冷灰墨、发丝描边、单支琥珀橙）。该仓库是 DSH Web UI 的客户端插件，与本仓库插件契约不同，这里只沿用取值与材质语言，不复制其代码、DOM 或脚本。

按项目要求**不做三面倾斜与透视层**（设计语言 §5.2 整层略去），因此本主题的识别特征是：发丝描边 + 中性灰四角刻线 + 行顶 2px 橙条。

- 采用：暖纸/冷墨两套调色板、材质不透明度下限、单层阴影语言、四角刻线、行顶橙条焦点、等宽数字、45° 切角（设计语言 §1.2 的可选装饰层）。
- 未采用：三面倾斜（按需求）、HUD 读数面板与工具卡（本仓库没有对应宿主位置）、氛围扫描光/等高线底（上一轮已确认去掉）、自定义背景图。
- 字体：参考皮肤内嵌的 **Borda 是商业字体，明确不可分发**，本主题不打包任何字体文件，改用系统 `Microsoft YaHei UI` 与 `Bahnschrift` 技术字栈。

## 外观配置（`theme.json` 当前值）

- `accentColor: #ff7f00`（界面强调与焦点）、`desktopAccentColor: #ffb03a`（桌面层琥珀焦点，比界面强调更亮以保证壁纸上的可见度）、`cornerRadius: 4`（设计语言的面板圆角）、`fontFamily: Microsoft YaHei UI`、`fontSize: 13`。
- 未声明 `boot.durationMs`，启动覆盖层沿用内置 `900ms`；主题只改它的底色、亮带与品牌字色。
- 颜色分工：琥珀橙只做界面强调、主命令填充、焦点条与桌面焦点；`--color-action-text` 深色用深墨 `#14181b`（在 `#ff7f00` 上 `7.05:1`，白字只有 `2.53:1`），浅色用白字（在 `#b25100` 上 `5.2:1`）。
- 浅色是暖中性纸：`background #e6e2db`、`surface #fcfbf8`、`subtle #f4f1ea`、`muted #4d5158`、`action #b25100`（烧焦橙，白字达标）。深色是冷中性墨：`background #0d0e10`、`surface #1b1c20`、`subtle #23252a`、`muted #b9bfc7`、`action #ff7f00`、`action-hover #f0a043`。
- 状态色：就绪 `#e0a23a`（浅色 `#8a5600`）、通过 `#7dbb42`（浅色 `#3f6b12`）、错误 `#ff3000`（浅色 `#b32400`）。

## 焦点语言

- **同屏一条 2px 橙条**：桌面项目选中、桌面项目悬停、门户条目选中与悬停、收集箱条目选中与悬停、自绘菜单命令的悬停/键盘焦点/展开中、设置导航的悬停与当前页、桌面格子的键盘焦点，都用行顶 `2px` 条表达；行底只做中性提亮（深色用白色 6%–14%、浅色用墨色 5%–10%），橙色不再出现在行底、边框或左侧竖条上。
- 每个载体的条都由自己的 `::before` 画出，从左侧 `scaleX(0→1)`：`transform 200ms cubic-bezier(0.22,0.88,0.24,1)`、`opacity 120ms ease`，只动这两个属性。两条时长分别取 `--blockade-bar-duration` / `--blockade-bar-fade`；`data-interface-animations="off"` 或 `prefers-reduced-motion: reduce` 时两值同时归零，静态落到最终态。
- 行底提亮走 `background-color` 过渡，时长取宿主 `--interface-transition-duration`（动画开启 120ms，关闭 0ms），不做阴影、位移或尺寸动画。
- 定位上下文：`.desktop-tile` 与两种桌面项目本来就有定位，桌面项目基类用 `:not(.desktop-item--unclassified):not(.desktop-item--drag-preview)` 限定后补 `position: relative`，不覆盖已绝对定位的未归类项与拖动预览；收集箱 `li` 与门户 `li` 由主题补 `relative`。
- 层级：条的 `z-index` 为 `1`（格子 `2`，压在透明标题栏之上），只占行顶 2px，命中区与布局盒不变。
- 格子焦点条画在格子内部上沿：不画外扩整圈，避免压到相邻格子与壁纸。
- 浅色桌面主题下组件对 `.desktop-item--fence[data-selected="true"]` 有更具体的选择器，主题用 `:root[data-desktop-theme] .desktop-item[...]` 同等具体度覆盖行底与边框；橙条走伪元素，不受组件 `background` 简写影响。
- 收集箱条目的选中与悬停覆盖 `.official-component__collect .collect-box__item--selected`、`.official-component__collect li:hover` 两条组件规则，并单独补 `:hover` 组合保持选中行底；组件改类名时主题测试会失败提示同步。
- 其余控件沿用宿主 `2px` 焦点环；发光文字是设计语言的反模式，本主题没有任何 `text-shadow` 光晕。

## 特效开关

设置条目保存两个布尔开关，写入文档根的 `data-blockade-<键>="on" / "off"`，未声明按开启；另有独立数值项：

| 键 | 开关 | 语义 |
| --- | --- | --- |
| `bevel` | 45° 切角 | 交互控件左上/右下切角开关 |
| `mono` | 等宽数字 | 数字与读数改等宽字形 |

- `bevelPixels`：切角像素，`0`–`12`，默认 `8`，写入主题私有变量 `--blockade-bevel`，停用主题时清理；与外观圆角偏好无关。
- 橙条是焦点语言本身，常驻生效，不做开关；主题不含全屏叠加层、循环动画与 `background-position` 动画。

## 材质与刻线

- 围栏：深色 `--fence-surface rgb(27 28 32 / 52%)`、白 13% 发丝描边；浅色 `rgb(252 251 248 / 86%)`、墨 20% 发丝描边——浅色主面取设计语言的不透明度下限，保证纸面在壁纸上可读。
- 格子阴影是一套单层语言：顶部内高光 + 底部内暗边 + 一层投影（深色 `4px 10px 26px rgb(0 0 0 / 40%)`，浅色 `3px 8px 22px rgb(28 26 22 / 12%)`）。
- 四角刻线：`.desktop-tile::after` 与两个自绘菜单容器各画八段发丝线（内缩 `6px`、长 `18px`、深色/浅色都用 `--fence-border` / `--menu-border` 的中性灰），只做装饰，不参与选中表达；菜单刻线画在容器 `background-image` 上，不改内距与行高。
- 减少透明效果（`prefers-reduced-transparency: reduce`）时格子撤下 `backdrop-filter`，改用不透明表面。
- 弹层：菜单面深色 94%、浅色 94%，单层阴影；原生 Toast 深底浅字。

## 交互控件切角

- 参与：`button:not([data-button="row-hit"])`、文本 `input`、`select`、`textarea`——左上/右下按 `--blockade-bevel` 切 45° 直角（分角圆角 + `corner-*` shape），其余两角保持直角。
- 不参与：`data-button="row-hit"` 命中层、复选与开关本体、自绘菜单表面、结构面、原生 Toast。
- 例外：自绘菜单命令保持组件原有的 `2px` 圆角——行高只有 `28px`，`8px` 切角会吃掉文字两侧留白。
- 关闭切角（`bevel` 开关 off）时参与控件半径归零、形状回到 round，不保留部分切角。

## 原生 Toast（`notification` 当前值）

`surface #16171b`、`border #3a3c42`、`text #f2f4f7`、`muted #b9bfc7`、`subtle #23252a`、`success #7dbb42`、`warning #e0a23a`、`error #ff3000`、`weight medium`、`cornerStyle bevel`、`cornerSize 10`。

`cornerStyle: "bevel"` 与 `cornerSize: 10` 同时声明时画左上/右下 `10 DIP` 45° 切角；任一缺省按[主题变量契约](../../docs/design/主题变量契约.md)回落原圆角。整套只有一份，不随深浅切换；页面 CSS 不装饰消息容器。

## 设置界面表现

- 品牌名使用桌面强调琥珀（`--desktop-accent`）；品牌盒不加扫描动画。
- 状态与分组标签（`.plugin-settings__label`、`.settings__status`、`.plugin-settings__status`、`.weather-settings__status`）用 `Bahnschrift` 技术字栈、字距 `0.08em`、`uppercase`；正文仍是 `Microsoft YaHei UI`。
- 设置导航行改直角；当前页与悬停都是行顶 `2px` 橙条，行底用墨色 5% / 8%，不再使用左侧竖条。
- 共享开关的专属覆盖：轨道 `40 × 22px`、圆角 `2px`、`--color-surface` 填充、`1px` 描边；滑块 `16 × 18px`、左上 `3px / 45°` 直切、上下内缩 `2px`；未选描边 `--color-muted`、滑块同色 `55%`；已选与聚焦描边 `--color-focus`、滑块用 `--color-focus`（不用状态色）并带 `5px / 32%` 光且靠右；键盘聚焦外环 `46 × 28px`、圆角 `4px`、`2px --color-focus`；禁用描边与滑块 `--color-border`、无光。撤下主题样式表后恢复共享胶囊几何；高对比度模式回系统绘制。
- 设置行保持直角与 `86%` 表面填充；文本字段悬停给强调色描边，聚焦为 `0.5px` 描边加 `20px / 14%` 淡光（设计语言输入卡聚焦值），不覆盖开关与复选焦点。
- 主题设置条目自身用 `.blockade-options*` 类：名称 `13px`、提示 `12px/18px` `--color-muted`、开关 `16 × 16px` 跟随 `--color-focus`、数值输入 `88px` 宽。

## 与设计语言的已知差异

| 项 | 设计语言 | 本主题实际 | 原因 |
| --- | --- | --- | --- |
| 三面倾斜 | 左/右栏、输入卡、弹窗、菜单透视旋转 | 不做 | 用户明确排除；降级后仍保留刻线与橙条 |
| 透视与 `translateZ` | 菜单悬停回正并上浮 | 不做 | 同上，倾斜层整体略去 |
| 悬停/按压缩放 | `scale(1.015)` / `scale(0.995)` | 悬停只提亮，按压只压亮度 | 宿主契约要求按下亮度不得变换尺寸；缩放会同时改变控件命中面 |
| 格子键盘焦点 | 2px 橙环、外偏 2px | 行顶 2px 橙条（画在格子内部） | 用户要求选中样式不要超出格子全边框；外扩环会压到相邻格子与壁纸 |
| 浅色强调色 | 浅色强调压深到 `#b25100` | 界面强调沿用 `#ff7f00`，浅色命令填充用 `#b25100` | 宿主只为两种深浅提供一个内联 `accentColor`；单值无法同时满足浅色 4.5:1 与深色 4.5:1（同一颜色对白与近黑不能同时达标） |
| 行高与栏宽 | 侧栏行 32–34px、栏间距 8px | 沿用宿主设置界面尺寸 | 布局由宿主组件持有，主题不改布局 |
| 正文/读数字体 | Borda / Titillium Web | 系统字体（微软雅黑 + Bahnschrift） | Borda 为商业字体不可分发；本主题不打包字体 |
| HUD 读数面板 | 侧栏内 21px 主值读数 | 无 | 本仓库没有对应宿主位置；时钟数字仍用等宽数字表现 |
