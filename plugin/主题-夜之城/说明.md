# 夜之城主题说明

本文件只记录「主题-夜之城」专属的事实（当前值、开关语义、装饰边界、消息外观、设置界面表现、令牌关系）。通用契约见 [主题变量契约](../../docs/design/主题变量契约.md)，界面外观规则见 [视觉规范](../../docs/design/视觉规范.md)。

## 外观配置（`theme.json` 当前值）

- `accentColor: #00c2d9`（界面强调与焦点）、`desktopAccentColor: #fce300`（NC 黄）、`cornerRadius: 0`（结构面直角）、`fontFamily: Microsoft YaHei UI`、`fontSize: 13`。
- `boot.durationMs: 2600`。
- 颜色分工：NC 黄只做主命令填充与桌面焦点（`--color-action`、`--desktop-accent`、`--fence-focus-border`）；霓虹青（`--color-ready: #00f0ff`，围栏/菜单描边与按钮冷光）只做焦点与装饰描边，不做按钮填充；`#ffb300` 只用于原生 Toast 的警告图标。
- 界面、围栏、菜单、消息四组深浅色各自给值，互相不借用。

## 特效开关

设置条目保存六个布尔开关，写入文档根的 `data-nightcity-<键>="on" / "off"`，未声明按开启；另有独立数值项：

| 键 | 开关 | 语义 |
| --- | --- | --- |
| `scan` | CRT 扫描线 | 全屏 `#root::after` 叠加的总闸（见「装饰边界」） |
| `brandScan` | 设置标题扫描线 | 只扫设置窗口标题品牌盒（含 logo 与名称）的循环亮带 |
| `tileScan` | 时钟扫描线 | 只扫桌面时间格子的循环亮带，受自身开关与 `scan` 总闸双重控制 |
| `bevel` | 45° 切角 | 交互控件左上/右下切角开关 |
| `glow` | 悬停冷光 | 按钮悬停青色光晕 |
| `mono` | 等宽数字 | 数字与读数改等宽字形 |

- `bevelPixels`：切角像素，`0`–`12`，默认 `6`，写入主题私有变量 `--nightcity-bevel`，停用主题时清理；与外观圆角偏好无关。
- 循环亮带动画（品牌盒 `4200ms`、时钟盒 `4800ms`）受界面动画开关与系统减少动效约束，任一关闭时动画层整体撤下，不残留半透明纹理。

## 交互控件切角

- 参与：`button:not([data-button="row-hit"])`、文本 `input`、`select`、`textarea`——左上/右下按 `--nightcity-bevel` 切 45° 直角（分角圆角 + `corner-*` shape），其余两角保持直角。
- 不参与：`data-button="row-hit"` 命中层、复选与开关本体、自绘菜单表面、结构面、原生 Toast。
- 关闭切角（`bevel` 开关 off）时参与控件半径归零、形状回到 round，不保留部分切角。

## 装饰边界

- 自绘菜单表面四角黄 L：`12px × 1px` 横竖线，只画 `.desktop-tile-menu` 与 `.folder-portal__breadcrumb-menu` 的表面；不装饰按钮、命中层和原生 Toast。
- 选中态四角 L（走 `--fence-focus-border`，即 NC 黄）：桌面项目选中、收集条目选中、桌面格子键盘焦点、门户条目选中；边框转透明只留四角图层，悬停仅改底色并使用 `background-*` 长写保护图层。
- CRT 全屏叠加：`#root::after` 鼠标穿透、只画线不铺底；深色为黑色扫描线配 `84px` 青色城市网格，浅色只留稀疏青网（`96px`、无黑线），`≤768px` 显示窗口不渲染，`scan` 开关关闭时整体撤下。

## 原生 Toast（`notification` 当前值）

`surface #0d1322`、`border #1f2c47`、`text #e8f1ff`、`muted #8fa3c8`、`subtle #121a2c`、`success #00f5a0`、`warning #ffb300`、`error #ff3b69`、`weight medium`、`cornerStyle bevel`、`cornerSize 12`。

`cornerStyle: "bevel"` 与 `cornerSize: 12` 同时声明时画左上/右下 `12 DIP` 45° 切角；任一缺省按[主题变量契约](../../docs/design/主题变量契约.md)回落原圆角。整套只有一份，不随深浅切换；页面 CSS 不得装饰消息容器。

## 设置界面表现

- 品牌名使用 NC 黄（`--desktop-accent`），品牌盒扫描亮带覆盖 logo 与名称整体；`brandScan` 有独立开关，不受 `scan` 总闸控制。
- 共享开关的专属覆盖：轨道 `40 × 22px`、圆角 `2px`、`--color-surface` 填充、`1px` 描边；滑块 `16 × 18px`、左上 `3px / 45°` 直切、上下内缩 `2px`；未选描边 `--color-muted`、滑块同色 `55%`；已选与聚焦描边 `--color-focus`、滑块 `--color-ready` 带 `5px / 28%` 冷光且靠右；键盘聚焦外环 `46 × 28px`、圆角 `4px`、`2px --color-focus`；禁用描边与滑块 `--color-border`、无冷光。撤下主题样式表后恢复共享胶囊几何；高对比度模式回系统绘制。
- 文本输入聚焦冷光不覆盖复选与开关；文本字段悬停先给青色边框。

## 与桌面/菜单令牌的关系

- 深色围栏：`--fence-border rgb(0 240 255 / 30%)`、`--fence-surface rgb(5 7 13 / 58%)`、`--fence-text #e8f1ff`、`--fence-focus-border` 走 `--desktop-accent`、项目文字阴影保证壁纸可读；浅色围栏独立取值。
- 自绘菜单：`--menu-*` 深浅色独立于围栏；容器内距 `4px`、命令行最小高 `28px` 由组件持有，主题不改。
