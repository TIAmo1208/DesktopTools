# Desktop Tools

Desktop Tools 是面向个人效率用户、专业创作者和开发者的 Windows 桌面内容工作区，负责呈现和组织桌面项目、围栏、文件夹门户与功能格子。Windows Explorer 继续提供桌面命名空间、Shell 操作和恢复兜底。

## 功能介绍

- 组织文件、目录、快捷方式和其他 Shell 桌面项目。
- 桌面和围栏中的可见项目按需读取 Windows Shell 图片缩略图、视频帧和音频封面，加载或失败时保留系统图标；不添加音乐角标、视频边框或快捷方式箭头，原生拖动复用已完成图像。
- 使用围栏管理项目归属、顺序、排序、滚动、折叠和布局。
- 使用文件夹门户浏览绑定目录及其子目录，并支持真实文件拖入和拖出。
- 提供收集箱、音乐、时间和 Debug 等功能格子；收集箱图片支持列表尺寸设置与悬停大图预览。
- 收集箱共享文本、独立图片和普通文件映射三类条目。文本和图片可追加到文本项，空白处创建独立条目，普通文件仅保存源路径；逐项反馈处理、跳过与失败。文本编辑窗打开时拒绝正文追加。图片收入设置位于收集箱二级设置；该设置用于文档插图。独立图片固定复制到 `collect` 根目录并保留源文件，同名自动生成不冲突的名称。
- 音乐格子接收单个受支持的媒体文件并交给系统默认程序打开，不保证自动播放；时钟与 Debug 拒绝内容投放。
- 收集箱的设置页、桌面背景菜单共用格子创建流程，统一确定初始位置与展开尺寸；格子菜单的“新建收集项”与工具栏按钮共用条目创建流程。
- 收集项编辑窗显示 Markdown 引用的本地图片与 HTTP(S) 图片，保留原始文件引用；收集箱与编辑窗的网页、邮件链接使用系统默认程序打开。
- 收集项编辑窗成功保存并关闭时，将明确归属且未引用的图片附件移入系统回收站；放弃草稿只考虑本次新增附件。普通保存与编辑过程中保留附件以支持撤销，历史未登记附件保留；回收边界见 [按需编辑窗口决策](docs/adr/0022-收集项编辑使用按需窗口.md)。
- 收集箱支持按格子保存混排／分离与类型筛选，单击选择、Ctrl/Shift 多选，双击、Enter 或右键打开。文本呈现标题、三行摘要及悬停预览，已有选择时仍可悬停预览。独立图片按显示尺寸和 DPI 按需读取静态缩略图，列表不播放 GIF，GIF 悬停大图与编辑窗使用原图播放；文件映射显示源路径。单选、多选清理先确认共享范围，映射清理保留源文件。
- 收集项拖出接入 Windows 复制路径，文本提供 Markdown 与配套资源、完整可读文本，图片提供实际文件，映射提供源文件；原条目保留。Windows 外部目标格式与实际拖放行为仍待实机验收。
- 收集箱格子菜单提供“移除”，只移除当前格子并保留共享收集内容；本次会话可撤销或重做，移除全部格子后仍可从设置页或桌面背景菜单重新添加。
- 统一功能格子的移动、尺寸调整、边缘吸附、折叠、标题工具和跨屏交互。
- 桌面项目拖动统一使用 Windows OLE；功能格子移动和尺寸调整使用工作区内部交互。
- 通过 Windows Shell 执行打开、重命名、删除、复制、移动、剪贴板和原生上下文菜单操作。
- 支持多显示器、DPI 坐标转换、跨屏预览和布局恢复。

桌面项目布局、围栏归属、门户配置和功能格子状态由 Desktop Tools 维护；文件事实和 Shell 恢复仍由 Windows Explorer 提供。

## 构建与运行

常用验证命令：

```text
npm run typecheck
npm run test:frontend
npm run test:rust
npm run build
npm run tauri:build
```

发布构建使用 `npm run tauri:build`。直接执行 Cargo 时沿用项目指定工具链、共享构建目录和 `src-tauri/Cargo.toml` 的 features。

Windows x64 未签名测试安装包入口为 `npm run tauri:installer`，产物目录为 `build/target/release/bundle/nsis/`。NSIS 使用当前用户安装，缺少 WebView2 时联网安装，安装包包含主程序、guardian 和许可声明；升级与卸载钩子请求正常退出并保留用户数据。

## 使用边界

- 天气入口提供显示偏好开关，默认关闭并随普通设置保存；当前尚未接入桌面天气格子，开关不会创建格子或改变凭据。API 字段旁的信息提示说明凭据来源与填写格式。

- 软件设置的“功能格子 → 天气”提供和风 JWT 凭据配置：填写账户 API Host、开发者 ID、项目 ID、凭据 ID 和 Ed25519 私钥，选择临时城市并完成全部能力验证后才能保存启用。凭据独立保存在 Windows Credential Manager，可替换或明确清除；实际账户权限须由用户验证。桌面天气格子、天气缓存及城市持久化尚未接入，范围见[天气组件决策](docs/adr/0025-天气组件采用单源基础预报与网页详情.md)。

- 关闭功能格子只隐藏实例并保留布局；折叠只隐藏内容，临时展开不修改保存的外观。
- 移动与缩放统一经公共外框处理，活动几何的 Escape 优先取消；开始提交后的领域操作沿用既有撤销边界。
- 多屏、混合 DPI、真实 Shell 文件投放及持续拖动性能需在 Windows 宿主验收，自动检查不能替代实机结果。
- 源码目录及入口分别见[前端目录结构](src/README.md)和[Rust/Tauri 目录结构](src-tauri/README.md)。
